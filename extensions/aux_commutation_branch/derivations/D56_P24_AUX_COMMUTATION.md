## 1. 问题

现有所有设计中，高侧都在谐振谷底开通（约 9 V / 12 V），不是零电压。

能否加一条小辅助支路实现高侧 ZVS，同时满足：
- 主电感负电流不提高（5% 设计不变）；
- 低侧 ZVS 保持；
- 净损耗下降。

## 2. 模型

### 2.1 单相开关节点

    C(x) dx/dt = i_r − i_f + i_dev(x)
    C(x) = 3·Coss(x) + 2·Coss(V_rail − x) + 2·Coss(x + ΔV_cs)
    Lf di_f/dt = x − Vo − R i_f
    Lr di_r/dt = Vs − x − R_aux i_r

**各项来源：**
- Coss 取 EPC2067 数据手册曲线（A59 数字化）；
- i_dev 是关断开关的反向导通（A57 拟合，Vf = 2.09 V，6.0 mΩ/器件）。
- **第三项是 SCB 特有的。** 本相的串联电容节点同时是下一相高侧的漏极，所以 x 上升时，下一相高侧的 V_DS 从 ΔV_cs ≈ 11.9 V 一起上升。
  - 不加这一项，谷值偏低 0.2–1.1 V。
  - 节点总电荷（0 → 12.2 V）：低侧 81 nC + 本相高侧 54 nC + 下一相高侧 30 nC = **165 nC**。

## 3. 线性近似：滤波电感门槛

上升沿期间，节点同时看到 Lf（接 Vo）和 Lr（接 Vs）：

    x_max = V_th + √(V_th² + (Z_eq·I_0)²)
    Z_eq = √((Lf∥Lr)/C)
    V_th = (Lf∥Lr)(Vo/Lf + Vs/Lr)

**推论：**
- **Vs ≈ 0 或 Vo 时**，V_th ≈ 1 V，Z_eq ≤ √(Lf/C) ≈ 0.36 Ω，总电流至少 ~33 A，与 Lr 无关。
  - 接 Vo 的 ZVT（Nan 2016）、钳位开关（Vicor，Ulrich 2021）、相间支路，都只是把"提高负电流"换个地方提供。
  - 文献里这些方法有效，是因为它们的 Lf 是 µH 级；P24 的 Lf 只有 1.47 nH。
- **Vs 过半轨、Lr ≤ Lf 时**，V_th → Vs，节点不需要额外电流就能摆到电压轨。这就是 ARCP 中点的作用。

**非线性模型数值（相1）：**

| 接法 | Lr | 低侧关断时需要的辅助电流 |
|---|---|---|
| 接 Vo | 0.25 / 1 / 2 / 5 / 10 nH | 82 / 46 / 38 / 32 / 29 A |
| 接 Vm | 0.5 nH，Vm ≥ 8 V | 0 A |
| 接 Vm | 0.25 nH，Vm ≥ 7 V | 0 A |
| 接 Vm | 1 nH，Vm 7 / 8 / 9 V | 22 / 15 / 5 A |

## 4. 结构：双向开关到自平衡电容 Cm

### 4.1 一个周期

1. 双向开关（BDS）与低侧关断同时导通（电流从零开始）。
2. 上升沿：节点到达电压轨后，高侧零电压开通。
3. 高侧导通期间，Lr 承受 Vm − V_rail < 0，电流过零变负，回充 Cm。
4. 高侧关断：负的辅助电流加快下降沿；低侧仍然 ZVS，死区需要缩短。
5. 低侧开通后，Lr 承受 +Vm，电流回零，BDS 零电流断开。

### 4.2 平衡与设定

**Cm 平衡：** 每周期净电荷为零时得到 Vm*。从 Cm 取出的电荷随 Vm 增大而增大，所以平衡点稳定，可以自启动（测试 test_capacitor_balance_is_stable）。

**高侧导通的结束条件：** 导通到 i_f 达到基线峰值，相当于电压环保持平均电流。所以主纹波不变。

**低侧死区两种规则：**
- 固定 1.26 ns；
- 重调到与基线相同的开通电压 −0.69 V。

## 6. 时序灵敏度

**BDS 开通偏离低侧关断 −1…+2 ns**（Vm 固定在平衡值）：
- 0.5 和 0.75 nH 都保持零电压（0.75 nH 在 +2 ns 时 0.30 V）；
- 1–2 nH 时 V_DS 变化 ≤ 0.66 V。

**高侧开通相对"节点到达电压轨"的偏差：**

| Lr | 提前 0.25 / 0.5 / 1 ns | 滞后 1 ns |
|---|---|---|
| 0.75 nH | +0.6 / +3 / +16 nJ | 0 |
| 0.5 nH | +3 / +14 / +63 nJ | +3 nJ |

**对比：** RTL 的 LSB 是 31.25 ps，研究过的抖动是 30–100 ps。

**结论：** 稳定运行时，D56 的 Vm、V_DS、辅助电流和净损耗都在登记带内。

**D56 没覆盖的三点：**
1. **高侧谷值测量的选择。**
   - 新加的"V_DS ≤ 0 即冻结"选项（登记运行 z075）让相2–4 的关断电流失控：离散 26–36 A，辅助电流爆发 ~400 A，Vo 振荡 ±7%。

3. **抖动。** 30 ps 时相2–4 关断电流离散从 0.6 A 增到 0.9–1.3 A。

## 8. 判定与局限

**判定：**
1. **在 P24 里，辅助支路必须接一个过半轨的电源，接 0 V 或 Vo 不行。**
   - 原因是 1.47 nH 的 Lf 把总电流门槛钉在 ~33 A。
   - 这是 P24 特有的结论，文献里大电感的场景不会出现。
2. **自平衡 Cm 加单脉冲 BDS** 可以在不改主纹波、保持低侧 ZVS 的前提下实现高侧 ZVS。
   - 按中心估计，净省约 4–5 W（输出的 ~2%）。
   - 净收益最优点是 1–1.5 nH 的部分 ZVS。
3. **结论依赖硬开通损耗模型。** 按 A91 下界，支路会略亏（+0.3…+2.3 W）。

**局限：**
- **单相模型。** 其他相看作刚性，只用串联电容电荷修正。辅助电流流过串联电容造成的均流偏移估计 < 1 A，留给协同仿真。
- **BDS 零电流断开是理想的。** 门极驱动要浮地，是复杂度成本，没有计入。
- **假设值未经验证：** α 缩放的 EPC2067、Lr 电阻 0.2 mΩ、关断下降时间。
- **没有算 Lr 磁芯损耗和 Cm 的 ESR。**
- **只算了 5% 工作点和 25 ℃。**
