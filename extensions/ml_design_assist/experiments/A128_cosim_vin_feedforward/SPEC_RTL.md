# A128 RTL spec - Vin feed-forward (cap_vin + learned falling-step rule)

**Status:** an opt-in extension. With `cfg_vff = 0`, every output must be
bit-identical to the current RTL.

**Files touched:**
- `src/scb_ivr/cosim/rtl/scb_ctrl.v`;
- a new `rtl/scb_vff.v`;
- `bridge.py` (the Vin ADC);
- `rtl/scb_multi.v`, regenerated by `gen_multi.py`, ports passed
  through;
- `tb/test_scb_ctrl.py` (new tests).

## Inputs

**The Vin ADC** is sampled at phase 1's high-side turn-on, the same
instant as Vo's.
- The bridge reads `p.vin_at(plant.t)`.
- `vin_valid`, `vin_code[11:0]`, LSB `cfg vin_lsb_v`, default 0.02 V.

**cfg:**
- `cfg_vff` (1 bit);
- `cfg_vff_c[4]`: signed 10-bit falling-step coefficients, Q16 per code;
- `cfg_vff_k`: the phase-1 cap constant, in LSB·code;
- `cfg_vff_lp2_sh` (default 2), `cfg_vff_lp20_sh` (default 6);
- `cfg_vo_code_ff` (Vo for the rail estimate, default the vref code).

## Per Vin sample (scb_vff.v)

**Low-passes,** each with 8 fractional bits:
- lp2 += (vin − lp2) >> lp2_sh;
- lp20 += (vin − lp20) >> lp20_sh.
- Both start at the first sample (no transient at enable).

**The falling term:** g = max(lp2 − vin, 0), in codes with 8 fractional
bits.

**Per-phase scale:** s_k = 1 + c_k · g / 2^16.
- Clamp to [0.5, 1.25].
- ton_k = ton_now · s_k, rounded to the LSB.

**The phase-1 cap:**
- rail = (2 vin − vin_prev) − 0.75 · lp20 − vo_code_ff (one-step prediction against the lag), in codes;
- cap = cfg_vff_k / rail;
- a sequential divider, ≤ 24 clocks, so the result applies from the
  next phase-1 turn-on (a one-period lag, modelled in D63's
  prediction);
- rail ≤ 0 → no cap.

**Output to the phases:**
- ton_ph[1] = min(ton_1, cap);
- ton_ph[k] = ton_k for k = 2-4;
- with `cfg_vff` = 0, ton_ph[k] = ton_now.

## Values for A124's design

- L 2.933 nH, I_CAP 180 A, so K = 16 896 LSB·V (LSB 31.25 ps).
- With 20 mV codes: cfg_vff_k = 16 896 / 0.02 = 844 800.
- c = (+64, −47, −47, −139) Q16 per code. That is A127 s1's falling
  weights × 0.25 × 0.02 V / 2 V × 2^16.

## Tests (cocotb)

1. `cfg_vff` = 0: identical ton to all phases.
2. A constant Vin: s_k = 1 and the cap is inactive.
3. A Vin step down: the expected per-phase ton within 1 LSB.
4. A Vin step up: the cap equals K / rail within 1 LSB, from the next
   period on.
5. The divider's latency is under one switching period.
