# D01 — 时刻与时间区间：定义接口

日期：2026-09-27。状态：独立接口与9项单元测试通过；未接入求解器。

## 依据和权限

本模块是 `PROJECT_DECISION`：为了不混淆论文描述而建立的数学记账接口，
不是论文新提出的控制方法，不给论文补造延迟、死区、阈值或开关命令。

论文依据的入口仍为 P24 Sec. II-B / Fig. 3–4、P25 Sec. II / Fig. 2–3。
既有转录位于 `paper_locked/02_ectc2024_main/STEP_11_P24_FIRST_PHASE_STATE_TRANSCRIPTION.md`。
该转录是项目记录，不替代原文；本次没有重新认证其中所有逐时刻映射。
尤其不能把 P24 的 t2 与 P25 的 t2 因同名当成同一事件。
此模块因此不导入旧 `physical_events.py` 的编号映射，也不声明已修正它。

## 输入与定义

每个时刻必须带：分支、实验编号、绝对时钟编号、nP、nM、模块号、相号、周期号、
H/L开关、事件类型、秒为单位的时间、证据类别及出处/假设。
H/L 是内部统一角色，不是替换论文原始符号。外部适配器须保留原符号与原文位置。

| 输出 | 起点 → 终点 | 限定 |
|---|---|---|
| 名义导通区间 | nominal_on → nominal_off | 同一开关，仅排程 |
| 命令导通区间 | command_on → command_off | 同一开关，仅控制命令 |
| 有效栅极导通区间 | effective_gate_on → effective_gate_off | 同一开关；有效阈值由适配器声明 |
| 命令死区 | 原开关 command_off → 对侧 command_on | 同相同桥臂 |
| 有效栅极死区 | 原开关 effective_gate_off → 对侧 effective_gate_on | 同相同桥臂 |
| 关断至对侧零电压区间 | 原开关 effective_gate_off → 对侧 vds_zero | 不自动等于任何一种死区 |

以上统一为 Δt = t_end − t_start。反向导通起点可记录，但不得冒充栅极开启。
未知时间为 None，不能代入0。UNKNOWN_BLOCKING 即使填了数字也不能计算。

## 边界

1. 当前只计算同一实验、同一绝对时钟、同一分支/相/模块/周期中已经配对的单段区间。
   跨周期区间、多个脉冲的累计导通时间、跨相换流关系不在本模块实现范围。
2. 时间可相对选定原点为负，但必须有限；区间长度不得为负。
   重叠导通报错，不能取绝对值或截成零。
3. 调用方负责保证两事件属于同一次转换且区间内无额外边沿；本模块尚不验证完整事件历史。
4. 事件检测的方向、容差、滞回、去抖及有效栅极阈值尚未实现，不能因接口存在就声称测得真实事件。
5. PROJECT_DECISION 表示定义方式，不表示填入的器件值来自论文。
   source 非空检查只能强制留出处，不能自动证明出处真实。
6. 不设默认驱动延迟为零，不设默认死区，不加入任何电压、电流、器件或预充电数值。
7. Vds归零不是栅极开启，也不是反向通道导通。若理想模型让事件重合，
   适配器必须明确声明零延迟/理想钳位假设，仍分别保存事件。
8. 不证明ZVS能量充足、周期闭合、启动可达性或论文复现成功。
   旧求解器尚未使用此接口，历史结果不能自动获得新的严格性保证。
