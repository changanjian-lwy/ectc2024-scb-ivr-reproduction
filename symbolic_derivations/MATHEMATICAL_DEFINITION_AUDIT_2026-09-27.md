# 数学定义审计与统一定义草案 — 2026-09-27

范围：审计现有公式、A51/A55求解器、周期接口和零启动接口。
本文件不改变电路、参数、控制器或历史结果，不新增扫描。
下述定义是项目的数学规范草案，不冒充论文明确给出的控制细节。

## 0. 当前结论的正确强度

现有项目已经有明确接线的分段电路方程和离散求解实现。但“离散
周期映射收敛”“事件窗口中准入”“实际门极ZVS”“原文控制复现”是
不同命题，不能用一个 PASS 代替。

A55九组数值及步长比较保留；其通过表示当前固定PWM窗口、恒定电容、
等效提前导通模型中的局部数值结果。尚未完成本审计要求的逐量纲周期
验收、所有支路一致性及独立门极/反向导通验证，不能升级为完整器件
或论文复现结果。旧测试通过不证明缺少的数学条件已被测试。

## 1. 时间必须由物理事件定义，而不是统称 Ton / dead time

对模块 m、相 k、周期 n，定义名义指令参考时刻

    tau[m,k,n] = tau0 + n*Tcmd + phi[k] + psi[m].

均匀相间交错可取 phi[k]=(k-1)*Tcmd/nP；模块偏移 psi[m]必须由该
实验单独给定，不能从相数自动推出。单模块明确写 nM_sim=1。

分别保存：控制逻辑指令时刻 t_cmd、驱动后有效门极时刻 t_g、
反向支路开始承载电流时刻 t_rev、零电压事件 t_z。

    Ton_gate = t_g,H,off - t_g,H,on
    Ton_model = integral 1{模型高侧沟道被置ON} dt
    d_cmd,LH = t_cmd,H,on - t_cmd,L,off
    d_gate,LH = t_g,H,on - t_g,L,off
    Tcomm,LH = t_z,H - t_g,L,off

反向过程 HL 另设对应量；不假定两个死区相等。若驱动延迟被忽略，
明确 t_g=t_cmd；即使如此也不等于反向导通时刻。

在当前A51对称窗口中，名义H开通中心是 tau，关断中心是 tau+Ton_nom；
两个窗口各宽d。H在 tau+Ton_nom-d/2被关断，若无提前准入则在
tau+d/2开通，所以 Ton_model=Ton_nom-d。若提前准入时刻为 t_adm，
本相该次高侧导通长度是 tau+Ton_nom-d/2-t_adm，不能再套 Ton_nom-d。

因此前次解释只在“无提前准入、当前对称窗口实现”下成立；它不是
所有变换器或论文中 Ton 的通用定义。

证据：A51 `period_intervals`、`period_start_s`、`_resolve_turn_on`；
A50副本 `ZeroStartBoundary.on_time_s`；P24语义模块将t1定义为高侧
导通区间结束。必须先核对名义时钟、真实门极与事件关系，再决定是否
改变程序。改为从实际开通起计满Ton是新的控制分支，不是无害更名。

## 2. ZVS可达、钳位和门极ZVS必须分开

高侧电压严格按实际两端定义 vH,k=vD,k-vS,k，而不是任意节点对地电压。
自由换流方程在有效域内产生轨迹；向下的首次零电压事件定义为

    t_z = inf{t>=t_release : vH,k(t)=0 且此前vH,k>0}.

常规穿越可要求 dvH,k/dt<0。相切到零必须另标 grazing，不应靠离散
网格的符号变化自动认定没有到达。起点已经<=0是独立入口状态，不能
记作在窗口内部刚刚发生了零交越。

器件门极开通的零电压指标是 vH,k(t_g,on^-)；理想定义为零，数值
判据为 |vH,k(t_g,on^-)|<=epsilon_V，同时检查支路有效性和事件顺序。
epsilon_V、epsilon_t必须显式列出来源或数值误差目的，不任意填入硬件
容许值。某时刻碰到零而后来回升，不代表以后开门极仍是ZVS。

A51在 vds<=0 时直接把高侧ON电阻接入；该动作兼任了理想反向钳位
和门极准入。`natural_zvs`目前应解释为“该等效模型的零电压准入”，
不能当作独立验证真实GaN反向特性和驱动时刻。低侧有同样问题。
真正的门极状态与反向导通支路必须各自有状态/本构关系。

## 3. 负电流比例：四个量及因果性

令 iL,k 正方向为开关节点经电感流向输出。相周期区间 J[k,n]必须
先按固定时钟或实际开通事件定义，二者不能切换使用。

    Ipk,k,n = max_{t in J[k,n]} iL,k(t)  (要求Ipk>0)
    alpha_valley = max(0,-min_{J[k,n]} iL,k)/Ipk,k,n
    alpha_off = max(0,-iL,k(t_g,L,off^-))/Ipk,k,n
    alpha_entry = max(0,-iL,k(t_window,start^-))/Ipk,k,n

控制器的 alpha_set 是另一输入。alpha_entry=alpha_off只在确实已证明
窗口起点就是低侧有效关断时刻的分支上成立。全周期谷值可能发生在
后续换流中，不能自动当作关断阈值。

因果阈值控制应写成 iL,k(t)+alpha_set*Ipk_ref,k,n=0 的定向事件，
且进入该阶段时阈值尚未越过。Ipk_ref必须规定为已经发生的本周期
正峰值、上一周期峰值或预设参考；不能让实时控制器读取未来才知道的
完整周期最大值。离线周期约束可以使用整周期最大值，但须另标用途。

A55没有alpha_set控制器；其39%是观测值，不是“求出了实现ZVS所必需
的最小负电流比例”。某一个可行点更不能证明必要性。

## 4. 状态、代数量和事件左右极限

定义 x 为独立储能坐标（电容电荷/独立电压、电感磁链/电流），y为
代数节点及支路变量，s为离散控制器状态及记忆（锁存、峰值记录等），
theta为时钟相位。完整状态是 (x,s,theta)，而MNA向量z=(x的表示,y)
不是必然具有相同数量独立自由度的物理状态。

    E_sigma zdot + A_sigma z = r(t),  z属于该模态一致性集合。

每次事件保存 t_e、sigma^-、sigma^+、x^-、x^+、y^-、y^+。在没有冲激
电流/电压的模型中，电容电荷和电感磁链连续；代数量按新模态求解。
理想开关若造成不相容的储能约束，必须定义冲激/复位关系或加有限
寄生元件，不能以“所有状态连续”略过矛盾。

序列化20个变量作为离散算法检查点是合理的软件接口要求，不证明
20个变量都能自由指定。输出的左极限不能被下游当右极限。旧Track-B
接口 `low_side_on_left_limit = not high_on`仅适用于无死区互补边界，
不得直接用于A55；有死区时须分别导出两侧门极及反向支路状态。

## 5. 周期误差必须具有量纲一致性（当前明确缺口）

A51 `relative_residual`使用

    ||F(z)-z||_infinity / max(||z||_infinity,1)

其中同时包含V与A；`PeriodicResidual.max_abs`也混合两种单位。因此
当前停止量会随使用V还是mV改变，不是物理上统一的相对误差。

反例：z=(1 V,100 A)，残差=(50 uV,0 A)，以V/A记录给5e-7；仅将电压
改用mV，同一物理状态给5e-5。若阈值1e-6，验收结果被单位选择改变。

建议逐变量定义

    r_j = |x_j(T)-x_j(0)| /
          [atol_j + rtol_j*max(|x_j(T)|,|x_j(0)|)]
    r_period = max_j r_j <= 1.

atol_j具有该变量单位；rtol_j无量纲。二者必须预先规定，不能为了
某个结果通过而调整。并另查代数一致性、控制器记忆及周期截面一致。
若求解的是离散F_h，必须称作离散周期解，使用步长收敛研究其与连续
系统的关系；线性系统残差很小也不等于时间积分误差小。

## 6. 固定点、秩、稳定与启动可达是不同命题

固定模态顺序的离散映射是 z_{n+1}=M_h z_n+c_h；固定点方程是

    (I-M_h) z*=c_h.

代码 `periodic_affine_solver.solve_periodic_fixed_point`返回的秩来自
I-M_h，不是M_h。历史文字“周期映射矩阵秩17”不准确，应说明这是
固定点线性系统的数值秩。数值秩还依赖尺度和截断；近单位特征方向
不能直接当作严格守恒量或精确三参数不变流形。

完整零启动模型中存在有限泄漏，因此“固定三个慢变量”是快子系统
的条件化近似，不证明原系统这些变量严格不变。A53/A55固定tap1..3
是该边界选择，不等于把飞跨电容强制设成36/24/12 V。

周期点存在不证明吸引性。对可微、有效的截面映射，需在独立一致性
坐标中分析DF的谱；事件驱动系统必须包含事件时刻变化的影响。擦边、
模态变换及非光滑处另做分析。即使局部吸引，也不证明零初始状态在
其吸引域内。因而 F(x*)=x*、局部稳定、零启动可达分别验收。

## 7. 固定支路必须验证有效域

理想二极管取电流a->k、vD=va-vk时：

    iD>=0, vD<=0, iD*vD=0.

有限Ron二极管使用其相应本构条件，不把理想式当精确关系。所有固定
OFF的预充电支路、被激活的钳位支路都要在整条接受轨迹上验证。
A51监视器有off-diode电压记录，但A53 `_safety`只把相电流作为硬门槛；
A55九组报告没有独立完成这一全轨迹支路有效性验收。代数方程求解成功
本身不能补足该项。过去固定二极管仿射模型的验证也不能转移给新工况。

## 8. 能量、电荷和三角波公式的适用域

`0.5*L*Ineg^2`是某时刻该电感的储能，只有特定孤立/净能量需求定义
下才是全部可用换流能量。多源多电容网络应从

    W(t_b)-W(t_a) = integral_{t_a}^{t_b}(P_sources-P_dissipation) dt

出发。不能把 `Ecomm<=0.5*L*Ineg^2`当成任意整机拓扑的通用必要条件。
本项目已有局部无损模板，守恒量为

    0.5*L*i^2 + 0.5*Ceq*(X-Vo)^2.

在模板的指定接线/初始方向/恒定源条件下，可达判据包含初始和目标
节点相对于Vo的势能差，而非仅剩电感储能。见共同符号文件。

电荷严格使用 Delta q=integral i_C dt；`I_initial*Delta t`仅为恒流
近似。若要称上界，需证明全区间 |i_C|<=I_bound 后才能使用
|Delta q|<=I_bound*Delta t。`feasibility_envelope.py`中的“ceiling”
文字不能对变化电流和整机所有电容无条件沿用。

同理 Iavg=(Imax+Imin)/2 只对整周期由两段线性坡道覆盖的波形成立；
存在零电流停留或额外谐振区间时，应直接用周期积分。负谷值修正式
Ipk=2Iavg/(1-alpha)继承同一假设，不能替代A55整周期电流积分。

非线性器件统一用 q(v)，Cdiff=dq/dv，储能 E(v)=integral_0^v u*dq(u)。
时间等效电容与能量等效电容不能不加说明互换；当前恒定电容模型在
自身边界内可以自洽，但不能据此声称器件真实开关能量已验证。

## 9. 测量和优化对象

目标电压、实际平均电压、额定功率、实际功率分别命名。固定R负载：

    Rload=Vtarget^2/Prated
    Pout=mean(vout^2)/Rload
    Pout-(mean(vout)^2/Rload)=Var(vout)/Rload >=0.

实际支路沟道损耗是 sum integral_enabled(v_branch^2/R_branch)/T；
不能替换成每相电感iL的平方，也不能遗漏接受轨迹的回退去重。
历史A51监视器仍会观察自由探测轨迹；A55独立计量已经去除这些探测
样本，但原求解器的最大电流门槛仍可能被它们触发。必须区分求解器
试探越界、自由换流预测越界和真实接受轨迹越界。

优化变量、参数、约束和目标函数应分别给定。以不同实际输出功率的
点比较绝对损耗，不是同额定性能优化。A55九点只能叫局部联合扫描，
不能叫已完成联合最优化；局部二分边界也不证明全局单调性或唯一阈值。

原生P24、原生P25和补充分支各自规定 alpha_set、门极真值表、事件
规则；A55固定窗口等效控制是单独分支。没有证据支持的参数/延迟/
容差保持“未指定”或明确探索假设，不通过改数值填补定义缺口。

## 10. 后续落实顺序

1. 统一事件字段和Ton/死区/频率定义；明确当前A55是哪个控制分支。
2. 实现逐量纲周期残差与全轨迹支路有效域检查；复核已保存候选，不先
   扫更多参数。补充单位变换不改变验收结论的反例测试。
3. 分开门极与钳位状态，明确峰值参考和事件左右极限；记录 simultaneous
   events 的优先级/联合处理及超时失败，不用强制开通掩盖原生分支失败。
4. 固定各原生/补充分支的方程、控制器及可行约束后，再进行联合求解。
5. 最后才讨论稳定、启动交接与同输出功率下的损耗优化。

本审计没有宣称所有缺口都已实现修复，也没有宣称论文错误。可立即
更正的是术语及结论强度；涉及控制器或验收行为的变化须独立版本化并
重新验证，历史数据保留其原始定义。
