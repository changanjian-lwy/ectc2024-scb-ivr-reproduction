# D55：定时关断的dlo规则——负载阶跃跟踪与抖动之间的取舍（A100的数学模型）

2026-10-01。计划写在A100 BOUNDARY第3–4节（代码与运行之前）。规则的选择和预测写在第5节，在定时运行之前提交（ac96d47）。

## 1. 问题

A99的dlo每周期只调 ±1 LSB（31.25 ps）。负载阶跃时，电压环改变Ton，相1所需的低侧时长随之变化：
- 比例约为 ∂i_off,1/∂ton_1 ÷ |∂i_off,1/∂tlow_1| = 6.47 / 0.68 = **9.52**（D54雅可比）；
- 参考运行实测为10.1–10.3。

±1 LSB 跟不上。另一方面，更快的规则会放进更多噪声。本文在同一模型中同时量化这两边。

## 2. 方法

### 2.1 跟踪：回放实测轨迹

在A100的参考运行（比较器关断的采用设计，400 µs处 ±25 A、±62.5 A 阶跃）中：
- 比较器本来就在目标电流处关断，所以每周期相1的"低侧开通到关断"间隔 R(n) 就是定时关断所需的值；
- 同时记录每周期的Ton(n)。

**回放：**
- 每条规则的dlo（整数LSB）对着 R(n) 运行；
- 关断误差为 dlo − R − 3 LSB；
- 相1关断电流误差为 −(Vo/L) 乘以该误差；
- 分不加噪声，和加30 ps抖动等效噪声（D54：e_lo 标准差0.56 ns）两种情况。

**局限：** 回放忽略了跟踪误差反过来对电压环和电路的影响。

### 2.2 抖动

D54的蒙特卡洛（线性电路 + 精确规则，平均槽位），0、30、100 ps。

**代码与记录：**
- `scripts/p24_dlo_rules.py`；
- `src/scb_ivr/p24_jitter.py`（`lo_adm`、`lo_smax`、`lo_ff`、`lo_kff`）；
- `diagnostics/D55_dlo_rules_5p0pct.json`。

## 3. 结果

### 3.1 参考轨迹

| 阶跃 | R的变化 | 每周期变化（95分位 / 最大） | ΔR/ΔTon |
|---|---|---|---|
| +25 A | +17.9 ns | 13.6 / 31 LSB | 10.20 |
| −25 A | −18.0 ns | 13.4 / 32 LSB | 10.14 |
| +62.5 A | +44.4 ns | 24 / 54 LSB | 10.34 |
| −62.5 A | −44.9 ns | 16 / 44 LSB | 10.11 |

### 3.2 规则比较

| 规则 | 相1电流最大误差（+25 / −25 / +62.5 / −62.5 A） | 30 ps：相2–4标准差 | 30 ps：周期标准差 |
|---|---|---|---|
| S（±1，A99） | 12.9 / 12.3 / 39.0 / 34.7 A | 0.40–0.42 A | 0.15 ns |
| ADM8 | 0.8 / 0.8 / 22.1 / 12.6 A | 0.42–0.44 | 0.24 |
| ADM16 | 0.7 / 0.8 / 8.6 / 2.8 A | 0.43–0.45 | 0.27 |
| **ADM32** | **0.9 / 0.8 / 2.4 / 1.9 A** | **0.44–0.46** | **0.30** |
| ADM64 | 0.9 / 0.8 / 2.5 / 2.0 A | 0.44–0.46 | 0.31 |
| FF10 + S | 6.2 / 5.3 / 21.3 / 13.1 A | 0.40–0.42 | 0.16 |
| FF10 + ADM32 | 0.8 / 0.8 / 2.0 / 1.9 A | 0.44–0.46 | 0.30 |
| 比较器（A97，参照） | — | 0.56–0.66 | 0.55 |

**读法：**
- **单独用前馈不够。** 瞬态中Vo的下陷改变了电流下降斜率，Ton前馈看不到这一部分。
- **自适应步长（ADM）承担了跟踪。** 上限越大跟踪越好，噪声也越大。
  - 这就是"跟踪速度 ↔ 噪声"的取舍：从S到ADM32，30 ps下的波动约 +9%，周期标准差 0.15 → 0.30 ns。
  - 但仍比比较器设计低25–30%。
- **−62.5 A阶跃约1.9 A的下限对所有规则都存在。** 阶跃初期R每周期变44–54 LSB，而测量晚一个周期。
- **选ADM32。** 它与最好的组合（FF + ADM32）相差 ≤ 0.4 A，且不需要前馈。

## 4. 与A100交叉验证

| | D55 | A100 |
|---|---|---|
| ADM32，+25 / −25 A：相1最大偏差 | 0.86 / 0.80 A | 0.61 / 0.68 A |
| ADM32，+62.5 / −62.5 A：相1最大偏差 | 2.42 / 1.91 A | 1.74 / 1.44 A |
| S，+62.5 / −62.5 A：相1最大偏差 | 39.0 / 34.7 A | 23.3 / 18.6 A |
| ADM32，30 ps：相2–4标准差 | 0.43–0.45 A | 0.42–0.47 A |
| ADM32，30 ps：周期标准差 | 0.27 ns | 0.37 ns（+39%，超出 ±30% 判据） |
| ADM32，100 ps：相2–4标准差 | 1.20–1.25 A | 1.04–1.20 A |
| ADM32，0 ps：各相标准差 | 0.018 A | 0.021 A（阶跃前） |

**结论：**
- **跟踪方面，回放高估误差约25–40%，但两种规则的排序和量级正确。** 回放不含闭环反馈：真实电路中，dlo滞后造成的电流偏差会反过来减小所需变化。
- **抖动方面，两个模型一致**，只有小σ时的周期标准差，协同仿真偏高（A98、A99、A100一致出现）。

## 5. 预测对照（A100 BOUNDARY第4.2节）

| 预测 | 结果 |
|---|---|
| 1. S在 ±25% 阶跃中误差 > 2 A | **成立**（D55：35–39 A；A100：19–23 A） |
| 2. ADM：所有阶跃误差在0.5 A以内，抖动在S的10%以内 | **抖动成立**（+9%）；**跟踪不成立**（±25% 阶跃1.9–2.4 A，±10% 阶跃约0.8 A） |
| 3. FF去掉大部分Ton驱动的误差，剩余部分仍需ADM | **部分成立**（只去掉约一半：Vo引起的部分前馈看不到） |
| 4. 选定规则保持抖动优势（30 ps ≤ 0.47 A），所有阶跃误差在1 A以内 | **抖动成立；±25% 阶跃不成立**（模型约2 A，实测1.4–1.7 A） |

## 6. 判定 / 局限

**判定：**
- 定时关断加自适应步长，可以同时满足稳态（无极限环）、抖动（比比较器低24–35%）和负载阶跃（相1偏差 ≤ 1.7 A，Vo与比较器设计相同）；
- 代价是相对 ±1 规则约9%的抖动增加。

**局限：**
- 回放是开环的；
- 学习长度只针对本次启动；
- 输入电压阶跃、其他负载、m ≠ 0 未检验；
- 电压环本身很慢，Vo偏差 ±12% 来自电压环，与本问题无关。
