# D59：P24 模块输出电压环——对 Ton 的采样 PI（A104 的数学模型）

2026-10-02。代码 `src/scb_ivr/p24_voltage_loop.py`，运行 `scripts/p24_voltage_loop.py`，记录
`diagnostics/D59_voltage_loop.json`，测试 `tests/test_p24_voltage_loop.py`（4个）。建立在 D58 的平均模型之上。

**工作顺序：** 先于 A104 的任何运行，与 A104 BOUNDARY 一同提交。

## 1. 问题

现在的电压环（A79）只有积分项，ki = 0.25 ns/V，当初没有经过设计：
- 带宽约 7.5 kHz，相位裕量 51°；
- ±62.5 A 阶跃时 Vo 偏 +122/−127 mV，要约 100 µs 才回到 1% 以内。

要回答：环路能做到多快？限制在哪里？

## 2. 对象（D58 的模式 P）

模块是一个由 Ton 控制的电流源：

  I = k·4·[(V_rail − Vo)·Ton/(2L) − i_neg]

满载附近的小信号参数：
- g = ∂I/∂Ton = 0.486 A/LSB；
- 电流源自身的电导 −∂I/∂Vo = 25 S，负载电导 250 S；
- 传递函数 Vo/Ton = g/(Co·s + 275 S)，极点在 9.4 kHz（Co = 4.672 mF）。

## 3. 控制器

每个周期在第 1 相开通时采一次 Vo（Ts = 232 ns，ADC 分辨率 0.5 mV），e = Vref − Vo：
- 积分：acc += ki·e，带限幅；
- 输出：Ton = round(acc + kp·e)，带限幅。

每相只在自己开通时才用新的 Ton，所以一条新指令要一个周期才传到全部四相。

**设计规则：**
- kp 决定穿越频率：在穿越频率高于对象极点时，P 单独作用的穿越频率 ωc = kp·g/Co；
- 积分零点放在 fc/5。

## 4. 验证

用现在的积分环复现 A100 的 ±62.5 A 阶跃：

| | 模型 | 仿真 |
|---|---|---|
| −62.5 A | +120.1 mV，19.2 µs | +121.9 mV，19.6 µs |
| +62.5 A | −127.1 mV，21.7 µs | −127.0 mV，21.9 µs |

## 5. 设计与预测

相位裕量按 0.75 个周期的延迟计算。

| 设计 | kp (ns/V) | ki (ns/V/采样) | 穿越频率，相位裕量 | ±62.5 A 偏移 | 回到 1% 以内 |
|---|---|---|---|---|---|
| 现在 | 0 | 0.25 | 7.5 kHz，51° | +120/−127 mV | 93/111 µs |
| 30 kHz | 56.7 | 0.50 | 29 kHz，94° | ±44-45 mV | 48/73 µs |
| 60 kHz | 113.3 | 1.98 | 60 kHz，84° | ±24-25 mV | 16/23 µs |
| 100 kHz | 188.9 | 5.51 | 101 kHz，78° | ±16 mV | 7/9 µs |
| 150 kHz | 283.3 | 12.40 | 153 kHz，73° | ±11 mV | 3 µs |

**量化：**
- 一个 Ton LSB 让 Vo 变化约 1.8 mV，而 ADC 一个 LSB 是 0.5 mV；
- 按 Peterchev-Sanders 的条件会出现几个 LSB 的抖动，模型给出 Ton 峰峰值 1-9 LSB，Vo 约 0.5 mV。

## 6. 模型没有包含的

- **串联电容的谐振。** 按 Roberts 式 3.44，N = 4、Cs = 3 µF、满载占空比时为 140、259、339 kHz。150 kHz 设计已经越过第一个谐振，由仿真来判断。
- **零电压开关时序校正器对 Ton 快速变化的反应。**
- **ADC 的滤波和延迟。**

| 30 kHz | +44.0/−45.3 / +46.2/−47.1 | 47.9/73.0 / 51.1/76.5 |

**偏移误差在 7% 以内**，模型总是略小于仿真。**恢复时间误差为 4-21%**。

**串联电容的谐振（140 kHz）在 153 kHz 的设计里也没有显现：**
- 150 kHz 那档同样稳定，同样贴近模型；
- 说明至少到 153 kHz，略去它不改变结论；耦合的强弱本身没有单独测量。

**量化抖动与预期一致：**
- Ton 峰峰值：现在 2 LSB，60 kHz 3，100 kHz 7，150 kHz 9；
- 带宽越高，轻载时第 2-4 相关断电流的分散越大：0.24 → 0.27-0.36 A。

**判定：**
- 推荐 100 kHz：阶跃 ±1.7%（现在 ±12%），10 µs 内恢复；
- 选哪一档是速度和零电压开关裕量之间的权衡，留给评估。
