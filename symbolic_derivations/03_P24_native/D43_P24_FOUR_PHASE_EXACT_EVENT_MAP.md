# D43：P24四相精确事件映射——与物理模型的独立交叉验证

2026-09-30。先写计划与边界，再写代码与运行；结果追加在后文。

## 1. 为什么需要

物理模型（Track A的A73–A81）在P24单模块上得到了以下结论：
- 负电流目标取5%时，第4相存在"软开通"与"重启"两种稳态，走哪条由过渡过程决定（A79，A80复现）；
- 取7.5%时，两种环路增益都只落在软开通稳态；
- P24所写的1–2%不够（A78）。

这些都来自同一个数值方法：10 ps固定步长梯形法、开关用小电阻表示、事件用线性插值定位。
按项目规则，每个新的主要结论都要在另一个模型、相同参数下交叉验证。
"两条周期轨道是否并存、各自是否稳定、重启轨道在哪里消失"又是结构性问题，正是数学模型该回答的。

现有数学模型（D02–D42）写死为P25三相（nP = 3），不能直接用。所以新建P24原生四相模型。

## 2. 与物理模型的独立性

| | 物理模型（A73–A81） | D43数学模型 |
|---|---|---|
| 开关 | 导通为0.1 µΩ电阻，二极管按步检查方向 | 理想开关：导通即两端节点合并（Vds = 0） |
| 硬开通 | 电阻在一步内放电 | 按电荷守恒瞬时重新分配（不经电阻） |
| 积分 | 10 ps梯形法（拓扑变化后2步后向欧拉） | 分段线性系统用增广矩阵指数精确积分 |
| 事件 | 相邻两步线性插值 | 在精确解上求根（0.25 ns网格括根，再用Brent细化） |
| 二极管关断 | 每步检查电流方向 | 由KCL写出器件电流的线性函数，在精确解上求其过零 |
| 方程组织 | 全节点矩阵 + 导通电导 | 按导通器件合并节点后，在"节点组"坐标下列方程 |

两者只共享电路元件及其取值、拓扑和控制规则。数值方法和开关的数学表示都不同。

## 3. 电路（与A79/A80参考运行一致）

P24单模块，N = 4：
- Vin 48 V；L 1.4666667 nH，每相串联0.54 mΩ；
- Cs 3 µF；Co 4.672 mF；负载4 mΩ；
- 高侧Coss 3.72 nF，低侧5.58 nF（线性）。

节点：a1–a3、x1–x4、out；固定节点vin、地。器件：
- SH1为vin–a1，SHk为a(k−1)–ak（k = 2, 3），SH4为a3–x4；
- SLk为xk–地；
- Csk为ak–xk；Lk为xk–out。

## 4. 控制器（与物理模型已采用的规则对齐）

- **第1相：**电流降到目标值即关断低侧。对应物理模型"比较器自动校准后，边沿电流等于目标"的情形。
- **第2–4相：**在 t_ref + (k−1)·T0/4 定时关断低侧。
- **高侧开通：**低侧关断后固定延迟 d_k 开通。d_k 取物理模型收敛后的 dt_pred；若该相处于重启状态，d_k = 20 ns。
  物理模型的逐周期修正是一个慢速外环，不属于快速周期轨道本身。所以周期轨道在固定的 d_k 下求，修正规则的自洽性单独检查（第5节）。
- **高侧关断：**开通后 Ton。Ton 取物理模型闭环收敛后的值，这里作为常数，电压环同样是慢速外环。
- **低侧开通：**节点降到地电位时二极管先导通；10 ns 后沟道开通，与物理模型的比较器到门极延迟对齐。
- **周期截面：**第1相高侧开通时刻。自由坐标只有8个：x1、a2、a3、out 和 i1–i4。其余由拓扑确定：a1 = Vin，x2 = x3 = x4 = 0。

## 5. 要回答的问题

1. **交叉验证。**在A79第3次运行的参数下（7.5%，Ton 18.034 ns，d_k取该运行收敛后的值），数学模型的周期轨道与物理模型稳态是否一致？比较周期、Vo、截面电流和各相开通电压。
2. **5%目标下两条轨道是否并存。**
   - 软开通轨道：d_4 取物理模型软稳态的值。第4相低侧关断时电流应为负，节点应谐振，谷底时刻应与 d_4 一致。
   - 重启轨道：d_4 = 20 ns。第4相关断时电流应为正（不谐振）。这正是物理模型中修正规则停在20 ns的原因。
   - 每条轨道都用牛顿法求不动点，再由截面映射雅可比的特征值判断稳定性。
3. **重启轨道在哪里消失。**把负电流目标从4%扫到8%，看重启轨道上第4相关断电流何时变负。电流一旦变负，节点就会谐振，修正规则就不会再停在20 ns。

## 6. 判定 / 不判定

**判定：**
- 物理模型在P24上的稳态能否用独立方法复现；
- 5%下两条轨道是否并存；
- 两条轨道各自的稳定性；
- 重启轨道失去自洽的负电流目标位置。

**不判定：**
- 逐周期修正规则与电压环作为慢速外环的动态；
- 非线性Coss与寄生参数；
- 多模块并联。

## 8. 结果

### 8.1 交叉验证

d_k 与 Ton 取物理模型收敛值；物理模型的数据为最后20个周期。

| 参考点 | 周期（精确 / 物理） | 第4相关断电流 | 四相开通电压（精确 / 物理） | \|μ\|max |
|---|---|---|---|---:|
| A79 r1：5%，软开通 | 230.24 / 230.11 ns | −5.08 / −5.09 A | 8.857, 8.851, 8.851, 9.244 / 8.86, 8.85, 8.85, 9.24 V | 0.9860 |
| A79 r2：5%，第4相重启 | 232.58 / 232.67 ns | −0.68 / −0.63 A | 8.987, 8.971, 8.971, 11.975 / 8.98, 8.96, 8.96, 11.97 V | 0.9858 |
| A79 r3：7.5% | 238.79 / 238.28 ns | −8.66 / −8.43 A | 7.958, 7.821, 7.786, 7.885 / 7.91, 7.90, 7.87, 7.99 V | 0.9856 |

- **独立数值方法复现了物理模型的三个稳态。**开通电压相差约0.01–0.1 V，周期相差不超过0.2%。
- **三条轨道都稳定。**最慢的模态每周期衰减约1.4%，对应飞跨电容与输出电容的慢过程。
- **5%下"软开通"与"第4相重启"是两条不同、各自稳定的周期轨道。**
- **自洽性：**7.5%时第1–3相的自然谷底在低侧关断后7.85–7.95 ns，第4相在6.59 ns。物理模型收敛的延迟比谷底晚0.3–0.45 ns，谷底平坦（电压差<0.01 V）。

### 8.2 负电流目标扫描

条件：Vo = 1 V（Ton自动求），软开通相的 d_k 等于其自然谷底时刻。

| 目标 | 软开通轨道 | 重启轨道（d_4 = 20 ns） | 重启轨道上第4相的自然谷底 |
|---|---|---|---|
| 1.0% | 30 ns重启下仍无自洽解，第4相谷底退到33 ns | 存在（+7.97 A） | 23.0 ns（晚于20 ns） |
| 1.5% | 同上（32.4 ns） | 存在（+7.57 A） | 22.4 ns（晚） |
| 2.0% | 30 ns重启下不自洽（d_4 漂到23.5 ns，第4相 +9.2 A） | 存在（+6.78 A） | 21.3 ns（晚） |
| 2.5% | 存在（30 ns重启下）：第4相 −1.36 A，10.34 V | 存在（+3.88 A） | 17.0 ns（早于20 ns） |
| 3.0–5.0% | 存在且稳定：第4相 −2.34 → −5.17 A，10.11 → 9.20 V | 存在：+2.03 → −0.80 A | 14.3 → 10.2 ns（早） |
| 5.5–9.0% | 存在且稳定：第4相 −5.83 → −10.39 A，8.96 → 7.25 V | 不存在（牛顿法无解） | — |

**逃逸测试：**在3%–5%，从每一条重启轨道出发，让第4相延迟也跟随它的自然谷底。结果全部回到软开通轨道，截面坐标差 ≤ 4×10⁻⁴。

### 8.3 结论

1. **结构确认。**物理模型在5%看到的两种稳态，是精确事件映射的两条稳定周期轨道。
2. **机理。**在3%–5%，重启轨道上第4相的自然谷底出现在20 ns重启之前（10–14 ns）。重启状态之所以能保持，是因为物理模型的修正规则只在"预测开通"时学习：dt_pred 一旦在过渡中涨过20 ns，每次都被重启抢先，修正就被锁死了。这是修正规则的设计缺陷，不是电路本身有两个工作点。
3. **对A78的修正（待A82物理验证）。**"P24的1–2%不够"仍成立：在≤2%，第4相关断时电流为正，谷底晚于任何固定的重启时间，而且开通越晚它的电流越高、谷底越晚，是自我强化的。但门槛在2%–2.5%之间，而不是A78所说的4%–5%。A78在3–4%看到的重启，是上述锁死。
4. **可检验的预测。**让修正规则在重启开通时也学习（节点已越过谷底，按"滞后"规则取观测谷底时刻）后，物理模型在3%–5%应当只剩软开通；在2%应当仍然重启或处于晚谷底。

## 9. 限制

- **只比较了单周期映射的周期轨道。**逐周期修正规则与电压环作为慢速外环，只在"自洽"这一层面检查（d_k 等于谷底、Vo = 1 V），没有模拟外环的动态。
- **电路是理想化的。**开关导通为理想节点合并，二极管为理想无压降，Coss线性，无寄生；与物理模型一致，所以这是数值方法与开关表示上的独立，而不是器件模型上的独立。
- **"无解"指牛顿法从上一个目标的解出发不收敛**（逐步延拓），不是全局不存在的证明。
- **2%这一点只到"不自洽"**（12次外迭代内 d_4 仍在漂移），1–1.5%为明确的重启。

## 10. 物理模型验证（A82，2026-09-30）

第8.3节第4条的预测，在物理模型中逐项成立（A82，修正规则在重启开通时也学习）：

- **5%（增益1.0，原为重启状态）、4%、3%：**全部软开通，满足单模块标准第2条。
- **定量对比（物理 / 精确）：**第4相延迟相差≤0.16 ns，关断电流≤0.2 A，开通电压≤0.05 V。
- **2%：**仍然重启（关断电流 +6.82 / +6.78 A），dt_pred 涨到上限34.8 ns。
- **2.5%：**平均意义上软开通，但不周期（抖动3.4 A），与门槛2%–2.5%一致。
- **对照（3%，不学习）：**锁死在重启状态（+2.18 / +2.03 A）。

至此，这条"数学模型推物理模型"的交叉验证闭环：
- 双稳是修正规则的锁死；
- P24的1–2%在两个模型中都不够；
- 修正后的下限是3%。
