# D48：结温125 °C下的P24事件映射——A90的数学模型交叉验证

2026-09-30。先写计划与边界，再写代码与运行；结果追加在后文。

## 1. 为什么需要

A90（物理模型）把已采用的P24单模块放到结温125 °C。三项参数的来源与核对见A90 BOUNDARY第2节：
- **导通电阻**乘以1.586：数据手册Fig. 9，与EPC模型相差≤0.25%；
- **反向导通**改用Fig. 8的125 °C曲线：Vf 1.9483 V、每器件R 8.948 mΩ；
- **Coss**不变：没有公开的温度数据。

按项目规则，要在数学模型中、相同参数下交叉验证。

## 2. 方法

用D47的事件映射（`p24_lowpred_event_map`，数据手册Coss(V)、反向压降、定时低侧），只改参数：
- 每相R = 0.54 mΩ × 1.5858 = 0.8563 mΩ；
- Vf = 1.9483 V，每器件R = 8.948 mΩ。

新脚本 `scripts/audit_p24_hot_orbits.py` 复制D47的求解函数，并把电路与压降参数作为输入。D47的库与脚本都不改。

**自洽条件与D47相同：**
- Vo = 1 V（由Ton调节）；
- 高侧延迟 = 自然谷底；
- 低侧死区 = 自然过零 + 1 ps（用探测测量）。

**种子：**D47在同一目标的轨道。

## 3. 运行

1. **周期轨道：**3%、2%、5%、7.5%，对照A90第1–4次运行。
2. **免费窗口：**在3%的轨道上，把低侧开通推迟到过零后 δ = 0.10–0.26 ns（步长0.01 ns），记录每相第一次出现反向导通能量的δ。25 °C（D47的轨道与参数）与125 °C各做一次，同口径比较。

## 4. 预测（运行前写下，同A90第5节）

- **与25 °C相比：**
  - Ton增加约0.3–0.5 ns；
  - 第4相电流与开通电压基本不变；
  - 反向导通为0。
- **免费窗口随Vf（2.09 → 1.95 V）等比例缩小：**第4相约0.15 ns，第1–3相约0.21 ns。

## 5. 判定 / 不判定

**判定：**
- A90的结论在数学模型中是否成立；
- 高温下定时窗口的宽度。

**不判定：**
- 温度梯度与热网络（下一层）；
- Coss的温度依赖（无公开数据）；
- 动态导通电阻。

## 7. 实现与检查（在写完第1–5节之后）

**代码：**`scripts/audit_p24_hot_orbits.py`。它复制D47的求解函数，并把电路与压降参数作为输入；还导入D47脚本的过零探测与余量常数。D47的库与脚本未改。

**过程中的问题：2%的收敛判据。**
- 第一次求2%时，外层迭代正常收敛（误差0.096 → 0.026 → 0.003 ns，Vo → 0.99995）。
- 第4轮的牛顿残差停在4.1×10⁻⁷：线搜索降不下去，提前结束。
- 默认的接受门槛是1×10⁻⁷，所以被判为"无轨道"。这是该边缘点映射的数值噪声底，不是轨道不存在；4×10⁻⁷ V/A在物理上可忽略。
- **处理：**加`--tol`选项，2%用1×10⁻⁷重求（接受到1×10⁻⁶），结果中记录`newton_tol`。3%、5%、7.5%用默认的1×10⁻⁸。

## 9. 结论

1. **A90的结论在数学模型中独立成立。**结温125 °C下，P24在2–7.5%仍全部软开通，轨道稳定，反向导通为0。
2. **温度主要通过导通电阻起作用：**导通损耗乘以约1.59，工作点只有很小的移动。
3. **定时低侧的窗口在高温下略窄**，仍远宽于Verilog延迟线的31 ps分辨率。
