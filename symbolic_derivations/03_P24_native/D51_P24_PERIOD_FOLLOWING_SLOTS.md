# D51：跟随周期的相位时隙——A93的数学模型

2026-10-01。计划写在A93运行之前，结果追加在后文。

## 1. 为什么需要

**问题的来历：**
- D43–D50的映射与A80以来的RTL一样，相2–4的低侧关断放在相1开通之后的固定时隙 k·T0/4，T0 = 200 ns。
- 论文基线规定的相移是 T/nP，T是开关周期（P24 Sec. II-B；P25 Figs. 1–2）。
- 稳态周期约232 ns，所以固定时隙（50/100/150 ns）其实也不是T/4（58/116/174 ns）。
- A92的m3n里，周期短到141 ns时，相4的150 ns时隙一直被推迟，低侧导通了969 ns。

A93在RTL里加入跟随周期的时隙。这里在映射里做对应的稳态。

## 2. 方法

**映射与工作点：**
- D47的映射（数据手册Coss(V)、反向压降、定时低侧），25 °C，5%；
- 采用A92误差型修正器的定点（D50）：低侧在过零 + 94 ps，高侧在谷底 + 94 ps，m = 0。

**时隙改为 k·T/4。** T是轨道本身的周期，也就是映射的时隙基准t0。外迭代令 t0 = 上一次轨道的周期。

**收敛判据：**
- Vo = 1 V（|ΔVo| < 1e-6 V）；
- 所有延迟与t0都自洽，偏差 < 2 ps。

**实现：** 新脚本 `scripts/audit_p24_followslot_orbits.py`，以D50的m = 0轨道为初值。D47–D50的脚本不改。

**对照：** 同一定点、固定时隙的轨道就是D50 m = 0。两者之差就是"时隙规则"这一个因素的影响。

## 3. 预测

**依据：** A74用旧plant比较过两种时隙。周期与Vo的变化很小（≤ 0.023 ns，≤ 0.45 mV），VCs3略有移动。

**预测：**
- 仍是软开通；
- Ton与周期的变化 < 0.1 ns；
- 相4关断电流的变化 < 0.5 A；
- 飞跨电容电压可能移动约0.1 V。

## 4. 判定 / 不判定

**判定：**
- 跟随周期的时隙对稳态的影响；
- 与A93 n0_both的对照。

**不判定：**
- 瞬态（相4饿死与否）。这个问题只能由A93的协同仿真回答。

## 5. 结果（数学模型，5%，25 °C，m = 0，e* = 93.75 ps）

**收敛：**
- 第3次外迭代收敛；
- 自洽残差0.6 ps（包括 t0 与周期之差）；
- Vo误差7.5e-7 V；
- Newton容差1e-7（同D50 m = 0）。

**结论：时隙规则对稳态几乎没有影响。** 所有量的变化都在第3节预测的范围之内，而且比预测小得多。

**解释（与A74的观察一致；未单独检验）：**
- 每一相的周期都以它自己的低侧关断为起点，整个波形随时隙一起平移；
- 各相之间只通过输出电容（4.67 mF）和飞跨电容的电荷平衡耦合，而这种平衡与时隙的位置无关。

所以A93改时隙只影响瞬态（相4会不会饿死），不改变稳态。这一点交给A93的协同仿真确认。

**结论：**
- 两个模型的差，与固定时隙时（A92对D50）同一量级。时隙之差就是周期之差的k/4。
- **稳态轨道一致。**
- A93中升高的dither（RESULTS第3节）是轨道附近逐周期动态的变化。D51只求定点，不包含这一部分。
- 要定量解释，需要把时隙对上一周期周期长度的依赖并入闭环雅可比矩阵。这与D50第8.3节提出的闭环修正器模型是同一项工作。
