# D46：带反向导通压降的P24事件映射——A87的数学模型交叉验证

2026-09-30。先写计划与边界，再写代码与运行；结果追加在后文。

## 1. 为什么需要

A87（物理模型）在A86的基础上加入EPC2067的反向导通压降。器件参数取自数据手册Fig. 8（A57数字化，并与EPC公开的SPICE模型核对，25 °C下差≤12 mV）。

按项目规则，新的主要结论要在另一个模型中、相同参数下交叉验证。D45（非线性Coss事件映射）的二极管是理想的：导通即两端节点合并，0 V。所以需要在D45上加入压降。

## 2. 方法

新建 `src/scb_ivr/p24_drop_event_map.py`，继承D45，D43/D45的文件不改。

**器件模型**与A87相同：只靠反向通道导通的器件满足 I_SD = n (V_SD − Vf) / R。
- 每器件 Vf = 2.0894 V，R = 6.013 mΩ（Fig. 8，25 °C，10–100 A拟合）；
- 高侧 n = 2，低侧 n = 3。

**相对D45的改动：**

| | D45 | D46 |
|---|---|---|
| 反向导通的器件 | 两端节点合并（0 V） | 不合并；在节点方程中加电导 n/R 与恒定项 n Vf / R |
| 反向导通开始 | V_DS下穿0 | V_DS下穿 −Vf |
| 反向导通结束 | 由KCL算出的器件电流过零 | I_SD = n (−V_DS − Vf)/R 过零（显式） |
| 沟道带反向电流关断时 | 二极管立即接管 | 节点先移动到 −Vf，由上一行的事件接管 |
| 周期状态机 | D43的`run_cycle` | 同一状态机，拓扑由（沟道集合，二极管集合）两部分决定 |

**反向导通能量：**在稠密输出上对 V_SD·I_SD 求积分（每段取50 ps以下的采样，辛普森法）。

## 3. 验证（在任何结果之前）

1. **Vf、R → 0的极限：**用一个很小的Vf与R，结果应接近D45（理想二极管）。
2. **单一反向导通过程：**节点稳定在 −(Vf + R I/n)，与A87的同一检查一致。
3. **物理模型的门控对照：**A87第0次运行（关闭压降）等于A86第3次运行；D45在3%已与之一致。

## 4. 运行

在A87的对应参数下（10 ns延迟），求调节后、谷底自洽的周期轨道：3%、2%、5%、7.5%，以及3%在2 ns延迟下的情形。比较：
- 周期、Ton；
- 第4相关断电流、各相开通电压；
- 反向导通时间与能量。

## 5. 判定 / 不判定

**判定：**A87的结论在数学模型中是否成立：
- 压降对轨道的影响（Ton、第4相电流）；
- 反向导通损耗的大小。

**不判定：**
- 逐周期修正与电压环的外环动态；
- 温度、负关断栅压；
- 封装与PCB寄生。

## 7. 实现与检查（在写完第1–5节之后）

**代码：**
- `src/scb_ivr/p24_drop_event_map.py`：新模块，D43/D45的文件未改。
- `scripts/audit_p24_drop_orbits.py`：每个目标一个进程。种子为D45在同一目标的轨道，Ton加2 ns。

**测试**（`tests/test_p24_drop_event_map.py`，2项）：
1. Vf = 0.01 V、R = 0.1 mΩ时，一个周期后与D45（理想二极管）相差≤2×10⁻³，每相各有一次比较器判定与一次反向导通开始。
2. SL4反向导通160 A时，节点在 −(Vf + R·160/3) 处平衡，器件电流为 −160 A。

**过程中的修正：事件定位的"抖振"。**
- **现象：**第一次求轨道时，第4相低侧在同一时刻反复"开始导通—结束导通"，超过50次后报错；牛顿法把这些报错当作失败步，所以5个目标都没有收敛。
- **原因：**
  - Brent求得的"开始导通"时刻，比函数真正越过 −Vf 的时刻早约2×10⁻¹⁹ s，状态停在阈值上方3×10⁻⁹ V；
  - 二极管电导为500 S，这3 nV读成 +1.5 µA的"正向"电流，立即触发"结束导通"；
  - 结束后节点仍在阈值上方，又触发"开始导通"，如此循环。
- **更正：**事件时刻取函数已真正越过（f ≤ 0）的第一个时刻。若Brent的估计还没越过，就在它与网格点之间二分。这与电平触发的语义一致。
- **影响范围：**修改只在D46的类中；D45的扫描函数不变。
- **结果：**修正后映射光滑，i2方向的有限差分雅可比在步长10⁻⁴、10⁻³、10⁻²下一致（−0.5080、−0.5081、−0.5082）。修正前的单周期试算（约54 W）作废。

- 数据手册Coss(V)；

- 低侧在比较器判定后 t_d 开通。

## 9. 结论

1. **A87的结论在数学模型中独立成立。**加入数据手册的反向压降后，P24在2–7.5%仍然全部软开通，而且轨道稳定。
2. **反向导通损耗约56 W，由10 ns的比较器到栅极延迟决定。**延迟为2 ns时是10 W；两个模型给出的数值相同。
3. **下一步：**在这一层，下一步是控制器的低侧开通时序（预测式或自适应死区），不再是器件参数。
