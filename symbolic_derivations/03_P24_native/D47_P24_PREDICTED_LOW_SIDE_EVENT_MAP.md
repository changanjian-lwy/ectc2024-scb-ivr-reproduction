# D47：预测式低侧开通的P24事件映射——A88的数学模型交叉验证

2026-09-30。先写计划与边界，再写代码与运行；结果追加在后文。

## 1. 为什么需要

A88（物理模型）把低侧开通从"比较器 + 10 ns延迟"改为定时边沿：开通时刻 = 高侧关断时刻 + 死区dtl。dtl由逐周期修正学到节点过零的时刻。依据是P25、Zhang等（TPEL 2023）与LMG1210的做法，见A88 BOUNDARY第2节。

按项目规则，新结论要在数学模型中、相同参数下交叉验证。

## 2. 方法

新建 `src/scb_ivr/p24_lowpred_event_map.py`，继承D46（数据手册Coss(V) + 反向压降），D43/D45/D46的文件不改。

**改动（只有低侧开通时刻）：**
- 第k相低侧在 t_off,k + d_low,k 开通，这是定时事件；
- V_DS = 0的比较器只记录过零时刻，不再触发开通。

**自洽条件：**d_low,k = 自然过零时刻 + 1 ps。
- 物理模型的修正器收敛到过零时刻，并在0.05 ns内抖动。数学模型取过零之后1 ps开通，保证先记录到过零。
- 1 ps内节点只下降约12 mV，远不到 −Vf，所以不产生反向导通。

**迭代：**与高侧的谷底自洽一起迭代，同时由Ton把Vo调到1 V。
- 若开通早于过零（没有测到过零），d_low加0.2 ns后重求。

**控制参数：**`ControlLP`是D43中`Control`的子类，多一个d_low字段。

## 3. 验证

- **d_low取得很大（晚于过零）时，低侧开通前会反向导通：**这一段应与D46相同的机理一致（D46在比较器判定后t_d开通）。
- **轨道的自洽与稳定性**，用Floquet乘子判断。

## 4. 运行

在A88的对应参数下求调节后、谷底自洽且过零自洽的周期轨道：3%、2%、5%、7.5%。

**对照A88第1–4次运行：**
- Ton、周期；
- 第4相关断电流、开通电压；
- d_low与A88的dtl；
- P_rev。

## 5. 判定 / 不判定

**判定：**A88的结论在数学模型中是否成立：
- 反向导通损耗是否消失；
- 软开通是否保持；
- 死区的数值。

**不判定：**
- 修正器与电压环的外环动态（自洽不动点层面）；
- 门极驱动的动态；
- 动态阈值；
- 温度；
- 封装与PCB寄生。

## 7. 实现与检查（在写完第1–5节之后）

**代码：**
- `src/scb_ivr/p24_lowpred_event_map.py`：用脚本从D46复制周期函数，只替换两处：低侧开通时刻；过零时刻与开通电压的记录。D46的文件未改。
- `scripts/audit_p24_lowpred_orbits.py`：每个目标一个进程。

**测试**（`tests/test_p24_lowpred_event_map.py`，2项）：
1. **d_low = 3 ns（晚于过零）：**每相都记录到过零；开通时节点低于 −Vf，有反向导通能量。
2. **d_low = 0.3 ns（早于过零）：**没有过零记录；开通时V_DS > 0，没有反向导通。

**单周期检查**（3%，D45的轨道，d_low取三种值）：

| d_low | 结果 |
|---|---|
| 0.8 ns | 早：2.1–3.7 V硬开通 |
| 1.2 ns | 第1–3相刚过零后开通；第4相已过零0.2 ns，反向导通0.014 µJ |
| 3.0 ns | 每相反向导通约1.8 ns，约0.5 µJ |

过零时间：第1–3相1.17–1.19 ns，第4相0.97 ns。

**过程中的修正：迭代规则。**
- **原规则：**"未测到过零则d_low加0.2 ns"。它在3%与2%陷入两状态循环：
  - 第4相死区设为"过零 + 1 ps"后，这一相不再反向导通，下一轮的工作点随之略变；
  - 过零时刻推后超过1 ps，被判为"早"，于是加0.2 ns；加完又变回"晚"。
- **改为探测：**与谷底相同，用探测测自然过零（该相低侧推迟到5 ns，其余不变）。过零发生在该相开通之前，所以探测不改变过零本身。
- **结果：**d_low = 过零 + 1 ps成为光滑的不动点，每轮误差约缩小为1/7（例如0.0022 → 0.0003 ns）。
- 旧规则下已收敛的5%与7.5%，也用新规则重算。

## 9. 结论

1. **A88的结论在数学模型中独立成立。**定时的低侧开通（死区 = 过零时刻）让反向导通损耗为零，所有目标都是软开通，轨道稳定。
2. **结果与理想二极管相同。**数据手册的反向压降在这种时序下不起作用：氮化镓约2.1 V的反向导通阈值，在过零之后留出0.16–0.22 ns的时间窗口。
3. **这个窗口是实现层面的要求：**死区控制的抖动必须留在窗口内。Verilog控制器的31 ps延迟线分辨率远在窗口之内。
