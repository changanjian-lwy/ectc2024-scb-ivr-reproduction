# D58：P24 模块启动与输出电压环的平均模型（A103 的数学模型）

2026-10-02。代码 `src/scb_ivr/p24_startup_averaged.py`，运行 `scripts/p24_startup_averaged.py`，记录
`diagnostics/D58_startup_averaged.json`，测试 `tests/test_p24_startup_averaged.py`（3个）。

**工作顺序：** 先于 A103 的任何运行，与 A103 BOUNDARY 一同提交。

## 1. 问题

采用设计的启动过程：
- Vo 在交接时（88.6 µs）冲到 1.277 V，随后跌到 0.903 V，约 170 µs 才稳住；
- VRD 11.1 要求过冲不超过 50 mV、在目标之上不超过 25 µs，现状不满足。

要回答两件事：原因是什么？只改启动时序能不能解决？

## 2. 模型

状态只有两个：输出电容 Co（4.672 mF）上的 Vo，以及电压环的 Ton 累加器。

**模式 S（固定时序，开环，Ton = Ton_s）：** 相当于一个电压源 a_s·Ton·Vin(t)/48，内阻 r_s。
- a_s = 1.2761 V / 533 LSB，取自参考仿真空载、48 V 时的模式 S 输出；
- r_s = 1.47 mΩ，取自 A73 run 6 带 4 mΩ 负载时的 0.933 V。那是旧版电路模型，所以这一项只是近似。

**模式 P（临界导通，负电流目标固定）：** 每相电流从 −i_neg 线性升到峰值，再降回 −i_neg，是一个三角波，所以平均电流

  i_avg = (V_rail − Vo)·Ton/(2L) − i_neg

与周期无关。整个模块输出 k·4·i_avg，相当于**由 Ton 控制的电流源**。
- k = 1.036：用参考满载稳态（568 LSB、1.000 V、250 A）标定；
- 周期 = Ton·(1 + (V_rail − Vo)/Vo) + t_x，t_x 用同一稳态（232.2 ns）标定。

**电压环（A79，只在模式 P 下工作）：**
- 每个第 1 相周期做一次 Ton_acc += 8 LSB/V × (Vref − Vo)；
- Ton 限制在配置值的 0.5–2 倍之间。

**负载：** 从 t_load 起接入，阻性。

## 3. 验证（参考启动 vs A100 参考仿真）

| 时刻 | 模型 Vo / Ton | 仿真 Vo / Ton |
|---|---|---|
| 60 µs | 0.988 V / 533 | 1.014 V / 533 |
| 88 µs | 1.269 / 533 | 1.277 / 533 |
| 105 µs | 0.989 / 443 | 0.999 / 455 |
| 125 µs | 0.883 / 506 | 0.903 / 504 |
| 150 µs | 0.956 / 577 | 0.955 / 569 |
| 190 µs | 1.018 / 576 | 1.013 / 577 |

全程 Vo 误差不超过 0.03 V，Ton 误差不超过 15 LSB。

**说明它抓住了主要物理：**
- 交接后变换器像电流源，Co 经负载放电（Co·R = 18.7 µs）；
- 积分环把 Ton 从 533 先拉到 455，再拉回 586，最后回到 568。

## 4. 结论（运行前）

1. **过冲来自空载开环。** 输入到 48 V 时，模式 S 空载输出就是 1.277 V。
2. **下冲来自交接时同时接上 250 A 负载。** 积分器从 533 出发，又先往下走。
3. **模式 P 不能在轻载下工作。**
   - Ton 取下限（0.5 倍）时，仍输出约 100 A；
   - 所以"空载闭环软启动 → VR_READY → 再接负载"这条路，对现有控制器不可行；
   - 这属于轻载工作，不在当前层级。
4. **负载从一开始接上就好了：**
   - 开环只到约 0.93 V，交接只需补 0.04-0.10 V；
   - 峰值 1.011-1.018 V，在 VRD 的 50 mV 之内。
5. **剩下的是电压环自己的长尾：**
   - Vo 在 1 V 之上约 60 µs，超过 VRD 的 25 µs；
   - 交接后加预偏置参考斜坡，只能把峰值降到 2-9 mV，时间缩不短；
   - 这要靠电压环本身的设计（记分表 T6），不是启动时序的问题。

## 5. 与协同仿真交叉验证（A103，2026-10-02）

| c1 负载从 0 | 峰值 / 交接时 Vo / 进入 1% | 1.011 V / 0.932 V / 156 µs | 1.007 V / 0.968 V / 127 µs |
| c1b + 72 µs 交接 | 同上 | 1.018 / 0.898 / 146 | 1.008 / 0.954 / 107 |
| c1d + 启动 Ton 568 | 同上 | 1.013 / 0.957 / 125 | 1.013（在交接时）/ 1.013 / 74 |

**模式 P 和电压环这部分是准的**（c0 全程）。

c1d 在 1 V 之上只有 17.6 µs（第4节的约 60 µs 是对 c1、c1b 的预测）：它的过冲出现在交接时刻，来自开环电压，不是电压环的长尾，所以满足 VRD 的 25 µs。

**偏差在模式 S 带载：**
- r_s 借用了 A73 旧电路模型的 1.47 mΩ，c1 反推是 1.275 mΩ；
- 用 c1 重新拟合（事后）后，c1b 的峰值差 2 mV、在 1 V 之上的时间差 3 µs，c1d 交接时差 14 mV；
- 模式 S 不完全是线性电压源，精度约 ±15 mV。

**模型给出的条件：** 开环结束时 Vo = a_s·Ton·R/(R + r_s)，所以复位期间的负载要接近满载：

| 复位负载 | Ton 533 | Ton 568 |
|---|---|---|
| 100% | 0.968 V | 1.031 V |
| 75% | 1.030 V | 1.098 V |
| 50% | 1.101 V | 1.173 V |
| 25% | 1.182 V | 1.260 V |

负载更轻时，需要在模式 S 下也闭环，并加参考电压软启动（改 RTL）。
