# D53：栅极驱动抖动在闭环中的放大——A98的数学模型

2026-10-01。计划与预测写在A98 BOUNDARY第3–4节（任何代码之前）；本文是结果。A98运行之前，又根据本文的结果在BOUNDARY第5节登记了对每个A98运行的预测。

## 1. 为什么需要

A91以来，每个栅极边沿都加独立的高斯抖动σ。协同仿真里，抖动被放大得很明显（30 ps：相2–4关断电流标准差0.52–0.66 A；20–27%的高侧开通早于谷底）。

D50的标量修正器模型只给出约3%的早到。它假设谷底不动，而实际谷底每周期移动约0.1 ns（D50第8.3节）。

D52已经建立了带修正器的闭环线性化，但输入只有trim。本文为每个边沿加一个输入，回答抖动从哪里被放大。

## 2. 模型

### 2.1 抖动如何进入（依据bridge.py与RTL）

**抖动模型。** 每个被命令的边沿在 t_cmd + t_drv + m（仅低侧）+ δ 到达电路，δ ~ N(0, σ) 相互独立。

**抖动不累积。** RTL的每个边沿都从上一个**命令**时刻排定，所以电路看到的是相邻两个边沿抖动之差。周期n内（截面 = 相1的实际开通）：

| 量 | 有效值 |
|---|---|
| 相1高侧开通（周期末，以锁存器命令时刻为基准） | d_1 + η(n) − δ_loff,1 |
| 相1导通时间 | Ton + δ_hoff,1 − η(n−1) |
| 相1低侧开通 | dl_1 + δ_lon,1 − δ_hoff,1 |
| 相1关断（电流比较器） | 延迟δ等价于阈值偏移 u = −(Vo/L)·δ |
| 相k（k = 2..4）槽位，相对实际截面 | slot_k + δ_loff,k − η(n−1) |
| 相k高侧开通 | d_k + δ_hon,k − δ_loff,k |
| 相k导通时间 | Ton + δ_hoff,k − δ_hon,k |
| 相k低侧开通 | dl_k + δ_lon,k − δ_hoff,k |

**测量量里包含抖动：**
- 高侧误差 = 实际开通 − 谷底；
- 低侧误差 = 实际开通 − 过零；
- 时隙用的周期是命令开通之差：T(n) − η(n) + η(n−1)。

### 2.2 逐边沿核心映射

**改动：** `ControlLP` 增加每相导通时间偏移 `ton_offset` 和槽位偏移 `slot_offset`，默认为0。
- 加0.0不改变任何浮点数。
- **门控：**
  - `scripts/p24_orbits.py --gate`：13条存档轨道全部逐位一致；
  - D52重算：除墙钟时间外逐项一致。

**核心映射：** p = (s, d_1..4, dl_1..4, ton_1..4, slot_2..4, u)，共24个输入，用中心差分求导。

**与D52的一致性：**
- ton列之和、按 (k−1)/4 加权的slot列，与D52的ton列、t0列相差 ≤ 6e-5（相对）；
- 截面列完全相同。

### 2.3 两种计算

**1. 线性协方差。**
- 闭环线性化：修正器增益1/2，电压环，时隙规则的记忆，再加η(n−1)这个状态。
- 输入：每周期16个白噪声边沿抖动。
- 由离散Lyapunov方程求稳态协方差。
- 不含量化与早到规则。

**2. 蒙特卡洛：线性电路 + 精确控制器。**
- 电路用上述线性化映射。
- 控制器逐条按RTL实现：
  - 命令延迟为整数LSB（31.25 ps）；
  - 误差四舍五入到LSB；
  - d −= (err − 3) >>> 1，并钳位；
  - 早到（开通早于谷底/过零）：高侧 +6 LSB（0.2 ns），低侧 +2 LSB（0.05 ns）；
  - trim：按相1实际关断电流的符号 ±1；
  - 电压环用整数实现（ki = 262/2^16 LSB/码，ADC 0.5 mV）；
  - 时隙规则用整数实现。
- 每例20 000周期（预热3000周期）。

**统计口径与协同仿真一致：**
- 关断电流标准差；
- 早到比例；
- 不早到周期上的误差与谷底标准差；
- 周期标准差；
- 20截面窗口的dither。

**代码与记录：**
- `src/scb_ivr/p24_jitter.py`；
- `scripts/p24_jitter_modes.py`；
- `diagnostics/D53_jitter_5p0pct_m0p0.json`。

### 2.4 建模中发现并改正的一个错误

**错误。** 线性模型里，电压环积分器的更新 acc' = Ton 起初用了"有效"导通时间。它包含 −η(n−1) 这一抖动项，所以每次相1开通抖动都被积分器永久记住。

**表现。** 周期的脉冲响应停在约 −10 ns 不衰减；线性周期标准差1.95 ns，而蒙特卡洛为0.55 ns、协同仿真为0.59 ns。

**改正。** RTL中积分器存的是命令值，改为 acc' = 命令Ton。
- 改正后线性周期标准差为0.46 ns。
- 电流结果几乎不变（0.503 → 0.500 A）。
- 蒙特卡洛本来就是按命令值写的，不受影响。

这个错误在A98的预测登记之前就已发现并改正。

## 3. 结果

### 3.1 与存档协同仿真对照（A92固定 / A93跟随 / A97平均，最后200周期）

| 30 ps | 关断电流标准差，相2–4（A） | 高侧早到 | 高侧误差标准差（ns） | 周期标准差（ns） | dither（A） |
|---|---|---|---|---:|---:|
| 固定：D53 / A92 | 0.57 / 0.52–0.61 | 24% / 21–27% | 0.15 / 0.14–0.16 | 0.55 / 0.61 | 1.92 / 2.03 |
| 跟随：D53 / A93 | 0.68 / 0.82 / 0.96，对 0.71 / 0.76 / 0.99 | 28–35% / 29–37% | 0.17–0.21 / 0.15–0.20 | 0.54 / 0.57 | 2.48 / 2.39 |
| 平均：D53 / A97 | 0.59–0.65 / 0.56–0.66 | 25–26% / 23–26% | 0.15–0.16 / 0.14–0.16 | 0.55 / 0.59 | 2.03 / 1.95 |

**100 ps 与 0 ps：**
- 100 ps：电流、早到、周期、dither都在10–20%以内；谷底标准差高约40%（线性电路的极限）。
- 0 ps（确定性）：电流在10%以内；跟随规则的早到为0 / 16 / 50%，A93为7 / 21 / 34%。

### 3.2 线性协方差给出了大部分放大

平均规则，30 ps，相2–4：

| | 线性协方差 | 蒙特卡洛 | 协同仿真 |
|---|---|---|---|
| 关断电流标准差（A） | 0.52 / 0.54 / 0.57 | 0.59 / 0.62 / 0.65 | 0.62 / 0.56 / 0.66 |
| 高侧误差标准差（ns） | 0.17–0.19 | — | — |
| 谷底标准差（ns） | 0.14–0.15 | — | — |
| 周期标准差（ns） | 0.46 | 0.55 | 0.59 |

**读法：**
- 线性模型中，高侧误差均值约0.11 ns（修正器死区：误差3、4 LSB不更新）。按此算，约25%的开通早于谷底。
- 所以**早到规则不是放大的来源**。电路加修正器的线性闭环已经给出了大部分放大。
- 蒙特卡洛多出的部分来自量化和trim的砰砰。

### 3.3 机理

**1. 开环链条**（D51轨道处的雅可比）：
- **∂T/∂ton_1 = +10.5 ns/ns。**
  - 相1由电流比较器关断。导通时间的误差在陡的上升斜率（约11 V/1.47 nH）上改变峰值电流，再在缓的下降斜率（Vo/L = 0.68 A/ns）上换回时间。
  - 两斜率之比约为10.5。
- **∂i_off,k/∂slot_k = −0.68 A/ns**，即 −Vo/L；**∂valley_k/∂slot_k = −0.18 ns/ns**。
- 相2–4的槽位以相1开通为基准，因此继承了相1的周期误差。
- 相k的导通时间不在同一周期影响自己的关断电流，而是经由下一周期的状态起作用。

**2. 方差来源**（线性协方差，平均规则，30 ps，相4）：

| 来源 | 关断电流 | 谷底 |
|---|---:|---:|
| 相1导通边沿（η、hoff_1） | 60% | 60% |
| 相2–4导通边沿 | 37% | 37% |
| 低侧边沿 | 3% | 3% |

周期的方差100%来自相1的导通边沿。

**3. 第二条路径：trim。**
- 相1关断边沿的抖动让trim的 ±1 LSB 判决随机化。每一步改变阈值0.25 A，即周期约0.37 ns（∂T/∂u = −1.47 ns/A）。
- 只抖低侧边沿时，它是主要来源：

  | trim | 周期标准差 | 关断电流标准差 |
  |---|---:|---:|
  | 冻结 | 0.065 ns | 0.10 A |
  | 工作 | 0.29 ns | 0.25–0.28 A |

- 全部边沿都抖时，它只占约7%（30 ps），100 ps时可以忽略。

### 3.4 控制器方案（蒙特卡洛，平均规则）

| 方案 | 30 ps：电流标准差 / 早到 | 100 ps：电流标准差 / 早到 |
|---|---|---|
| 采用设计（步长6，增益1/2，目标3） | 0.59–0.65 A / 25–26% | 1.70–1.91 A / 46–49% |
| 早到步长2 LSB | 0.55–0.62 / **32–36%** | 1.66–1.89 / **63–66%** |
| 增益1/4 | 0.56–0.63 / **12–14%** | 1.67–1.88 / **32–35%** |
| 目标5 LSB | 0.57–0.64 / 17–19% | 1.70–1.91 / 43–46% |
| 目标5 + 增益1/4 | 0.55–0.62 / **8–10%** | 1.66–1.87 / 30–32% |

**结论：**
- **没有一种修正器设置能把电流波动减小7%以上。** 放大在电路里，修正器管不到。
- **大的早到步长其实在保护：** 它把开通推回谷底之后，减小步长反而更差。
- **增益1/4能把早到减半。** A98用协同仿真检验了它（第4节）。

## 4. 与A98交叉验证

**条件：**
- A98协同仿真，采用设计（平均槽位 + guard），5%，种子1，最后200周期；
- 预测带：蒙特卡洛40 000周期中200周期窗口的5–95%范围；
- 判据：电流标准差在中位数 ±20% 以内，早到在中位数 ±8 个百分点以内（BOUNDARY第5.3节）。

| 运行 | 电流标准差相对D53中位数（相2/3/4） | 早到 − 中位数（百分点） | 判定 |
|---|---|---|---|
| s10 | +18% / +8% / **+23%** | +4.5 / 0 / +5.0 | **超出** |
| s20 | +9% / −6% / +2% | +2.5 / 0 / +1.5 | 一致 |
| s50 | +4% / −11% / 0% | +1.0 / −1.5 / −0.5 | 一致 |
| h30（只抖高侧） | +11% / +14% / +16% | +1.5 / +3.5 / +2.5 | 一致 |
| l30（只抖低侧） | +18% / +18% / +10% | +4.0 / +2.5 / +1.0 | 一致 |
| g4_j30（增益1/4） | +3% / −5% / 0% | +0.5 / −1.5 / +1.5 | 一致 |
| g4_j100 | +2% / −6% / 0% | −3.0 / −2.5 / −1.5 | 一致 |

**结论：**
- **7个中6个一致。** s10的相4电流超出3个百分点。
- σ小时协同仿真普遍高于D53（+10%到+23%）。可能的原因是D53没有的测量噪声：协同仿真的谷底与过零取在10 ps的步长上，再量化到31.25 ps；D53中二者是精确值。此原因未单独检验。

**方差份额（30 ps）：**
- 只抖高侧（h30）给出全部边沿方差的122%（200周期的抽样误差约 ±20%）；
- 只抖低侧（l30）给出17%；
- D53预测为89%与14%。

**增益1/4的效果：**
- 预测的早到减半得到证实：30 ps从23–26%降到12–16%，100 ps从41–47%降到30–34%。
- 但反向导通损耗上升：30 ps从3 mW到11 mW，100 ps从89 mW到172 mW。
- 这比它省下的硬开通损耗（A91的估计：30 ps ≤ 0.13 mW；100 ps 30–102 → 12–39 mW）还多，因此**不采用**。
- D53没有计算损耗。早到比例这个指标不等于损耗：大多数"早于谷底"的开通离谷底很近，V_DS接近最小值。

## 5. 预测对照（A98 BOUNDARY第4节）

| 预测 | 结果 |
|---|---|
| 1. 线性协方差低估30 ps的波动和早到（至少一半）；早到规则是缺的部分 | **不成立。** 线性已给出0.52–0.57 A和约25%早到；谷底标准差在2倍以内（成立）。 |
| 2. 蒙特卡洛在30 ps重现协同仿真：电流 ±30%，早到 ±10 个百分点 | **成立**（10–15%以内，≤ 4 个百分点）。 |
| 3. 100 ps：电流为30 ps的2.5–3倍，早到35–50% | **成立**，在区间上沿：2.9–3.0倍；45–49%。 |
| 4. 导通边沿是谷底变化的主要来源 | **成立**：97%。 |

## 6. 判定 / 不判定 / 局限

**判定：**
- 抖动放大的来源是电路：相1的电流比较器关断（×10.5），经槽位传给相2–4（0.68 A/ns）；
- 修正器无法减小它；
- trim是次要路径。

**不判定：**
- 架构层面的手段，未检验：
  - 槽位改用滤波后的时间基准（Huber 2009的PLL方法）；
  - 相1改为定时关断；
  - 降低驱动器抖动。

**局限：**
- 电路线性化：100 ps时谷底标准差偏高40%。
- 抖动是理想化的高斯独立分布。
- 只有5%、m = 0。
- 不含损耗模型。
