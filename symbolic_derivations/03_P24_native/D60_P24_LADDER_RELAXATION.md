## 1. 问题

**Cs 的范围。** 串联电容 Cs 一直是一个范围：0.6-8.7 µF，第一性原理估计，见 `CFLY_FIRST_PRINCIPLES_ESTIMATE.md`。A104/A105 只算了 3 µF。

**担心的情形。** 按 Roberts 式 3.44，梯形的最低谐振频率与 1/√Cs 成正比：3 µF 时为 140 kHz，8.7 µF 时为 82 kHz。8.7 µF 时它会落到推荐的 100 kHz 电压环带宽以下。

**问题：** 这个谐振在 P24 的控制方式下存在吗？

## 2. 推导

**预测模式（临界导通，每个周期都从固定的负电流 −i_neg 开始）。** 电感电流在周期之间不是状态量，每个周期都会回到 −i_neg。第 k 相高侧在导通时间内流过的电荷：

  Q_k = Ton·(−i_neg + (V_rail,k − Vo)·Ton/(2L))，

其中 V_rail,1 = Vin − V1，V_rail,k = V_(k−1) − V_k，V_rail,N = V_(N−1)（V_k 是第 k 个串联电容的电压 a_k − x_k）。

**电容的充放电。** 第 k 相导通时电流从 a_k 流向 x_k，给 Cs_k 充电。第 k+1 相导通时第 k 相低侧导通，电流从 x_k 流向 a_k，给它放电。所以每个周期 T：

  Cs·dV_k/dt = (Q_k − Q_(k+1))/T。

**线性化。** 令 q' = Ton²/(2L)，D2 = tridiag(1, −2, 1)，则 dV/dt = (q'/(T·Cs))·D2·V。
- 特征值为 −(2 − 2cos(jπ/N))，j = 1…N−1，**全是负实数**；
- 所以梯形只做一阶回落，没有谐振；
- 时间常数 τ_j = T·Cs/(q'·(2 − 2cos(jπ/N)))，与 Cs 成正比。

| Cs | 时间常数（µs，慢→快） |
|---|---|
| 0.6 µF | 2.21，0.65，0.38 |
| 3 µF | 11.07，3.24，1.90 |
| 8.7 µF | 32.11，9.40，5.51 |

**输出电压不受梯形分配影响。** 四相电流之和 ∝ Σ(V_rail,k − Vo)·Ton = (Vin − N·Vo)·Ton，与电压如何在电容间分配无关。所以在平均模型里，梯形的回落不进入输出方程，D59 的环路结论与 Cs 无关。

**启动模式（固定时序）不同。** 那里是固定频率 PWM，电感电流是状态量，Roberts 的谐振成立。68.61 µs 的输入斜坡相对第一个谐振的裕量为：0.6 µF 时 71 倍，3 µF 时 32 倍，8.7 µF 时 19 倍（Roberts 用的是 30 倍）。

## 3. 用 A106（3 µF）验证

| 输入阶跃 | 梯形偏差峰值 D60 / 仿真 | 回到 1% 以内 D60 / 仿真 |
|---|---|---|
| −4.8 V，1 µs | 7.98% / 6.97% | 23.3 / 5.0 µs |
| +4.8 V，1 µs | 6.70% / 6.66% | 32.1 / 16.8 µs |
| −4.8 V，10 µs | 4.50% / 4.09% | 28.4 / 24.7 µs |
| +4.8 V，10 µs | 4.10% / 3.50% | 36.6 / 22.1 µs |

**确认的：**
- 仿真里梯形单调回落，没有振荡（A106 上升阶跃的轨迹）；
- 峰值吻合（±15%）。

**模型偏慢：**
- 最慢时间常数仿真拟合为 7.5 µs，D60 为 11.1 µs，约 1.5 倍；
- 推测：第 2-4 相按时序槽关断，谷底电流随各自的输入电压变化，等效 q' 更大；
- 未验证，也不在事后调整模型。

**不包含的：**
- 快速阶跃时 Vo 多出来的偏移（−18.5 对 −8.2 mV）：来自周期内效应，平均模型没有；
- 周期内的电容电压纹波 Q/Cs：0.6 µF 时约 1.8 V，让第 2-4 相的输入电压比第 1 相高。

## 4. A107 的预测

推荐设计 I2，Cs 取 0.6 和 8.7 µF：
- 梯形回落时间与 Cs 成正比（考虑模型偏慢约 1.5 倍）；
- 没有振荡，环路稳定；
- 负载阶跃与 3 µF 时相同（D59）。

## 5. 与协同仿真交叉验证（A107，2026-10-02）

**结构对：**
- Cs 取 0.6 和 8.7 µF 时，梯形偏差在输入阶跃后都单调回落，反弹不超过 0.11 个百分点，没有谐振；
- 负载阶跃与 Cs 无关（±12%）；
- 启动模式的预测也对：68.61 µs 的斜坡在 8.7 µF 时裕量只剩 19 倍，启动峰值电流从 170 A 升到 215 A。

**速率不对：**

| Cs | 仿真拟合（电容 1） | D60 最慢时间常数 |

| 0.6 µF | 1.9 µs | 2.2 µs |
| 3 µF | 7.5 µs | 11.1 µs |
| 8.7 µF | 5.7 µs | 32.1 µs |

- 仿真并不随 Cs 线性变慢，D60 缺了一个回复项；

- 0.6 µF 时，周期内纹波（约 1.8 V）让采样到的梯形偏差稳态就有 2.7%。D60 是逐周期平均，看不到这一点。
