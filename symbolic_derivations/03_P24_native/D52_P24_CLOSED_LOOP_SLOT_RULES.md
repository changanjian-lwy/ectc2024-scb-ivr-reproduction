# D52：带修正器的闭环逐周期线性化，三种时隙规则——A97的数学模型

2026-10-01。模型和预测写在A97 BOUNDARY第5节，在任何代码与运行之前。本文给出结果。

## 1. 为什么需要

D50第8.3节和D51第6节都留下同一件事：把修正器的状态并入映射的雅可比矩阵。

**原因：**
- A92中，高侧误差在0.19与0.03 ns之间两周期交替；
- A93的跟随时隙让这种交替随相序增大，dither超过1 A；
- 定点（D50、D51）不包含逐周期动态，所以解释不了这两个现象。

## 2. 模型

**映射：** D47的 `LowPredEventMap`。
- 数据手册Coss(V)；
- 反向压降：Vf = 2.089 V，每器件R = 6.01 mΩ；
- 定时低侧；
- 25 °C，5%（相1电流阈值 −6.25 A）。

**核心映射（一个周期，从截面即相1开通出发）：**

  p = (s, d, dl, Ton, t0, u) → q = (s', T, crossing_k, valley_k, i_off,k)

- s：截面自由变量（8个）；
- d、dl：各相高侧、低侧延迟；
- t0：时隙基准，相k在 (k−1)·t0/4 关断；
- u：相1电流阈值的偏移，即trim；
- valley_k：用 `nl_valley_after_lowoff` 求，与D50相同。

**闭环状态：** z = (s, d, dl, acc, 时隙记忆)。

**更新律与RTL一致，线性化，不计量化：**
- Ton = acc + ki·(Vref − Vo(s))，ki = 0.25 ns/V。ADC在相1开通时采样，4 ns后更新Ton，所以本周期就生效。
- d' = d − g·(d − valley − e)
- dl' = dl − g·(dl − crossing − e)
- g = 1/2，e = 93.75 ps
- acc' = Ton
- 三种时隙规则：
  - 固定：t0 = 200 ns；
  - 跟随：t0 = T(n−1)；
  - 平均：t0 = (T(n−1) + T(n−2))/2。

**工作点：**
- 固定：D50的m = 0轨道；
- fixed_at_T、跟随、平均：D51的m = 0轨道。周期为1的轨道上T_avg = T，所以这三种规则共用D51的轨道。
- fixed_at_T是同一轨道上t0固定为T* = 231.884 ns的规则，用作同等条件下的对照。

**数值方法：**
- 核心雅可比用中心差分。步长：截面1e-5（相对），时间1 ps，u为1 mA。
- 二阶项与一阶项之比最大2.9%（截面变量 i1）。
- 步长取 ×0.5 和 ×2 时，z = −1 的增益（电流、周期、高侧误差）变化 ≤ 3.9%。低侧误差约0.001 ns，处在噪声水平。
- 每个核心雅可比约1分钟（4进程）。

**输出：**
- 闭环特征值；
- 从u到各输出的频率响应 H(z) = C(zI − A)⁻¹B + D；
- 两周期分量 = |H(−1)| × 0.125 A。

**代码与记录：**
- `src/scb_ivr/p24_closed_loop.py`；
- `scripts/p24_closed_loop_modes.py --step-check`；
- `diagnostics/D52_closed_loop_5p0pct_m0p0.json`。

### 3.1 闭环特征值（按模排序）

| 规则 | 慢模态 | 两周期模态（负实部） | 修正器模态 | 记忆带来的模态 |
|---|---|---|---|---|
| 固定（D50） | 0.993 ± 0.011j，0.967，0.842 ± 0.055j，0.824 ± 0.123j，0.763 | **−0.662 ± 0.014j，−0.650** | 0.498–0.500（5个） | — |
| fixed_at_T（D51） | 同上（差 < 0.001） | −0.663 ± 0.013j，−0.650 | 0.498–0.500 | — |
| 跟随 | 同上 | −0.663 ± 0.014j，−0.655 | 0.498–0.501 | 0.020（一对） |
| 平均 | 同上 | −0.663 ± 0.013j，−0.648 | 0.498–0.501 | 0.085，0.049（一对） |

**读法：**
- 三种规则的模态几乎相同。时隙记忆只带来很快的模态（≤ 0.085）。
- 两周期模态的模是0.65–0.66，阻尼中等，不是"轻阻尼"。
- 修正器模态在0.5，即 1 − g。

**平均规则与fixed_at_T在4位有效数字上相同。**
- 平均规则的时隙记忆以 (z⁻¹ + z⁻²)/2 = z⁻¹(1 + z⁻¹)/2 进入，在 z = −1 处为0。
- 所以同一轨道上，它在两周期频率的响应与固定时隙完全相同。
- 这是模型结构的性质；数值结果与之一致。

## 4. 机理：跟随规则加的是一条注入路径，不是一个模态

**1. 斜率检验。** 雅可比给出：

  ∂i_off,k/∂t0 = −0.170 / −0.340 / −0.509 A/ns（k = 2/3/4）

- 相k的时隙在 (k−1)/4·t0。
- 低侧导通期间电感电流的斜率是 −Vo/L = −1 V / 1.4667 nH = −0.682 A/ns。
- 理论值 (k−1)/4 × (−0.682) = −0.171 / −0.341 / −0.511 A/ns，与雅可比一致（0.5%以内）。

**2. 直接注入。**
- 周期的两周期幅度是0.093 ns，三种规则下都一样；它由trim经相1决定，∂T/∂u = −1.47 ns/A。
- 跟随规则把其中 (k−1)/4 搬到相k的时隙上。
- 直接注入量为 0.016 / 0.032 / 0.048 A。

**3. 闭环放大。**
- 跟随规则比fixed_at_T多出 0.078 / 0.157 / 0.235 A，正好是直接注入的 **4.9倍**，三相相同。
- 所以增量与 (k−1) 成正比，这正是A93测到的规律。
- 放大来自闭环在 z = −1 的响应：两周期模态（−0.65到−0.66）和修正器（0.5）。

**4. 平均规则在 z = −1 处没有这条路径（3.2节），所以回到固定时隙的水平。**

## 6. 与协同仿真的交叉验证（A92 / A93 / A97）

**条件：**
- Verilog RTL + A88的物理plant，5%；
- 每种规则取5个确定性运行：n0、m1p、m1n、m3p，以及带guard的m3n；
- 最后200个周期，A93 RESULTS第3节的两周期度量。

| 量 | 固定：D52 / A92 | 跟随：D52 / A93 | 平均：D52 / A97 |
|---|---|---|---|
| 相2关断电流（A） | 0.160 / 0.142–0.187 | 0.240 / 0.240–0.301 | 0.162 / 0.142–0.163 |
| 相3（A） | 0.160 / 0.148–0.179 | 0.316 / 0.343–0.467 | 0.159 / 0.133–0.165 |
| 相4（A） | 0.155 / 0.144–0.183 | 0.390 / 0.426–0.589 | 0.155 / 0.132–0.179 |
| 周期（ns） | 0.094 / 0.083–0.106 | 0.094 / 0.077–0.103 | 0.093 / 0.079–0.097 |
| 高侧误差，相1（ns） | 0.051 / 0.051–0.055 | 0.051 / 0.053–0.054 | 0.051 / 0.051–0.055 |
| 高侧误差，相2–4（ns） | 0.055–0.056 / 0.047–0.063 | 0.084, 0.110, 0.138 / 0.072–0.093, 0.087–0.117, 0.099–0.142 | 0.055–0.057 / 0.043–0.059 |

**结论：**
- 固定和平均规则下，两个模型在运行间的离散范围内一致。
- 跟随规则下，D52的高侧误差也在范围内；但相3–4的电流比协同仿真低10–25%。
  - 可能的原因：修正器的量化（31.25 ps LSB，误差右移取整），以及A93中相4有24–41%的高侧开通落在谷底之前，线性模型不包含这一点。
  - 这个原因未单独检验。
- 周期的两周期分量在两个模型、三种规则下都是约0.09 ns，与A93"周期本身的交替不变"的观察一致。
- 高侧误差测量需要保留周期奇偶；A93第3节只量了电流，A97 RESULTS第3.2节补上了这一项。

## 7. 判定 / 不判定 / 局限

**判定：**
- A93 dither升高的机理：时隙把周期的两周期交替按 (k−1)/4 注入相k，闭环把它放大4.9倍；
- 平均规则在两周期频率上精确消除这条路径；
- 两周期交替的来源：trim的 ±1 LSB 极限环。它不是一个轻阻尼模态。

**不判定：**
- 抖动的放大。抖动作用在每个边沿上，不是这里的输入；频带增益只是定性旁证。
- 其它负载与m ≠ 0。

**局限：**
- 线性化，不含量化：Ton的1 LSB跳变、修正器取整、trim的砰砰本身（这里把它当作已知输入）；
- 不含早到开通（A93）；
- 只有5%与m = 0。
