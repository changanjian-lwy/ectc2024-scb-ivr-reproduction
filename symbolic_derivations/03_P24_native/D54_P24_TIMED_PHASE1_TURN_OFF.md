# D54：相1低侧定时关断对抗驱动抖动——A99的数学模型

2026-10-01。计划与预测写在A99 BOUNDARY第3–4节（任何代码之前）。D54的结果、选定的规则和对A99各运行的预测带写在BOUNDARY第5节，在RTL修改和运行之前提交（df44f43）。

## 1. 为什么需要

D53/A98发现，抖动的主要放大器是相1的电流比较器关断：
- 导通时间误差δ在陡的上升斜率上改变峰值电流，比较器再在缓的下降斜率上换回时间，于是周期移动10.5·δ；
- 相2–4的槽位继承这个周期误差（0.68 A/ns）；
- 相1导通边沿约占方差的60%。

近年文献里有"用预测代替比较器"的做法（Zhou等，TPEL 2023；TIE 2025）。本文检验把相1的关断改为定时、比较器只做测量会怎样。

## 2. 模型

### 2.1 映射几乎不需要新代码

在D47的映射中：
- 把相1的电流阈值设到不可能达到（−1e9 A）；
- 把相1的定时重启关断设为轨道上相1的低侧导通时长。

这就是定时关断。

**门控：** 在D51轨道处，时长取 t_lo1 − (Ton + dl_1) = 203.447 ns 时，定时映射与比较器映射的一个周期相差 ≤ 2.7e-8（截面、周期、过零、谷底、关断电流）。

**结论：轨道完全相同，只有逐周期动态改变。**

### 2.2 逐边沿输入与闭环（在D53的基础上）

**输入：** 最后一个输入从"阈值偏移u"换成"相1低侧导通时长"。

**抖动注入：** 命令关断从命令开通算起，所以有效时长 = dlo + δ_loff,1 − δ_lon,1。

**测量：**
- 比较器只测量，e_lo = 实际关断 − 电流到达−6.25 A的时刻；
- 低侧导通期间相1电流线性下降，所以 e_lo = (−6.25 A − i_off,1)/(Vo/L)；
- 没有trim。

**dlo规则（在蒙特卡洛中精确实现）：**
- **误差型**（与dtl相同）：dlo −= (err − 3) >>> shift；早到（未过阈值）+2 LSB。
- **符号型**：早到或 err < 3 LSB 时 +1 LSB，否则 −1 LSB。

**代码与记录：**
- `src/scb_ivr/p24_jitter.py`（选项 `timed1`、`lo_sign`）；
- `scripts/p24_timed_modes.py`；
- `diagnostics/D54_timed_turnoff_5p0pct_m0p0.json`。
- 加入这些选项后重算D53，模型结果逐项不变。

## 3. 结果

### 3.1 开环链条被切断

| 雅可比项（D51轨道） | 比较器关断（D53） | 定时关断（D54） |
|---|---:|---:|
| ∂T/∂ton_1 | +10.5 ns/ns | **+1.000 ns/ns** |
| ∂i_off,1/∂ton_1 | 0（关断在阈值处） | **+6.47 A/ns** |

导通时间误差不再改变周期，而是落在相1的关断电流上。

### 3.2 闭环蒙特卡洛（平均槽位，30 ps，相2–4）

| 方案 | 电流标准差（A） | 周期标准差（ns） | dither（A） | 高侧早到 | 相1关断电流均值（A） |
|---|---|---:|---:|---|---:|
| 比较器关断（D53，采用设计） | 0.59–0.65 | 0.55 | 2.03 | 25–26% | −6.24 / −6.49 交替 |
| 定时，误差型，增益1/2 | 0.44–0.46 | 0.28 | 1.47 | 17–18% | **−6.04（偏早，68%早到）** |
| 定时，误差型，增益1/8 | 0.42–0.43 | 0.19 | 1.43 | 17–18% | −6.36 |
| 定时，误差型，增益1/2，早到+6 | 0.49–0.51 | 0.36 | 1.62 | 20–21% | −6.21 |
| **定时，符号型 ±1 LSB** | **0.40–0.42** | **0.15** | **1.39** | **16–17%** | **−6.31（无偏）** |

**100 ps：**
- 符号型：1.17–1.22 A，周期0.35 ns，相1均值−6.33 A；
- 比较器：1.70–1.91 A，1.57 ns；
- 误差型增益1/2：相1均值−4.9 A，86%早到。

**0 ps：**
- 符号型：电流标准差0.018 A，dither 0.04 A，相1均值−6.30 A；
- 比较器：0.16 A、0.38 A。trim的 ±1 LSB 极限环消失。

**代价：** 相1自己的关断电流标准差在30 ps时为0.38 A（比较器0.17 A），约44%的关断在电流到达−6.25 A之前。

### 3.3 误差型规则为什么偏早

**原因是两侧不对称：**
- 晚于过零时，误差可以测出，按比例往回调；
- 早于过零时，电流从未到达阈值，测不出早了多少，只能加固定步长。

**后果：** 噪声大时，按比例的回调大于固定的前推，dlo被推向偏早，直到早到概率足够大才平衡。

**符号型规则两侧对称：** 在对称噪声下收敛到中位数（e_lo = 3 LSB），所以无偏；而且每步只有31 ps，自身注入的噪声很小。

这和D52/D53里trim、早到规则的分析是同一类问题：符号型（砰砰）校正，步长决定噪声底，对称性决定偏差。

## 4. 与A99交叉验证

**条件：**
- A99协同仿真，采用设计 + 定时关断（符号型，学习1024周期）；
- 5%，运行到500 µs，最后200个周期（全部处于定时模式）。

| | D54（中位数） | A99 | A97（比较器） |
|---|---|---|---|
| n0：各相电流标准差（A） | 0.018 | **0.018–0.019** | 0.13–0.21 |
| n0：dither（A） | 0.04 | **0.04** | 0.57 |
| n0：周期标准差（ns） | 0.016 | **0.016** | 0.14 |
| j30：相2–4电流标准差（A） | 0.39–0.41 | **0.39–0.43** | 0.56–0.66 |
| j30：周期标准差（ns） | 0.14 | 0.19（+35%，超出 ±30% 判据） | 0.59 |
| j30：相1电流标准差（A） | 0.38 | 0.39 | 0.17 |
| j30：高侧早到 | 16–18% | 17–18% | 23–26% |
| j100：相2–4电流标准差（A） | 1.16–1.20 | **1.02–1.16** | 1.59–1.79 |
| j100：周期标准差（ns） | 0.32 | 0.29 | 1.65 |
| j100：dither（A） | 4.13 | 3.47 | 5.70 |

**结论：**
- **无抖动时，两个模型精确一致**：0.018 A、0.04 A、0.016 ns。
- **有抖动时：** 电流与早到在误差带内；j30的周期标准差高于模型35%。
  - 与A98的s10一样，小σ时协同仿真偏高。
  - 可能的原因是模型没有的测量噪声（10 ps步长上的过零检测，再量化到LSB），未单独检验。
- **门控：** A99在切换前的1467个截面与A97逐位一致；m3n的启动与交接不变，峰值156 A。

## 6. 判定 / 不判定 / 局限

**判定：**
- 定时关断切断了×10.5的放大链（∂T/∂ton_1 = 1.0），两个模型一致地把相2–4的抖动响应降低约三分之一，并消除了无抖动时的trim极限环；
- dlo应采用对称（符号型）规则。

**不判定：**
- 负载与输入阶跃。符号型规则每周期最多调31 ps，阶跃跟踪需要粗/细两级规则或比较器兜底，需单独检验；
- 学习长度的通用选取；
- 相1关断电流变化（100 ps时最小−3.3 A）对ZVS裕量的长期影响。A91的硬开通估计未上升，但裕量变小。

**局限：**
- 电路线性化；
- 只有5%、m = 0、种子1；
- 抖动是理想化的高斯独立分布。
