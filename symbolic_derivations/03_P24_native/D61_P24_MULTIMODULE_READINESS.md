# D61：单模块要为多模块准备什么——均流、交错与零电压开关裕量（平均模型，不做协同仿真）

**定位：** 这是下一层（多模块）的准备度检查。它只回答一个问题：单模块的设计里，哪些结论可以直接乘到多模块，哪些会被改写，以及单模块必须对外提供什么。不改任何实验。

P24 原文把"相与相之间、模块与模块之间的电流均分"列为这个结构的主要挑战。它要求各模块交错运行来降低输出纹波（1 kW = 4 个 250 W 模块，共 16 相）。

## 1. 关键关系

在预测模式下（临界导通，谷底电流固定为 −i_neg），每相：
- **平均电流** I = (V_rail − Vo)·Ton/(2L) − i_neg，与 Ton/L 成正比；
- **周期** T = Ton·(1 + (V_rail − Vo)/Vo) + t_x。上升用 Ton，下降用 ΔI·L/Vo = (V_rail − Vo)·Ton/Vo。**L 和 i_neg 都约掉了。**

**推论：电感有公差（ε）时，只用 Ton 无法同时做到"电流相等"和"周期相等"。**
- **Ton 相同：** 周期相同，电流按 1/L 分配。
- **调 Ton 让电流相等：** 周期按 L 分开，交错的几个模块会互相漂开。
- **Ton 相同，再用各模块的 i_neg 均流：**
  - 所需 i_neg = i_neg + I_ac·(1/(1+ε) − 1)，其中 I_ac = (V_rail − Vo)·Ton/(2L) = 66.6 A；
  - i_neg 就是零电压开关的裕量。

## 2. 数字（P24 点：Ton 568 LSB，单模块 250 A，周期 232.2 ns）

| 电感偏差 | Ton 相同时的电流 | 让电流相等所需的 i_neg（标称 6.25 A） |
|---|---|---|
| −10% | 280.7 A（+12.3%） | 13.65 A |
| −5% | 264.5 A（+5.8%） | 9.75 A |
| +5% | 236.9 A（−5.3%） | 3.08 A |
| +10% | 224.9 A（−10.0%） | 0.20 A，几乎没有负电流，失去谷底软开通 |

- **i_neg ≥ 2.5 A（2%，A82 的软开关边界）时，电感最多只能比标称大 6.0%。**
- **交错漂移（两个自由运行的模块错开一个时隙 T/16 所需的时间）：**
  - Ton 差 1 LSB：9 µs；差 5 LSB：1.8 µs；
  - 过渡时间差 0.2 ns：17 µs；差 1 ns：3.4 µs；
  - **所以无论哪种方案，模块之间都必须主动同步**，光靠 Ton 相等保不住交错。

## 3. 四个模块共用一个输出（平均模型，Co 和负载都 ×4，300 µs）

| 方案 | 结果 |
|---|---|
| 各模块各用 A104 的 PI，ADC 偏差 ±0.5 mV | **发散**：193/250/250/307 A，还在继续散开，Ton 差 234 LSB。各自积分的环在共用输出上无法均流 |
| 一个共用的 PI，Ton 相同，电感 ±5% | **稳定**：236/250/250/264 A（按 1/L 分配），Ton 相同、周期相同 |
| 各模块下垂（0.08 mΩ/模块），ADC ±0.5 mV | 均流 ±2.6%，但 Vo 低 20 mV（负载线）。Ton 差 26 LSB，0.35 µs 就错开一个时隙，交错失效 |
| 同上，再加电感 ±5% | 均流 ±2.6%，Ton 差 30 LSB，交错失效 |

## 4. 可评估的方案（多模块层面）

| 方案 | 均流 | 交错 | 零电压开关裕量 | 要求 |
|---|---|---|---|---|
| **A：一个共用电压环 + 共同 Ton + 从模块按时隙同步** | 误差等于电感公差（±5% → ±5.5%） | 周期天然相等，只需小的时隙修正 | 不变 | 接受电流不均（导通损耗和温升不均约 ±2ε） |
| **B：A + 各模块 i_neg 修正均流** | 相等 | 同 A | 各模块不同；电感偏大的模块变小 | 电感偏差 ≤ +6%（保 i_neg ≥ 2.5 A） |
| C：各模块下垂 | ±2.6%（0.5 mV 偏差） | 失效，需要另加锁相，又会动到 Ton | 不变 | 2% 负载线；Ton 同时被均流和锁相占用 |
| D：各模块独立积分 | 发散 | 失效 | - | 不可行 |

**结论：A 是基线，B 在电感匹配到 +6% 以内时可加。**

## 5. 单模块必须对外提供的接口

这是框架层面的约定，数值可替换：

| 方向 | 信号 | 现状 |
|---|---|---|
| 输入 | 共同的 Ton 命令（来自共用电压环） | 单模块现在自己算 Ton（A104）。多模块时电压环上移到系统层 |
| 输入 | 第 1 相的时隙参考（主模块的周期 + 本模块偏移 m·T/16） | 模块内第 2-4 相已经按时隙跟随第 1 相（A97）；跨模块需要把同一机制开放给第 1 相，要改 RTL |
| 输入 | i_neg 修正（方案 B） | 已是参数（i_target），需要变成运行中可调 |
| 输入 | 使能 / 预偏置启动 | A103 的启动假设模块独自启动；多模块时整体共用一个启动顺序 |
| 输出 | 本模块的平均电流 | 没有；均流或监视需要 |
| 输出 | 第 1 相开通时刻（作主模块时的同步源） | RTL 内部已有（t_ref），没有引出 |

## 6. 对单模块结论的影响

- **直接适用、可按模块数相乘：**
  - 每相的开关物理和零电压开关时序（A86-A100）；
  - 器件现实度；
  - 模块内的串联电容（D60/A107）；
  - 损耗与面积。
- **要上移到系统层或改写的：**
  - 电压环：A104 的 PI 参数要按共用环重算；对象增益 ×M，输出电容是共用的；
  - 输出电容 Cout 的选取：交错抵消纹波后再定，所以原计划在单模块上做的 Cout 实验不做了；
  - 启动顺序：整体启动，以及模块后加入时的预偏置启动。
- **多模块反而有帮助的：** 轻载时可以关掉部分模块，避开单模块约 40% 负载以下的限制。

**文献：** 这类周期随负载变化的变换器怎么交错，CRM（临界导通）PFC 那边有成熟方法：
- 开环和闭环交错（Huber、Irving、Jovanović 等）；
- 锁相交错及其稳定性；
- 过零预测和无差拍交错（近年）。

## 7. 没有做的

- **多模块的协同仿真。** 现在的电路模型只有一个模块，要扩成多模块（共用输出、各自的串联电容）是框架层面的改动，属于下一层。
- **电感以外的模块差异：** 串联电容、Coss、过渡时间、ADC 增益。
- **母线阻抗和输入滤波。**
