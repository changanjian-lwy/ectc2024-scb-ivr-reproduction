# D50：误差型修正器的定点、无直通条件与抖动——A92的数学模型

2026-10-01。推导与计划写在A92运行之前；轨道数值和对比追加在后文。

## 1. 为什么需要

A91发现：
- A89的两个修正器把延迟直接设成测得的绝对时刻；
- 测量从实际边沿算起，延迟却加在命令时刻上；
- 所以驱动器失配m学不进去，较快一侧的实际死区等于"自然转换时间 − |m|"，没有下限。

A92按文献（APEC 2023的相位误差检测，ECCE Europe 2025的迭代小步）改成误差型更新。这里用代数和D47的映射，回答三个问题：
- 它的定点在哪里？
- 为什么不会直通？
- 抖动被放大多少？

## 2. 修正律与定点

**记号。**
- 时间都从实际边沿算。驱动器让低侧边沿比高侧晚m。
- 低侧：
  - a_k = 第k次低侧实际开通 − 实际高侧关断 = dtl_k + m + j_k；
  - c_k = 自然过零时间；
  - 误差 e_k = a_k − c_k。
- 高侧：
  - b_k = 实际高侧开通 − 实际低侧关断 = base_k − m + j'_k；
  - V_k = 自然谷底时间；
  - 误差 e'_k = b_k − V_k。
- j、j'是两条边沿抖动之差。

**更新（A92 BOUNDARY第3节），增益 g = 2^−shift：**
- 低侧晚到或准时：dtl_{k+1} = clamp(dtl_k − g(e_k − e*_l), 0, max)；早到：+step。
- 高侧晚到：dt_pred_{k+1} = clamp(base_k − g(e'_k − e*_h), 0, max)；早到：+step；平台：保持。

**定点（无抖动、c与V不变、钳位不起作用）：**

$$e = e^*_l \;\Rightarrow\; dtl^* = c + e^*_l - m, \qquad e' = e^*_h \;\Rightarrow\; dt\_pred^* = V + e^*_h + m$$

**实际边沿落在"过零 + e*_l"和"谷底 + e*_h"，与m无关。** m只进入命令延迟。这正是A89的绝对设定律做不到的：A89的定点是 a = c + m。

**下限何时起作用：**

| 下限 | 起作用的条件 | 5%下的情形 |
|---|---|---|
| 低侧 dtl ≥ 0 | m > c + e*_l | c = 0.96–1.17 ns（D47），所以 m > 1.05–1.26 ns：m = +3.4 ns起作用，m = +1 ns不起作用 |
| 高侧 dt_pred ≥ 0 | m < −(V + e*_h) | 稳态 V = 8.1–9.3 ns，|m| ≤ 3.4 ns时都不起作用；A91交接瞬态里 V ≈ 1.2 ns，所以 m < −1.3 ns时会起作用 |

下限起作用时：
- 低侧：a = m，晚于过零 m − c，要付反向导通的代价；
- 高侧：b = −m = |m| > V，开通晚于谷底，节点已回升，代价是部分硬开通。

**两种情况都不是直通。**

## 3. 为什么不会直通（理想传感器）

**直通的条件：**
- 低侧：a < 0，低侧在高侧实际关断之前就开通；
- 高侧：b < 0。

**低侧，第k次晚到（a_k ≥ c_k）之后：**

$$a_{k+1} = (1-g)(a_k - j_k) + g(c_k + e^*_l - j_k) + j_{k+1} \;\ge\; c_k + g\,e^*_l - j_k + j_{k+1}$$

- 只要 c_k + g e*_l > j_k − j_{k+1}，就有 a_{k+1} > 0。过零时间c ≥ 0.96 ns，远大于抖动差。
- 由此还得到 dtl_{k+1} = a_{k+1} − m − j_{k+1} > −m。所以m < 0时下限0不可能起作用，钳位不会把低侧推到直通。
- 早到的那一步让dtl变大，只会更安全。

**高侧，第k次晚到（b_k ≥ V_k）之后：**

$$b_{k+1} \ge V_k + g\,e^*_h - j'_k + j'_{k+1}$$

- 只要 V_k > 抖动差，就有 b_{k+1} > 0。A91里最坏的瞬态 V = 1.2 ns，也满足。
- 下限起作用时，b = −m + j' > 0。
- 重启基准时，b = rs_high − m > 0。
- 平台时保持，b不变。

**剩下的暴露点：**
- mode S的固定死区必须大于 |m|，所以取4.5 ns；
- 进入mode P的第一个低侧边沿用 dtl_init，必须 ≥ |m|，所以取4.5 ns。

**对比A89：** A89晚到时直接设 a_{k+1} = c_k + m + j，m < −c 时为负，这就是A91 m1n直通的原因。

**前提：**
- 误差报告是真值，即理想比较器；
- 过零与谷底发生在实际关断之后，这在物理上成立；
- 每相每周期更新一次，延迟远小于231 ns。

## 4. 抖动

**一阶自回归。** 忽略钳位、早到支路，并设c不变。令 u_k = dtl_k + m − c − e*_l，则

$$u_{k+1} = (1-g)\,u_k - g\,j_k, \qquad e_k - e^*_l = u_k + j_k$$

$$\mathrm{Var}(u) = \frac{g\,\sigma_j^2}{2-g}, \qquad \mathrm{Var}(e) = \frac{2\,\sigma_j^2}{2-g}$$

**其中 σ_j 是两条边沿抖动之差的标准差。** 每条边沿各自独立带σ，所以 σ_j = √2σ（A92 BOUNDARY第9节）。

| g | σ_e / σ_j | σ_e / σ |
|---|---:|---:|
| 1/2（A92） | 1.155 | 1.63 |
| 1（g = 1的误差律） | 1.414 | 2 |

注：g = 1的误差律只在早到支路上与A89的设定律不同。

**早到的比例：** Φ(−e*/σ_e)。

**超出自由窗口w的比例：** Φ(−(w − e*)/σ_e)，平均超出量为 σ_e φ(z) − (w − e*)Q(z)。

**在A92的参数下（e* = 94 ps，w = 0.16 ns 取相4）：**

| σ | σ_e | 早到 | 超窗 |
|---:|---:|---:|---:|
| 30 ps | 49 ps | 2.7% | 9% |
| 100 ps | 163 ps | 28% | 34% |

## 5. 轨道（D47的映射）

**脚本：** `scripts/audit_p24_errcorr_orbits.py`（新）。D47、D49的脚本不改。

**条件：**
- 5%、25 °C，数据手册Coss(V)，反向压降；
- 调节轨道（Vo = 1 V）；
- 每相低侧死区 = max(过零 + e*_l, m)，高侧延迟 = max(谷底 + e*_h, −m)；
- e* = 93.75 ps（3个LSB）。

**两条轨道：**
1. **m = 0。** 因为下限都不起作用，这也代表m = ±1与m = −3.4的稳态。对照A92的n0、m1p、m1n、m3n。
2. **m = +3.4 ns，低侧下限起作用。** 对照A92的m3p。预测P_rev约11–13 W（A92 BOUNDARY第5节）。

## 6. 判定 / 不判定

**判定：**
- 误差型修正器的定点、无直通条件与抖动放大，在理想传感器下的结论；
- 定点轨道的代价。

**不判定：**
- 比较器的延迟与失调；
- 早到支路的非线性统计；
- 瞬态过程。瞬态由A92的协同仿真回答。

### 8.2 无直通

**第3节的结论在8个运行中都成立：没有一次直通。**

但m3n出现了与修正器无关的826 A瞬态（A92 RESULTS第4节）：
- 开环启动使交接时Vo达到1.54 V；
- 电压环随后把周期缩短到141 ns；
- 相4的固定时隙（150 ns）一直被推迟，低侧导通了969 ns。

第3节只讨论直通，不覆盖这一机理。

### 8.3 抖动

**低侧与第4节一致：**
- j30：误差标准差0.050 ns，预测σ_e = 49 ps；
- j100：早到34%、超窗36%，预测28%与34%。

**高侧不一致：**
- j30的高侧早到比例是20%，标量模型预测约3%；
- 原因是谷底时间V本身每周期都在变：n0为0.046 ns，j30为0.098 ns，j100为0.185 ns；
- 它随低侧关断电流变化，而这个电流又取决于前面各相的边沿；
- 即使没有抖动，n0的高侧误差也在0.19与0.03 ns之间两周期交替，说明闭环里有一个接近 −1 的模态。

**所以第4节"c、V不变"的标量模型对高侧不够用。** 需要把修正器的状态（d、dl）并入D47映射的雅可比矩阵，求闭环特征值。这是下一步的数学工作。
