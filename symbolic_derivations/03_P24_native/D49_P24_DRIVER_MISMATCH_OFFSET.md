# D49：低侧固定偏移的P24事件映射——A91驱动器失配的数学模型交叉验证

2026-10-01。先写计划与边界，再写代码与运行；结果追加在后文。

## 1. 为什么需要

A91（Verilog协同仿真）加入驱动器的高低侧延迟失配m（LMG1210：典型1 ns，最大3.4 ns）。A91 BOUNDARY第3节推出：
- 已采用的修正器把"测得的时刻"直接设为延迟，但测量相对实际边沿，延迟加在命令时刻上；
- 所以m > 0（低侧慢）时，低侧开通稳定地晚于过零m，这是一个固定点；
- 高侧会形成锯齿（第8节），不是固定点。

## 2. 方法

用D47的映射（数据手册Coss(V)、反向压降、25 °C），求调节后的周期轨道：
- **低侧死区 = 自然过零 + m**（固定偏移）；
- **高侧延迟 = 自然谷底**（不含高侧锯齿，只从一端界定其影响）。

新脚本 `scripts/audit_p24_offset_orbits.py`。D47的库与脚本不改。

## 3. 运行与预测

5%，m = 1 ns与3.4 ns，对照A91的m1p、m3p。

**预测（同A91第3节）：**
- 每个低侧边沿反向导通约 m − 0.2 ns；
- P_rev约4–6 W（m = 1）与18–22 W（m = 3.4）；
- 软开通保持。

**比较的主要量：**P_rev与反向导通时间，它们由低侧偏移主导。

## 4. 判定 / 不判定

**判定：**A91中低侧偏移的损耗是否与固定点一致。

**不判定：**
- 高侧锯齿与抖动的动态；
- m < 0的极限环；
- 随机抖动。

## 5. 结果（数学模型，5%，25 °C）

**条件：**
- D47的映射：数据手册Coss(V)；反向压降Vf 2.0894 V + 6.013 mΩ/器件（A87）；定时低侧；
- 目标负电流 −6.25 A（5% × 峰值）；
- 收敛判据 |Vo − 1| < 1e-6 V，所有延迟自洽 < 2 ps；
- 两次运行都在第5次外迭代收敛：自洽残差0.09 ps（m = 1）与0.035 ps（m = 3.4），Vo误差6e-7 V；
- 记录：`diagnostics/D49_orbit_5p0pct_m1p0.json`，`..._m3p4.json`。

**读法：**
1. **反向导通时间 ≈ m − 0.2 ns。** 因为过零之后，节点还要再降约0.2 ns才到 −Vf，这就是D47/D48的自由窗口。
2. **P_rev与第3节的预测比较：**
   - m = 1：4.31 W，落在4–6 W内；
   - m = 3.4：17.92 W，比预测下限18 W低0.4%。那个预测本来就是粗估。
3. **Ton上升0.17 / 0.64 ns：** 反向导通的损耗由多出的输入能量补上。
4. **高侧开通电压基本不变（±0.02 V）。** 这里高侧放在自然谷底，见第2节。

**这一节判定的是：**低侧偏移m在固定点上的代价。

**它不判定的是：**A91的系统能不能到达这个固定点。A91的结果见下一节。

## 6. 与A91的交叉验证

**条件：**
- A91的m1p：Verilog RTL + A88的物理plant，5%；
- 低侧边沿比高侧晚1 ns，无抖动；
- 取最后50个周期。

**m = 1 ns的对比：**

| | A91 m1p（物理模型） | D49（数学模型） | 差 |
|---|---:|---:|---:|
| 低侧边沿在过零之后（ns） | 平均0.996 [0.974, 1.021] | 1（设定） | — |
| 每个低侧边沿的反向导通时间，相1–3 / 相4（ns） | 0.768–0.773 / 0.833 | 0.780–0.782 / 0.841 | −0.012 / −0.008 |
| **P_rev（W）** | **4.30** | **4.31** | −0.01 |
| Ton（ns） | 18.000 | 17.922 | +0.078 |
| 周期（ns） | 231.63 | 231.76 | −0.13 |
| 相4关断电流（A） | 平均 −5.89 | −5.84 | −0.05 |

**结论：**
- **P_rev在0.01 W内一致，反向导通时间在0.012 ns内一致。** 第3节的固定点就是A91系统实际到达的状态。
- **Ton差0.078 ns（2.5个LSB）。** 对照：没有失配时，A91的门控运行与D47只差0.003 ns。
  - D49把高侧放在自然谷底，而A91的高侧在谷底前m到谷底之间做锯齿（A91 RESULTS第5节）。
  - 这可能就是差异的来源，但没有单独检验。

**m = 3.4 ns：没有可比的A91运行。** A91的m3p与m3p_s45都因直通而停止。17.92 W是这个固定点的代价，但A91的系统到不了这个固定点。

**m < 0：D49没有固定点可比，原因见第4节。** 不过D47轨道里相4的自然过零时间是0.96 ns，小于1 ns。这正是A91 m1n直通的条件（A91 RESULTS第4节）。所以数学模型事先就能指出：失配典型值1 ns时，低侧没有余量。
