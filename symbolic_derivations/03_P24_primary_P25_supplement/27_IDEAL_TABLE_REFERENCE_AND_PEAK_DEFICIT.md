# 27 — P24理想公式基准与详细模型峰值缺口

## 理想公式复核

对P24的48→1 V、1 kW、nP=4、nM=4、5 MHz配置：

- 总输出电流 `Io=P/Vo=1000 A`；
- 每模块平均电流 `Io/nM=250 A`；
- 每相平均电流 `Io/(nP nM)=62.5 A`；
- 边界三角波峰值 `Ipk=2Io/(nP nM)=125 A`；
- `D=nP Vo/Vin=1/12`，`Ton=D/f=16.6667 ns`；
- 单相间距 `Ts/nP=50 ns`；
- `Lcrit=(Vin/nP−Vo)Ton/Ipk=1.4666667 nH`。

因此，在“电流0→125→0、完整50 ns为三角形底边”的P24理想边界模型中，每相平均62.5 A、每模块250 W、四模块1 kW代数上完全闭合。这一层已经复现。

这里必须与Table 1分开：P24 Eq.(4)代入上述工况得到1.4667 nH，但Table 1的nP=4、nM=4、5 MHz单元格写2.68 nH。该内部不一致仍保留，本文按用户确定的规则采用公式计算值，不能写成“Table 1的2.68 nH已复现”。

## 详细夹具对照

使用第26笔记的严格98.5%Lcrit候选（L=1.4446667 nH、J=11.82 A），保持固定50 ns交错：

- 实际四相峰值118.304–118.543 A；
- 实际J/Ipk=9.971–9.991%；
- 四相平均电流52.118、52.198、52.241、52.351 A；
- 单模块总平均电流/理想1 V端口功率208.908 A/W，仅为250 W的83.56%。

详细夹具包括有限Coss换流、负电流、Ron/绕组电阻和有限飞跨动态；仍使用借用的常数Coss与理想反向支路，且不包括零启动、闭环调压、非线性制造商GaN模型及四模块耦合。

## 高侧导通阶段的严格KVL分解

每相都满足端点恒等式：

`Ipk = Istart + [mean(Vx) − Vo − Rind mean(I)] Ton/L`。

数值积分的恒等式误差为0或约1.4e−14 A。四相高侧开始电流为−0.649至−4.939 A，平均相节点电压仅11.311–11.700 V，而理想公式使用12 V。若在相同L下仍有理想12 V节点，16.667 ns应增加126.904 A；实际只增加118.952–123.439 A，电压项造成3.465–7.951 A的上升量缺口。

以第二相为例，相对于P24目标125 A：

`118.457−125 = (126.904−125) + (−2.262) + (120.718−126.904)`

即较小L本可增加约1.904 A，但高侧开始时的负电流减去约2.262 A，详细平均节点电压又减去约6.185 A，最后峰值低约6.543 A。

## 能说与不能说

可以说：P24理想公式本身给出250 W；详细模型的负电流起点和低于12 V的有效相节点电压共同破坏理想125 A峰值/62.5 A平均值假设。

不能说：缺口已经唯一归因于某个器件。平均节点电压不足同时包含开关导通压降、飞跨电压状态、换流和模型理想化。下一步应进行有来源、一次只改变一个模块的参数消融，并在每种模型下重求周期状态，不能拿同一旧初值直接比较。
