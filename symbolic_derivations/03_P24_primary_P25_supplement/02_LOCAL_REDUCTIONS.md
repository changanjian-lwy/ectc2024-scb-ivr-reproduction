# 局部化简：从完整模块导出，不另造独立电源

对应01_FULL_MODULE_EQUATIONS.md的连接、符号与理想边界。局部模型分成“完整模块的精确降阶”与“隔离单元的额外近似”，两者不能混用。

## 1. M2/M5：完整四相模块的精确一节点降阶

所有高侧OFF、除选中相s外全部低侧ON。令X=x_s，其他xj=0。使用整体电容矩阵A和Bf：

    bs = Bf的第s列
    cs = D的第s个对角元
    ps = A⁻¹bs
    A da/dt = bs dX/dt
    a=a0+ps(X-X0)
    Ceq,s = cs-bsᵀA⁻¹bs
    Ceq,s dX/dt=-is
    Ls dis/dt=X-Vo

这是从完整模块得到的Schur补，不是CH/CL人为串联。其他相电流保留为ij(t)=ij,0-Vo τ/Lj，其低侧电流吸收对应KCL。理想接地阶段内它们不直接改变Ceq,s；它们会影响后续事件时刻和整体周期。

A正定且电容参数正时，Ceq,s>0。完整Coss链与三个飞跨电容都通过A参与降阶；不能只取目标开关的CHs/CLs。

## 2. 四个目标高侧电压都必须追踪

定义：

    d1=(-1,0,0)ᵀ, d2=(1,-1,0)ᵀ,
    d3=(0,1,-1)ᵀ, d4=(0,0,1)ᵀ
    VH1=Vin+d1ᵀa; VH2=d2ᵀa; VH3=d3ᵀa; VH4=d4ᵀa-x4

在选中相s自由的阶段：

    VHm(τ)=VHm,0+[dmᵀps-δm4 δs4](X-X0)
    γm,s=δm4 δs4-dmᵀps

因此γs,s>0时，选中高侧ZVS对应：

    Xz=X0+VHs,0/γs,s

若γs,s≤0，不能使用“负电流抬高X即可降低自身Vds”的结论，必须重新判断轨迹。即使选中目标尚未到零，其他器件也可能先触发反向钳位；此时当前子模态提前结束，必须改方程。

## 3. 钳位前无损轨迹：M2/M5共用

令τ=0为本次关断瞬间，i0=is(0)，X0=X(0)：

    ωs=1/√(Ls Ceq,s), Zs=√(Ls/Ceq,s)
    X=Vo+(X0-Vo)cos(ωsτ)-i0 Zs sin(ωsτ)
    is=i0 cos(ωsτ)+(X0-Vo)/Zs sin(ωsτ)

M2常见i0>0，节点初始向下降；M5 i0=-Ineg<0，节点初始向上升。节点与电流的起点来自前阶段终态，不允许为了达到ZVS重新指定。

曲线中心X=Vo来自di/dt=0；当is=0时dX/dt=0，对应节点极值。它不保证该极值正好是Vds=0，也不保证极值时应当开通。

## 4. M5的自然ZVS可达条件

对γs,s>0、Xz>Vo的上升目标：

    R²=(X0-Vo)²+Ineg² Ls/Ceq,s
    R≥Xz-Vo

当括号为正时：

    Ineg,min²=(Ceq,s/Ls)[(Xz-Vo)²-(X0-Vo)²]

括号非正不能直接宣布首次上升就通过；仍需检查轨迹方向、首次到达时间和其他钳位。实际ZVS还要求到达目标发生在允许时间内，且准入瞬间自身VH=0。

写成首次到达的隐式时间方程：

    (X0-Vo)cos(ωs τz)+Ineg Zs sin(ωs τz)=Xz-Vo

选最早满足上升目标且不越过其他模式边界的正根。门槛附近到达时间、出口电流都可能很敏感。

## 5. 电荷与飞跨电压：换流也会搬运电荷

    Δa=ps ΔX
    ΔvFj=[(ps)j-δjs]ΔX, j=1,2,3
    ΔqFj=Fj[(ps)j-δjs]ΔX

该式可直接计算其他飞跨电容在一次局部节点换流中的变化，不需要预设其电压。它解释为什么忽略换流电荷的Qj=Qj+1只是基础近似，而不是完整周期条件。

## 6. 隔离单相模板：额外删支路后的模型

只有CH连刚性上方节点U与a、Cf连a与X、CL连X与地，并删去其余高侧电容链时：

    Ceq=CL+CH Cf/(CH+Cf)
    β=Cf/(CH+Cf)
    Xz=X0+(U-a0)/β

Cf≫CH时Ceq≈CH+CL，β≈1。这是孤立模板，不是完整四相Ceq,s。此前粗略把CH与CL串联得到的有效电容，不适用于这个模板接线。

## 7. 哪些规律可以说，哪些不能说

- 初始dX/dt=-i0/Ceq,s：正电流帮助低侧节点下降，负电流帮助节点上升，但高侧VH变化还由γ决定。
- 固定节点目标与电容比例时，Ineg,min尺度为√(Ceq,s/Ls)。电容比例变化会改变γ和Xz，不能一律归结为同一幂律。
- 更大L可能降低电流门槛，却增加特征时间√(L Ceq)，构成能量与时序的妥协。
- 飞跨电压通过VHs,0改变所需摆幅，因而影响准入门槛；不是只有Coss大小重要。
- 初始值敏感性、被动均衡和周期稳定性是不同问题。局部轨迹或单变量扫描不能证明整体稳定。
