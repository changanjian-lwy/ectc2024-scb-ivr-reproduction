# 单模块四相：整体节点方程与六阶段映射

状态：候选网表拓扑的解析推导。不是作者已确认的完整P24模型；未证明周期存在、稳定性、零启动或实际器件ZVS。无器件数值，无新仿真。

## 1. 依据与边界

P24四相拓扑结构；P25全非工作相低侧导通和向下一相交接的六模态外延。低侧Source接公共地是当前明确采用的解释。连接已对照A43网表的功率级，但网表不能代替作者原图确认。

nP=4，nM_instance=1：无模块间耦合。Vin、Vo刚性恒定。保留四相电流、三个有限飞跨电容、八个开关输出电容。基础版本理想开关与电感、恒定电容，无电阻、磁耦合、ESR/ESL、驱动/检测延迟、外加snubber。反向钳位在单独子模态中加入；未触发时不参与方程。

初始值为符号且须满足接线、导通约束。不能同时任意指定全部节点电压与全部电容电压。此处不规定36/24/12 V，也不假定所有电感电流为零。

## 2. 精确连接与极性

高侧H1: Vin→a1；H2: a1→a2；H3: a2→a3；H4: a3→x4。箭头规定常规支路电流hk的正方向，不限制实际电流符号。

飞跨Fj: aj→xj，j=1,2,3，vFj=aj-xj。低侧Lk: xk→地，支路电流ℓk。相电感: xk→Vo，电流ik。此文H/L为开关角色简写，不是修改原论文或旧网表名称。

    vH1=Vin-a1; vH2=a1-a2; vH3=a2-a3; vH4=a3-x4
    vLk=xk
    qHk=CHk vHk; qLk=CLk xk; qFj=Fj(aj-xj)
    Lk dik/dt=xk-Vo, k=1,…,4

CHk/CLk是该开关位置所有并联器件的总电容，不暗含器件型号或并联数量。

## 3. 七个节点KCL：每个阶段都适用

    dqF1/dt-dqH1/dt+dqH2/dt+h2-h1=0
    dqF2/dt-dqH2/dt+dqH3/dt+h3-h2=0
    dqF3/dt-dqH3/dt+dqH4/dt+h4-h3=0
    dqL1/dt-dqF1/dt+ℓ1+i1=0
    dqL2/dt-dqF2/dt+ℓ2+i2=0
    dqL3/dt-dqF3/dt+ℓ3+i3=0
    dqL4/dt-dqH4/dt+ℓ4+i4-h4=0

OFF开关的沟道电流h/ℓ=0，但其Coss电流不为零。ON理想开关满足自身端电压=0，其电流由KCL决定。把关断开关当成完全开路会丢失换流机理。

## 4. 电容矩阵：整体与局部的共同入口

令y=(a1,a2,a3,x1,x2,x3,x4)^T，电感注入矩阵B=(0_{3×4}; I4)。

    C = [ A  -Bf ]
        [-Bfᵀ D  ]

    A = [CH1+CH2+F1, -CH2,             0;
         -CH2,       CH2+CH3+F2,      -CH3;
          0,         -CH3,            CH3+CH4+F3]
    Bf = [F1,0,0,0; 0,F2,0,0; 0,0,F3,CH4]
    D = diag(F1+CL1,F2+CL2,F3+CL3,CH4+CL4)

对本阶段所有ON开关，建立电压约束Gy=b。每个高侧约束使用自身Vds=0：H1为-a1=-Vin，H2为a1-a2=0，H3为a2-a3=0，H4为a3-x4=0；低侧为xk=0。于是整体DAE为：

    C dy/dt + Gᵀλ = -B i
    diag(L1,…,L4) di/dt = Bᵀ y-Vo·1
    Gy=b

λ是ON开关支路电流，G每个阶段变化。恒定Vin/Vo且导通约束不变时，求导得到G dy/dt=0，可联立鞍点矩阵求节点斜率。

## 5. 六阶段：k为当前相，r=k mod 4+1为下一相

| 阶段 | ON高侧 | ON低侧 | 退出事件 |
|---|---|---|---|
| M1 | Hk | 除Lk外全部 | 相对本次导通时刻的Ton,k结束 |
| M2 | 无 | 除Lk外全部 | xk达到低侧零电压，Lk准入 |
| M3 | 无 | 全部 | 下一相ir向下过零 |
| M4 | 无 | 全部 | ir达到-αr Ipk,r |
| M5 | 无 | 除Lr外全部 | 下一高侧vHr达到零并准入 |
| M6 | Hr | 除Lr外全部 | 下一高侧Ton,r结束；对应下一轮M1 |

M3入口若ir已经为负，不能虚构稍后才过零；必须报告该顺序入口条件不成立。M4入口要求目标负电流尚未越过。ZVS出口必须按实际目标开关端电压检测，不按某个猜测节点值替代。

固定相间时隙不是P25物理事件的替代。若后续加T/nP时隙保护，它是另一个控制分支；必须在实际准入时检查Vds，而不是永久锁存曾经发生的零电压来保证未来ZVS。

## 6. 逐阶段的整体性质

M1/M6：使用整体DAE与一个高侧ON约束。非工作xj=0，其ij斜率=-Vo/Lj；当前相斜率由完整节点解决定。不能一面保留全部CH，一面无条件使用忽略CH的纯搬运公式。

M2/M5：所有高侧OFF，只有选中相x_s自由，其他xj=0。a1/a2/a3通过飞跨和高侧电容链共同响应。可精确Schur化简，见02_LOCAL_REDUCTIONS.md。

M3/M4：全部xk=0、高侧OFF，在基础线性模型中A da/dt=0，所以a与飞跨电压暂时不变，四相电流各按-Vo/Lk下降。其他相电流由ON低侧承担，不直接注入内部电容链。M3与M4电路方程相同，区别在控制事件。

## 7. 周期与电荷条件

完整周期必须同时满足y(T)=y(0)、i(T)=i(0)，且门极状态处于同一周期位置。所有四个电感有∫(xk-Vo)dt=0；每个飞跨电容有∫iFj dt=0。总输出电流为Σik，但刚性Vo不能证明调压或指定输出功率。

若周期存在且元件模型无损，整个周期平均输入功率等于Vo·Σ平均ik；瞬时两者可以不同，差额进入电容与电感储能。此等式不等于系统已达到论文1kW目标。

## 8. 可拓展接口

非线性电容：将q=Cv改为q(v)，KCL不变，矩阵改为随电压变化的微分电容矩阵。损耗：电感方程加-Rk ik，开关ON约束改为器件I-V关系。钳位：增加有导通判据的支路，而不是继续使用钳位前谐振解。其他模块不在本模型中。
