# 24：节点回归约束、连续检查及局部数值条件

## 共同边界与定位

共同起点为笔记22候选。P24拓扑/P25控制序列补充分支、原器件参数/反向I-V、固定5 MHz时隙、Ton、J=11.25 A及理想1 V输出源均不变。无新增SPICE实验，无强制36/24/12 V维持源，候选各节点作为独立未知数求解；候选初态仍不是零启动结果。

增加5.23 mV节点回归上限，是参照笔记22最大5.229 mV差值的算法比较要求，不是论文容差。新增1 ps最小首次到零提前量及40%固定参考余量也均为辅助算法限制。

## N4主候选与连续失败

较共同起点总归一化残差降低约75.33%，但不是周期闭合。

    节点最大回归差：约1.406 mV
    四相电流回归差：[0.22218,0.19172,0.22836,0.31327] A
    一模块转换器输出积分（理想1 V）：约207.567 W
    一轮4次交接：通过原数学准入
    第二轮H3在300 ns：失败，Vds≈+0.540837 V
    第二轮下一相低侧释放：298.029928 ns
    释放至时隙：约1.970072 ns，未出现首次Vds到零事件

两档rtol/atol=1e-9、1e-10复核相近。250 W参考输出尚未达到，四模块1 kW更未验证。理想1 V源不构成输出调压测试，不能直接把单模块输出乘4当整机结果。

## 局部数值条件审计

对N4完整11状态回归映射，用中心差分的两档步幅计算Jacobian。最小奇异值约4.91e-4/4.92e-4，最大约37.757/37.755，条件数约7.69e4/7.67e4。弱方向对小导数偏差较敏感；但这些结果本身不能证明停滞主要由病态性造成。

局部线性Newton可以把线性残差压到舍入量级，却需要约0.2 V节点变化和最大约0.89 A电流变化。较大试探违反初始H2 ZVS或下一轮H2固定准入，小试探才能通过且损失辅助余量。因此“线性方程解出来”不等于完整非线性事件环可行。

所有谱审计均局部，未计算验证性误差界，不证明全局无解或稳定性。N5停滞也不能作为物理矛盾结论。

## 后续方向

停止把同一局部方向反复缩小当作新的物理探索。继续审计固定Ton、负电流阈值和固定时隙的联合可行性，并核查论文允许的控制自由度；任何新控制自由度必须另开有文献依据的分支，不能悄悄加进现有分支。尚未复现成功，也未证明原论文不可复现。
