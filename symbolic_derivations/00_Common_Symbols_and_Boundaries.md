# 共同符号、边界与局部换流模板

## 符号

- nP：每模块相数；nM：模块数。原生P25取nP=3，P24分支取nP=4；未分析模块间耦合时nM只作为系统接口。
- Xk：电感前节点；ik：从Xk经Lk流向输出的常规电流。
- vCj：飞跨电容电压，必须根据该分支原图确认极性。
- Vin、Vo：换流期间近似恒定的输入、输出电压。不是固定48 V/1 V的数值分析。
- α：负电流相对峰值比例，Ineg=αIpk。P24、P25范围独立保存，不默认相同。

## 基础模型

理想导通开关；理想电感与飞跨电容；不考虑电阻、ESR/ESL、磁耦合、驱动与检测延迟。换流阶段不能省略输出电容。各相初始电流与电容电压显式保留，不默认零或相等。

共同电感关系：

    Lk dik/dt = vXk - Vo

低侧确实将Xk接地且保持导通时：

    dik/dt = -Vo/Lk
    Δt(正电流到零) = Lk ik,start / Vo
    Δt(零到-Ineg) = Lk Ineg / Vo

这些时间式不包含电阻、钳位压降和延迟。

周期要求是额外待验证条件：所有电感电流、电容电压满足x(T)=x(0)。局部事件通过不能证明周期闭合。零启动不属于当前分析。

## 局部换流模板：只适用于下面的接线

CH连接刚性上方节点U与内部节点a；Cf连接a与X；CL连接X与地；L连接X与Vo。两开关关断，无其他动态支路，直到目标钳位。U、Vo恒定，电容为常数。初始电容电压必须满足节点一致性。

    (CH+Cf) da/dt - Cf dX/dt = 0
    -Cf da/dt + (Cf+CL) dX/dt = -i
    Ceq = CL + CH Cf/(CH+Cf)
    β = Cf/(CH+Cf)
    a-a0 = β(X-X0)
    Ceq dX/dt = -i
    L di/dt = X-Vo

Cf远大于CH时才有Ceq≈CH+CL。不能把CH与CL直接按串联电容处理。

从i(0)=-Ineg、X(0)=X0开始，钳位前无损解为：

    ω = 1/√(L Ceq), Z = √(L/Ceq)
    X(τ) = Vo + (X0-Vo) cos(ωτ) + Ineg Z sin(ωτ)

高侧Vds=U-a，目标节点：

    Xz = X0 + (U-a0)/β

对Xz>Vo且初始高侧电压为正的上升换流，轨迹可达条件为：

    (X0-Vo)² + Ineg² L/Ceq ≥ (Xz-Vo)²

它只是电压目标可达条件；还须在允许时间内触发，并保证实际导通时Vds=0。损耗、非线性电容、额外支路与多相耦合均可能改变该条件。

固定起终点下，所需负电流尺度为√(Ceq/L)；固定释放电流下，电压摆幅尺度为√(L/Ceq)。改变电容比例可能同时改变β和Xz，不能直接声称普遍的单参数幂律。
