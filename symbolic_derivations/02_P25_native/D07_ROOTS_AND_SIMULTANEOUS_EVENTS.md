# D07：事件根定位、先后关系与受限同时事件规则

2026-09-28。继续P25原生三相数学框架；保留D03全部电容，复用D05互补约束和D06控制记忆。
本模块是数值/数学实现规则（PROJECT_DECISION），不是论文给定的检测器或硬件参数。

## 1. 根的定义

给定切换前模式的连续状态延拓x(t)，事件函数g(x(t))可为：

- Vds(SLk)：本相低侧归零，单位V。
- iq：下一相电感电流向下过零，单位A。
- iq-I_target_latched：负电流目标，单位A。
- Vds(SHq)：下一高侧归零，单位V。

目标事件时刻应定义为被监视区间内满足方向条件的首次到达：

    tau = inf {t >= t_start : g(x(t))=0 且为允许的到达方向}

有限采样不能自动证明“首次”或连续性。本实现只在已给定括区间中定位一个向下过零。
若声明并证明该区间g连续，且g(left)>0、g(right)<=0，则有根；
若进一步有整个区间dg/dt<0，则根唯一。前置区间无遗漏事件仍需另行检查。
代码要求记录延拓声明，但不把一个说明字符串当作这些假设已经获证明。

## 2. 双重停止条件，不修改状态

二分保留g(left)>0、g(right)<=0，同时要求：

    right-left <= epsilon_time
    abs(g(right)) <= epsilon_value

时间容差与事件量容差独立，后者按V或A解释。
只满足时间区间很小、残差却很大的跳变函数不能当成根。
迭代上限或浮点时间分辨率不足时报告失败，不返回伪成功。

结果保留左右两个Snapshot、判别函数残差和评估次数，状态标记NUMERICAL_ROOT_ONLY。
不把节点电压、电感电流或g覆盖为0。

试探点是原模式方程的数学延拓，不是已经接受的电路轨迹；
它可能位于真实模态有效域之外。不能用试探点的峰值宣称实际器件峰值。
最终候选点仍需D05有效性、D06状态/控制检查，允许误差必须相容。

回调必须保持同一分支、实验、时钟、周期、栅极状态，并返回所请求时刻的状态。
根定位过程中自行切换栅极或更换模型会被拒绝。

## 3. 事件列表必须完整

不能只定位“想要的下一开关动作”，还需要监视更早的模态退出：

| 类别 | 必须考虑的边界 |
|---|---|
| 控制 | 实际高侧Ton终点、零电压准入、下一相过零、负目标 |
| 关断器件 | 所有关断支路的反向电压余量g_rev归零 |
| 已有反向路径 | 反向电流降至零及钳位释放 |
| 其他相 | 当前模态要求保持正/负的电流到达零边界 |
| 外部端口 | 输入/负载模型已知的不连续时刻 |
| 未解析模型 | 退化约束、器件模型有效范围退出 |

当前代码提供通用事件量和时间窗口接口，尚未自动枚举上述完整列表。
因此排序结果明确只针对“已提供的窗口”，不能证明没有漏掉其他事件。

## 4. 有误差的事件时间如何比较

每个事件保留时间窗口[l,u]，不能只用中点排序。
只有某事件的上界严格小于其他候选的下界，才可判为唯一最早事件。

- 窗口重叠或仅接触：返回OVERLAP_REFINE_OR_DECLARE_UNRESOLVED。
- 精确声明在同一时刻：返回EXACT_COINCIDENCE_REQUIRES_RESET_RULE。
- 不将“误差范围内很接近”自动当作“严格同时”。
- 不给目标开关动作高于其他相越界的默认优先级。

若最早事件是另一相电流出界，必须先处理该边界，不能越过它继续等目标ZVS。
数学排序的结论是条件性的：所提供窗口确实包含所监视的首次事件，且事件集合没有遗漏。

## 5. 已定义的一类同时事件

对D05显式ideal_zero_drop分支与D06显式零延迟控制，定义：
“目标开关Vds归零、到达其反向通道边界、该开关栅极开启”的一次联合处理。

    1. 在原栅极状态下，求完整三相网络的反向互补解。
    2. 按D06执行一个合法的零电压栅极事件。
    3. 所有电容电压、电感电流保持原值。
    4. 在新栅极状态下重新求完整网络的互补解。
    5. 前后任一局部问题退化/未解决则拒绝，而非任意指定分流。

可用于SLk归零开启或SHq归零开启。反向支路到导通沟道的电流分配可以改变，
因为理想支路电流是代数量；储能状态不能跳变。
全过程未删除寄生电容，也没有为了实现理想开启而把电容电压改成0。

这是特定复合转移的定义，不是“栅极永远优先”的通用规则。
固定非零压降或真实GaN模型不自动使用该规则。
若还有另一控制事件同时发生（例如另一相电流恰好过零），本处理器没有代为解决。

一般同时事件需要验证约束兼容、状态更新兼容及处理次序无歧义：

    R_a(R_b(x,m)) = R_b(R_a(x,m))

或另行给出有物理依据的联合更新。仅仅时间一样不能保证上式。

## 6. 边界开始时恰好为零

普通二分器要求左端严格为正，故不重复触发起点已经为零的事件。
初始边界、切换后新激活的零事件、切触后离开等情况需要独立的
事件激活/去重/方向规则；尚未通过“时间加一点”绕开。
多事件级联以及防止无限零时间切换也仍需在整体调度层定义。
