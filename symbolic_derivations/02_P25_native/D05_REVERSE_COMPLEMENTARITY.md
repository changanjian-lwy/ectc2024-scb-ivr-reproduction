# D05：模态有效域与反向通道的互补约束

2026-09-28。当前仍为P25原生三相，沿用D02开关顺序和D03端点。
本次是局部数学约束与合成测试，不做论文参数仿真或整周期积分。

## 1. 证据和假设分开

P25 Sec. II/Fig. 3提出换流、可选反向导通区间以及GaN无Qrr的说明。
下述理想单向支路/固定压降支路是PROJECT_DECISION数学替代模型，
不是论文给出了GaN的完整本构关系，也不是我们获得了实际反向压降。

两个可选分支均须显式声明；不存在默认选择：

- ideal_zero_drop：六个反向压降均显式为0，理想、无损、无恢复电荷。
- constant_drop_surrogate：六个非负常数压降显式输入，具有Vf*r耗散。
  不是含电流、门极电压、温度依赖的真实GaN模型。

真实GaN对应的关系可写为F(vDS,iDS,vGS,T,历史)=0，留作独立器件模块；
本次不凭空选择这个函数或它的参数。

## 2. 统一方向与互补条件

v=vDS按漏到源为正。反向通道电流r按源到漏为正，故其漏源方向支路电流j_rev=-r。
对关断开关，定义电压余量g=v+Vf，其中Vf>=0为显式常数：

    g >= 0,  r >= 0,  g*r = 0

含义：

- g>0：反向通道未导通，r=0，电容电流仍保留。
- r>0：反向导通，v=-Vf。
- g=r=0：位于边界，不能仅凭电压为零断言已产生反向电流。

在g=0处，对固定Vf的连续、无冲激局部解，还检查切向互补条件：

    dg/dt >= 0,  r >= 0,  (dg/dt)*r = 0

若某个假定钳位需要r<0，它要求关断通道提供不允许的正向电流，必须拒绝。
若钳位电流降至0，且解除钳位后的dg/dt>0，则可以离开边界。
当两者同时为0时，活跃标签可不唯一，需后续轨迹/更高阶变化判定，不强行保持或释放。

**栅极已导通的开关不应用这套单向电流限制。** 理想ON沟道满足v=0，
其沟道电流可以正负双向。否则会误删M4中低侧承载负电感电流的路径。

## 3. 与共享节点方程拼接

沿用D03的C、B、节点/电流方向，令Sg为栅极导通支路关联列，Sr为活跃反向支路关联列：

    C*dv_node/dt + B*i + Sg*j_gate - Sr*r
        = -Cfull[internal,vin]*dVin/dt + e_o*(i_other-i_load)

栅极导通支路满足原电压为0，活跃反向支路满足原电压为-Vf。
对固定Vf求导，二者都要求该支路电压导数为0。
联立KCL及这些导数约束，得到节点导数和支路电流，再检查反向电流符号。

开关电容、串联电容、输出Co和电感方程全部复用D03；不因为加入反向支路就删电容。
状态不重置；已经越过允许电压边界的输入会报出具体开关，要求回退并定位边界，
不会把电压投影回钳位值。

## 4. 活跃集合检查与不唯一性

实现对当前位于边界的关断支路枚举反向导通组合，不提前指定一定是某一只开关导通。
每个组合检查：

1. 原状态满足栅极电压约束和所有关断支路g>=0。
2. 支路约束列独立，局部约束方程可解。
3. 活跃反向支路r>=0且dg/dt=0。
4. 边界上未活跃支路r=0且dg/dt>=0。
5. 保存KCL与能量残差，电压、电流及电压变化率容差分别显式输入。

若存在约束相关的理想支路组合，返回DEGENERATE_ACTIVE_SETS_UNRESOLVED。
即使另一些组合找到了解，也不使用伪逆静默认定反向电流分配唯一。
这个状态是保守的：相关组合是否确实可行尚未进一步求解，不等于已证明物理无解。
无奇异组合时，仍比较各候选的节点导数和支路电流；不一致则返回MULTIPLE_LOCAL_SOLUTIONS。

局部唯一导数并不自动意味着每个理想支路电流唯一。对于零电压理想回路，
可能需要有限寄生或额外约束才能确定分流；这些不能通过任意取一个电流解来掩盖。

当只存在零电流支路的活跃标签差别、导数和全部电流都一致时，可返回局部互补检查通过，
但不替控制器选择必须保持哪一个标签。

所有“通过”仅指当前瞬间、给定替代模型、给定容差；不证明可持续到下一事件。
实际参数下的数值条件数和误差收敛也不由合成测试自动保证。

## 5. 模态电流有效域，检查全部三相

`paper_mode_violations`将电路可解与论文模态符合性分开。
以下采用闭域，零值为边界，仍须D04方向检查：

| 模态 | i1 | i2 | i3 |
|---|---|---|---|
| M1 | 不重置入口电流 | >=0 | >=0 |
| M2/M2′ | >=0 | >=0 | >=0 |
| M3 | >=0 | >=0 | >=0 |
| M4 | >=0 | <=0 | >=0 |
| M5/M5′ | >=0 | <=0 | >=0 |
| M6 | >=0 | 不重置入口电流 | >=0 |

M1/M6工作相入口不强制归零，是连续状态模型的明确处理；
不把论文省略入口电流的线性简式用作状态重置依据。
本表不替代电流导数、目标幅值、时长与换流端点检查。

例如M4的i3已经为负时，即使第二相达到目标、电路KCL可解，也必须报iL3_SIGN，
不能继续称其为论文描述的“另外两相正向续流”模态。
此检查与反向互补求解保持独立，后续调度器需要同时调用二者，不能只调用一个。

## 6. 能量、钳位与ZVS不是同一条件

固定压降支路功耗：v*j_rev=(-Vf)*(-r)=Vf*r>=0。
因此完整能量式为：

    dW/dt = Vin*i_in + vo*i_other - vo*i_load
            - Σ Rwinding*i² - Σ Vf*r

理想零压降分支该项为0；不能据此声称真实死区损耗为0。

如果Vf>0，钳位电压是-Vf而不是0。此时把理想栅极直接改为ON会要求电容电压跳变。
本模块拒绝这个不相容切换；若要描述真实有限Ron开通过程，应接另一器件模型，
不能为了“接上下一阶段”把节点电压改成0。

对明确的零压降理想分支，在同一零电压状态将电流从反向支路交给导通沟道，
可以保持电容电压、电感电流及局部导数不变；这是该理想模型下的衔接验证，
不是对实际驱动延迟的测量或保证。
