# D19：不重置状态的完整单周期尝试器

## 目的与依据

将D18高侧导通与D17四种交接动作，按D15的M1–M15表连接，
输入一个SH1开启截面，尝试返回下一SH1开启截面。
目的首先是保证失败不会在模块拼接中丢失，而不是调出一个好看的周期。

严格沿用P25原生三相单模块、线性常量元件、全部开关寄生电容、
动态Co、恒定电流端口、理想零压降反向支路和零延迟控制。
不新增实际器件参数、不改alpha、不修改旧失败种子。

## 调用和返回契约

模块：src/scb_ivr/p25_period_attempt.py。

attempt_period接受原始Memory、元件、端口、控制策略、
显式四类搜索时长上限和各层数值容差，顺序调用：

    高侧导通 → 低侧准入 → 下一相过零 → 负目标 → 下一高侧准入

三组执行分别对应M1–M5、M6–M10、M11–M15。
搜索上限只是本次数值搜索范围，不是强制切换时间；没有找到事件就停止，
不能写成“电路无解”或到时强行开关。
没有安装峰值观测器，也不把关断电流当峰值。已有峰值记录原样保留；
下一相所需参考缺失时，执行器在相应过零事件拒绝控制动作。

每个PeriodStep保留模态、相号、真实入口Memory和完整动作结果，
包括候选失败事件、根括区、停止原因和局部电气检查状态。
下一步直接使用前一步返回的同一个Memory，不另造初值。

独立核对每次成功交接：

- 同一连续流到达该时刻的全部电压、电流必须与交接后严格一致。
- 拓扑边界、run_id、clock_id不变。
- 下一模态相号和栅极与D15一致，只有M15→M1允许周期计数加1。
- 没有声明观测器时峰值记录不得变化。

失败时返回最后接受的入口和失败阶段；不把越界的试探积分点当作接受状态。
若真走完，返回名为NEXT_SH1_SECTION_REACHED_NOT_PERIODICITY，
仍须用D08比较全部电气及控制状态，不直接宣布稳态或稳定性。

## 同一旧种子的结果

沿用D12/D13/D14的合成种子、元件、alpha=5%、公共Ton=0.02 s，
及第二相20 A声明峰值参考。不是论文工作点。

| 已执行阶段 | 结果 |
|---|---|
| M1 | 原Ton末端关断，进入M2 |
| M2 | SL1准入，进入M3 |
| M3 | i2过零并锁存−1 A目标，进入M4 |
| M4 | 目标到达，进入M5 |
| M5 | domain.iL3先发生，停止，不生成M6状态 |

失败时刻约4.137001278 s，与此前连续失败链一致。
秒级数字来自F/H/s合成夹具，不能换成论文纳秒工况解释。
因此本次没有获得周期解；获得的是具有完整轨迹身份和失败记录的尝试接口。

## 五项新增测试

1. 原种子仍在M5失败，逐段Memory连续传递且根时刻一致。
2. 去掉峰值参考后应在M3停止，不能从高侧关断自动补造。
3. 故意缩短搜索上限，仅返回未找到事件，不强行开门。
4. 非SH1截面、残留负目标、非法搜索上限必须拒绝。
5. 故意在交接后将i1加1 A，独立连续性检查必须检测到这颗“雷”。

所有事件筛查仍为有限网格条件性检测；可能漏切触/同格多次过零。
