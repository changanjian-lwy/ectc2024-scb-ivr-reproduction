# D10：从瞬时方程到连续局部换流

2026-09-28。目的：为连续M1→M6交接提供真实的电气状态推进，
并识别目标ZVS事件之前是否已有其他相或关断支路触边。
不是继续扩大参数扫描；不把D09原文公式疑点当作已解决。

## 边界

- P25原生三相；nM显式保留。nM=1禁止非零其他模块注入。
- 复用D03完整节点和所有六个开关电容、两个串联电容、共享Co。
- 常数线性L/C/R、理想导通沟道；参数全部来自调用者，没有论文数值默认值。
- 本次区间内Vin恒定，负载及其他模块电流为显式恒定端口。
  不代表实际负载恒流，也不代表多模块动态已求解。
- 固定栅极模式；反向通道尚未导通。到达反向边界后必须停止/交给其他模块。
- 无状态重置、不冻结串联电压、不添加理想输出电压源。
- 尚不支持输入斜坡、时变负载、非线性Coss、真实驱动、反向活跃区间连续推进。

## 方程和实现

同一模态、上述边界下，D03的KCL和电感方程为常系数仿射系统：

    y = (a1,a2,x1,x2,x3,vo,i1,i2,i3)
    dy/dt = A*y+b
    z=(y,1), dz/dt=G*z
    z(t)=exp(G*(t-t_entry))*z_entry

G从同一约束KCL矩阵直接组装，不靠扰动电压后投影到合法状态来拟合。
初始栅极电压约束先由D03检查。固定Vin下约束导数为零；矩阵指数数值计算
应保持这些约束到舍入误差。指数解是该局部线性方程的表达式，不是无限精度计算。
Co和串联电容的动态始终参与，不采用论文局部恒压/恒流换流时间式替代。

`LocalFlow.at`提供的是事件前方程的数学延拓；超出模态有效域的点
只能用于定位边界，不是已接受物理状态。调用它本身不证明状态可行。

## M2/M5事件筛查

扫描目标Vds、所有OFF支路的Vds+Vrev，以及三相模态电流符号边界。
使用D07分别定位电压/电流根并比较时间窗口；同刻或重叠窗口不任意排优先级。
零压降模型中目标归零和该器件反向边界可能是同一物理时刻，报告两者，
不擅自先开启栅极或先加入反向通路。

**限制：有限采样不能证明没有漏根。** 区间内的切触、两次过零都可能漏检。
故结果仅为`CONDITIONAL_SAMPLED_SCREEN_ONLY`，不是严格首事件证明。
未发现符号括区时写`NO_DOWNWARD_BRACKET_OBSERVED`，不写“不会发生ZVS”。
起点已在边界容差内时写`ENTRY_BOUNDARY_UNRESOLVED`，不加任意epsilon推进。
这意味着本模块目前还不能独自接受真实高侧刚关断的完整入口交接。

## 验证结果与用途

7项专项合成测试通过；全部数值标记为代数夹具，不来自论文工况：

1. 矩阵推进导数与独立调用D03瞬时求解结果一致。
2. 一次推进与分段推进一致；栅极不变而输出电压确实动态变化。
3. 目标零电压与理想反向边界同时出现时保持未排序。
4. 减小非工作相入口电流后，检测到该相过零先于目标ZVS。
5. 起点已在关断支路零电压边界时明确阻塞。
6. 非法开通约束和单模块外来注入被拒绝。
7. M5保留负入口电流、相间节点变化及SH2电压下降。

这些测试证明局部推进/接口的指定行为，不是论文功率、频率、ZVS比例或周期的复现。

## 下一步与通过标准

先补“起点在边界”的方向判定：离开边界进入合法域、需反向钳位、
或退化待定必须区分，不能让零值不断触发或漏掉实际钳位。
