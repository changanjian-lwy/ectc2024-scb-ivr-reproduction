# D31：保留节点残差的换流电荷上界

## 目的与边界

D30仅允许其他相ON节点严格为0，不能直接用于旧连续轨迹。
本次分析LocalFlow已经保留的常量节点偏移ek，不修改入口状态。
P25三相单模块，M5/M10/M15，所有R=0、恒Vin、恒流负载、动态Co；
常量线性开关/飞跨电容全保留，反向支路尚未接管。
来源是D24/D25的网络关系与电感KVL，不是论文另给的一条控制规则。

重要区别：非零ON节点是数值仿射延拓的偏移，不是理想导通开关的精确物理解。
本结果解释这一残差保留的延拓，不认证前序数值误差或理想开关代数准入。
原来的事件控制器、状态与D30严格版本均未替换。

## 推导

q为负电流相，k≠q为其余相，ek=xk0为固定ON节点值。
要求iq0<0、ik0>0、目标V0>0，以及Vo0>max(0,e_k)。
定义（所有时间均相对本模态入口）：

    T = min_{k≠q} Lk ik0 / (Vo0-ek)
    Fbar = min_{k≠q} [Lk ik0 + max(ek,0) T]
    b_j = ij0 + [min(xj0,0) T - Fbar]/Lj, j=1,2,3
    Smin = sum(b_j) - Iload

在0<=t<=T、其他相仍正、iq仍负且未发生其他事件期间：

    Φ = ∫Vo dt
    ik = ik0 + (ek t - Φ)/Lk > 0
    Φ < min_k(Lk ik0 + ek t) <= Fbar
    xq = xq0 + gamma(V0-V) >= xq0
    ij >= b_j

若Smin>=0，则Co*dVo/dt>=0，Vo>=Vo0。
这个结论通过上述入口界建立，不是采样观测，也不把Vo冻结为常数。
对给出T最小值的相，有ik(T)<=ik0-(Vo0-ek)T/Lk=0。
因此本模态保持全部其余相正电流的时间不超过T。

    Qrequired = Cn V0
    Qavailable = ∫(-iq)dt <= (-b_q)T = Qupper

Qrequired>Qupper便排除该固定模态内先ZVS后其他相过零。
更早的反向支路接管或iq过零仍必须交回事件控制器；此式不穿越边界。
Smin<0返回不适用；未违反电荷不等式不代表成功。
ek=0且xq0>=0时，公式退化为D30。

## 旧轨迹的直接计算结果

原D29基线，不改入口残差、初始电流、器件或控制：

| 量 | 合成数学单位下的结果 |
|---|---:|
| M5入口时刻 | 3.4256471053 s |
| x1残差（保留） | -3.0133624e-9 V |
| Vo入口 | 4.0108205722 V |
| Smin | 11.1542261143 A |
| 本模态可用时间上界T | 0.7479766155 s |
| 所需归一化电荷 | 20.3152069950 C |
| 可供电荷上界 | 1.4959532311 C |

所需电荷远大于上界，故此残差保留的固定模态延拓不能在其余相过零前完成目标ZVS。
上界不是实际搬运电荷；D23算出的实际前缀电荷约1.0525 C，低于该上界。
本界也不判定具体哪一相最先过零，精确事件次序仍来自原事件检查。
所有数字来自F/H/s合成夹具，不能用于论文硬件的负电流百分比结论。
