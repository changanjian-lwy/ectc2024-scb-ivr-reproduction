# D14：量化续流裕量，区分测试入口与周期入口

## 目的

解释D13原始连续夹具的最早失败，不改alpha、初始电流或电容电压以制造通过。
固定P25原生三相单模块，nP=3、nM=1；这是数学模型测试，不是论文工况复现。
本次所有数值均沿用D12/D13的合成F/H/s夹具，不作为器件参数库条目。

## 计算方法

D10增加`integrated_coordinates`，用扩展矩阵指数同时计算六个节点电压和三个
电感电流的时间积分。无需假设Vo恒定，不求可能奇异的A逆，不使用采样求积。
这是常系数线性模型的积分表达式，浮点计算不是严格区间算术证明。
与状态推进同样，越过首个事件后的数学延拓不自动具备物理意义。

`p25_freewheel_margin.freewheel_margin`检查当前相确实由低侧ON续流，计算：

    Lk*ik(end) = Lk*ik(entry) - integral(Vo-xk+Rk*ik) dt
    consumed = integral Vo dt - integral xk dt + Rk*integral ik dt
    remaining = Lk*ik(entry) - consumed

输入nP=4或nM>1会拒绝。完整保留非零绕组R及低侧节点残差项，
不把数值容差内的节点电压偷偷清零。
仅在R=0、xk=0时才化为“初始L*i减去输出伏秒”。
返回端点正负状态不证明中间没有过零，不作为首事件定位器或周期证明。

## 原失败点的定量核对

同一D13轨迹，M5入口约t=3.4256471049 s，首个候选iL3=0约t=4.1370012779 s。
以下是合成单位，禁止解读为论文纳秒工况：

| 量 | 第一相 | 第三相 |
|---|---:|---:|
| M5入口L*i，V·s | 31.3084522382 | 2.99999999846 |
| 区间消耗，V·s | 2.99999999902 | 2.99999999891 |
| 剩余L*i，V·s | 28.3084522392 | 约-4.43e-10（根容差内） |
| 末电流，A | 14.1542261196 | 约-1.11e-10（零带） |

第三相收支残差约4.44e-16 V·s。第一相因保留低侧微小节点残差项，
消耗与公共输出伏秒有约1.11e-10 V·s差别，不将它删除。
此时SH2的Vds仍约5.9835116412 V，i2约-1.9597759386 A。
因此当前观察到的是第三相先退出论文M5的正向续流域，不是第二相电流已经回到零。

## 输出电荷收支与入口适用范围

该夹具Co=23 F（测试尺度），Vo从1 V升到4.4072392453 V。
按各段连续轨迹计算输出净充电量：

| 区段 | integral(sum iL - i_load) dt，C |
|---|---:|
| M1 | 0.4799810853 |
| M2 | 6.5011232971 |
| M3 | 49.3777098421 |
| M4 | 12.8900589382 |
| M5至失败 | 9.1176294786 |
| 合计 | 78.3665026413 |

Co*ΔVo=78.3665026413 C，与端口电荷积分一致。
这表明不能把该段当作近似恒定Vo的论文波形来解释，也不能把这种Vo变化归咎于
某个未建模的外部稳压器：当前输出边界是显式动态Co与恒流负载。

**部分周期净充电不证明整个周期不可能闭合。** 后半周期可能放电；这里没有合法
完整周期，也没有求解过该入口的周期性，所以既不能称它稳态，也不能证明周期解不存在。
这组夹具最早用于验证接口/方程，不来自论文周期设计，是失败回归测试而非待调参的原型。
