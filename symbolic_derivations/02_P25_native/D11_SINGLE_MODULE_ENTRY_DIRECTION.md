# D11：P25原生三相、单模块的零边界入口方向

目的：解除D10对“刚关断器件Vds恰好为零”的一概阻塞，同时不把它误当成开通请求。
分支固定P25，nP=3、nM=1、module=1；接口明确拒绝四相及多模块。
没有借用A51的四相时序、工况或把反向导通等同于栅极开启的实现。
借鉴的是分开记录入口状态、细化事件时间、保留失败边界的验证方法。

## 数学依据和范围

D10提供固定模态、常数端口、全部电容保留的仿射系统zdot=Gz。
对关断反向通道定义g=Vds+Vrev，合法未钳位域g>=0。
直接由Gz和支路关联矩阵求gdot，Vin恒定，不通过时间差分或epsilon试跳估算。

在g(t0)=0且导数连续的边界下：

- gdot(t0)>0：存在一个局部右邻域使g>0，可离开反向边界进入未钳位模态。
- gdot(t0)<0：未钳位延拓将越界，需要反向互补求解；本模块不能直接推进。
- gdot(t0)=0或在导数容差内：一阶判断不足，保留未解决，不猜测高阶符号。

数值实现分别指定V、A、V/s、A/s容差。只有精确零且导数超过显式容差才准许局部离开。
小正值落在数值容差带内仍报告NEAR_BOUNDARY_UNRESOLVED；负值报告域外。
不把近零强制投影为零。该实现保守，可能拒绝数值舍入后的合法入口；不能用隐式舍入绕过。

目标开关本身在入口归零，属于待处理的控制事件，不按“离开反向边界”放行。
电感电流起点为零也保持待处理，因为可能承担模态/控制双重角色。
这里不新增高低侧开启命令，不修改任何储能状态。

## 与D10连接

`scan_commutation(..., entry_direction=...)`显式启用D11；不提供时保留D10原来的严格阻塞。
入口容差必须与扫描器一致。只有全部入口项目均为内部点或可局部离开的反向边界时才扫描。
局部离开的支路仍被监视；必须先观察到正值样点，再进行返向过零定位。
若首个样点未见正值，报告ENTRY_RELEASE_NOT_RESOLVED_ON_GRID，不悄悄丢掉可能的短暂往返。

局部导数论证不保证整个采样间隔内安全。有限扫描仍可能漏掉切触或多次过零，
仍标记CONDITIONAL_SAMPLED_SCREEN_ONLY；不升级为严格首事件证明。
目标归零和零压降反向边界同刻出现仍保留两者，交给兼容事件处理，不能任意排序。
