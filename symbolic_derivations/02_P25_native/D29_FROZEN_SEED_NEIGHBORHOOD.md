# D29：冻结边界的初值邻域诊断

后续D33补充：本页13点的i1均为正，不能成为当前M15→M1顺序的周期不动点。
本页保留为局部初值诊断，不将它用于证明周期解附近的行为。
详见[D33](D33_PERIODIC_SECTION_DIRECTION_AUDIT.md)。

## 目的与设置

在D20/D21接口上检查旧失败是否只出现在一个孤立初值点。
不是寻找论文匹配参数，不调器件、Ton、alpha或峰值参考。
全部采用D21完整声明的合成三相单模块边界：

- Coss每库1 F、snubber=0、飞跨17/19 F、Co=23 F。
- L=(2,3,4) H，绕组R=0，Vin=12 V，恒流负载1 A。
- 公共Ton=0.02 s，alpha=5%，三相设计峰值均20 A，理想零延迟/零压降支路。
- 基线六坐标为(a2,x1,Vo,i1,i2,i3)=(4,2,1,20,2,3)。

以上沿用数学夹具，不是器件选型或论文运行点。
相对基线每次只改一个坐标±10%，共基线+12个案例。
±10%是数值局部诊断幅度，与论文负电流比例不是同一个概念。
每段200点和400点各跑一遍，根时间/值容差和搜索时长均不变。

## 结果

13个案例均在M5由domain.iL3先触发，没有返回周期残差。
下表给出合成时间/s；两个网格分辨率结果一致至下列精度：

| 改变的坐标 | 减少10%时失败时间 | 增加10%时失败时间 |
|---|---:|---:|
| a2 | 4.137001278 | 4.137001278 |
| x1 | 4.139057280 | 4.134762587 |
| Vo | 4.219550069 | 4.056029442 |
| i1 | 4.304185904 | 3.989175903 |
| i2 | 4.152862448 | 4.121327190 |
| i3 | 3.882018257 | 4.379818075 |

基线4.137001278 s。失败时间改变不代表周期残差改善，因为这些轨迹均未走完。
a2的两点未改变本次首个i3事件时间，不证明a2不影响目标开关电压或其他范围的事件排序。

## 结论和不能外推的部分

所测邻近点仍有同一障碍，不是单一初值或200点网格独有现象。
这不是区间认证、全局搜索或无周期解证明，更不能推断实际P25硬件表现。
不能将扩大任意搜索范围、调器件或改变参考峰值作为本结果默认授权的下一步。
