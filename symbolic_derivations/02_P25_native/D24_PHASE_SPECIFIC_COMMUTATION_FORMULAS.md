# D24：三相换流的不同闭式公式

## 目的与来源

D23用完整矩阵求得电流到目标Vds的传递系数。本次独立从D03物理连接消元，
不调用矩阵求逆来定义闭式公式，再与原全网络KKT逐项比较。
来源是已锁定的P25拓扑及D15循环模态映射，不声称以下表达式逐字来自论文。

边界：P25原生三相单模块；恒Vin；两相低侧理想ON、其他栅极OFF；
无反向钳位正在导通；线性常量电容。保持全部飞跨和开关电容，不预设阶梯电压。

## 符号

Hk、Bk分别为高/低侧的总电容库值（Coss+已声明snubber）。
F1、F2为两只飞跨电容。全部为正。
Cn定义为dVds_target/dt=iq/Cn中的网络归一化电容，不是某只Coss。

## M5：下一相为2，目标SH2

令：

    A=H1+F1
    K2=H3+H2*A/(A+H2)

由于x1、x3由ON低侧约束不变，a1节点KCL给出：

    (A+H2)*da1 = H2*da2
    (K2+F2)*da2 = F2*dx2
    (B2+F2)*dx2 - F2*da2 = -i2*dt

目标是Vds_SH2=a1−a2，因此：

    Cn_M5 = (A+H2)/A * [B2 + (1+B2/F2)*K2]
    dVds_SH2/dt = i2/Cn_M5

这里da1、da2、dx2表示微分，不是假定这些电压为零。

## M10：下一相为3，目标SH3

仍有A=H1+F1。消去a1后：

    K3=F2+H2*A/(A+H2)
    (K3+H3)*da2 = H3*dx3
    (B3+H3)*dx3 - H3*da2 = -i3*dt

目标为a2−x3，而不是−a2，得到：

    Cn_M10 = B3+H3+B3*H3/K3
    dVds_SH3/dt = i3/Cn_M10

## M15：下一相为1，目标SH1

消去a2，a1对固定电位的等效电容为：

    K1=H1+H2*(H3+F2)/(H2+H3+F2)
    (K1+F1)*da1 = F1*dx1
    (B1+F1)*dx1 - F1*da1 = -i1*dt

目标为Vin−a1，Vin恒定：

    Cn_M15 = B1+(1+B1/F1)*K1
    dVds_SH1/dt = i1/Cn_M15

## 规律和限制

即便H1=H2=H3、B1=B2=B3，三相Cn一般仍不同。
当F1、F2同时远大于开关电容时，分别趋近：

    M5: B2+H2+H3
    M10: B3+H3
    M15: B1+H1+H2

所以相序可以复用，但不能把第一组的“电容之和”仅换相号就复制到最后一相。
Co和L没有直接出现在这个瞬时传递系数里，但它们决定iq(t)，
因此仍影响换流时间、竞争事件和周期性，绝非可以从全模型中删除。

## 验证

代码p25_commutation_closed_form独立计算上式。
4项测试：非对称电容库含snubber，在F和nF两种缩放下，
每相系数与原KKT一致；等开关电容时三相不同；L/Co不改变瞬时系数；
非单模块/非升压换流被拒绝。
还检查目标电压对其他状态的瞬时系数在数值误差内为零。
D23仍完整保留浮点计算出的微小系数，不强行删除。
