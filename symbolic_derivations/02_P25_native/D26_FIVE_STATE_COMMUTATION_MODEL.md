# D26：保留三相与动态输出的五状态换流模型

## 目的与范围

从D24/D25闭式关系独立组装M5/M10/M15局部连续流，
与原D03/D10完整节点KKT模型交叉核对。
不是将整个周期降成五状态，也不是删掉开关或飞跨电容。

边界仍为P25三相单模块、恒Vin、线性常量元件、固定栅极、
另两相低侧ON、无反向钳位正在导通、恒流负载、动态Co。
电容经闭式Cn和gamma进入模型，入口电压保存被消去坐标的积分常数。

## 五个动态状态

    z=(Vds_target, i1, i2, i3, Vo)

设q是正在负向换流的相，入口值带0下标：

    V' = iq/Cn
    iq' = [xq0 + gamma*V0 - gamma*V - Vo - Rq*iq]/Lq
    ik' = [xk0 - Vo - Rk*ik]/Lk                 (k!=q)
    Vo' = (i1+i2+i3-Iload)/Co

其中其他相xk0为低侧ON时的常量；若输入有数值容差内残差也完整保留，
不投影成零。上述为仿射系统，可用6×6扩充矩阵指数计算。
原完整节点流用10×10扩充矩阵，不调用它来生成本降阶矩阵。

保留其他两相电流，是因为它们经Co影响Vo，
Vo又同时影响换流相和续流相。不能把这五状态模型再无条件简化成二状态孤立LC。

## 验证

模块p25_reduced_commutation只返回目标电压、三相电流和输出电压，
无栅极动作、无重置、无事件准入逻辑。
4项新增测试：

1. 三相、不等开关电容和非零绕组R，在多个时间点与完整流一致。
2. 原M5失败边界仍得到i3约零、SH2约5.98351164 V、Vo继续上升。
3. 微小ON节点残差作为常量项保留，不删除。
4. 错误相位栅极与倒退时间被拒绝。

测试包括数学延拓点，超出物理事件后的点仅用于方程等价性验证，
不能视为已通过的电路轨迹。数值一致性不等于完整周期可行性。
