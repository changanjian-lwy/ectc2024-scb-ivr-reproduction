# D28：已接受轨迹的电荷与伏秒账本

## 目的和边界

将D14局部积分推广到D19同一条尝试轨迹的所有已接受段，
检查漏段、重新拼接和状态变化与积分收支是否一致。
P25三相单模块、器件、动态Co和恒流端口等边界不变。
不是新的仿真控制，也没有重置失败后的状态。

## 逐段累计

使用D10扩充矩阵指数得到坐标积分，不做稀疏波形梯形积分。

    Qout = sum_segments integral(sum ik - Iload) dt
    Phi_k = sum_segments integral(xk - Vo - Rk*ik) dt

分别与Co*(Vo_end−Vo_start)、Lk*(ik_end−ik_start)比较。
另外累计全部九个电容库的支路电荷增量，与对应C*DeltaV支路比较。
包含六个开关电容库、两飞跨电容和输出电容，不只看Vo。

各段入口必须等于前段返回Memory，模态编号不能跳跃。
未接受的失败段不积分：根括区右端或扫描网格点只是试探信息，
不能默认作为已接受的电路状态。
完整周期标签要求15段全部接受；否则标ACCEPTED_PREFIX_ONLY。

## 同一旧基线

仅累计接受的M1–M4，不含失败M5：

| 段 | 输出净充电/C |
|---|---:|
| M1 | 0.4799810853 |
| M2 | 6.5011233065 |
| M3 | 49.3777098359 |
| M4 | 12.8900589340 |
| 合计 | 69.2488731617 |

Co*DeltaVo与合计一致；三相伏秒收支残差约0、1.78e−15、−1.78e−15 V·s。
数值为原F/H/s合成夹具，不是论文工况。
这与D14不同：D14另外诊断延拓到M5失败边界，本次只核查正式接受前缀。
不能把两个不同覆盖范围的合计混在一起。

前缀充电不证明全周期不闭合；只有完整可达后，
周期解才应同时满足全部电容净电荷和电感净伏秒为零。
这里验证的是积分恒等式，不是已经达到那些零净变化条件。
