# D27：五状态换流流的完整节点重建

## 目的和边界

补齐D26未输出的节点电压，检查是否丢失非目标开关的信息。
仍为P25原生三相单模块M5/M10/M15、恒Vin、线性电容、固定栅极、
无正在导通的反向钳位、动态Co。没有换参数、改变事件顺序或替换主周期推进器。

## 重建式

沿用D24/D25定义，令DeltaV=Vtarget(t)−Vtarget(0)。
按(a1,a2,x1,x2,x3)排列，节点增量为r*DeltaV：

    M5:  r=(-H2/A, -(A+H2)/A, 0, -gamma, 0)
    M10: r=(-H2/(A+H2)*H3/K3, -H3/K3, 0, 0, -gamma)
    M15: r=(-1, -H2/(H2+H3+F2), -gamma, 0, 0)

每个节点都从同一入口的自身电压加增量，Vo使用五状态模型独立输出。
不以固定阶梯替代入口，不把低侧节点的微小数值残差清零。
六个开关Vds由原Snapshot的同一物理连接计算，Vin保持原值。
电流、相序、模型身份和周期号不重新定义。

## 核对

新增3项测试：

- 三相、非对称开关电容、非零R，在多个时刻全部节点和六个Vds与原流一致。
- 用独立时间括区在重建轨迹上定位旧i3过零根，与原检测结果一致；
  同时SH2仍大于5.9 V，不产生假ZVS。
- M15两个ON低侧节点的微小残差原样保留。

这些是合成模型等价性检查，不是论文完整周期或硬件结果。
