# D23：M5失败时还差多少换流量

## 目的与来源

D22说明旧轨迹到负目标时第三相仍有3 V·s，但不能判断随后换流能否完成。
本次用D10完整仿射节点流及D14坐标积分，对M5同一失败段做电压/电荷收支。
P25原生三相单模块、恒定Vin和电流端口、线性常量电容、理想栅极等边界均不变。
所有开关电容、有限飞跨电容和动态Co保留，不换成孤立LC近似。

## 一般公式

设九个电气坐标为z，常数扩充为y=(z,1)，D10给出dy/dt=G*y。
目标开关的节点电压选择向量为a，Vin恒定，因此：

    dVds/dt = a^T * G_voltage * y = w*y
    Vds(t)-Vds(0) = sum_j w_j*integral z_j dt + w_const*Delta_t

这保留所有坐标项与常数项，不删除浮点计算中的微小耦合系数。
对M5/M10/M15，令下一相q的电流系数k=w_iq>0，定义：

    C_norm = 1/k
    Q_req = C_norm*Vds(0)
    Q_phase = -integral iq dt
    Q_other = -C_norm*(除iq外的全部电压增量)
    Q_remaining = C_norm*Vds(t)

收支恒等式：

    Q_req - Q_phase - Q_other = Q_remaining

C_norm只是完整线性网络到目标电压的传递归一化，
不是某一个晶体管的Coss；这些Q也不是直接照搬器件datasheet的Qoss。
只有到目标电压为零，才有Q_remaining=0。端点收支不证明它是首个可行事件。

## 同一旧失败段的结果

沿用D21基线M5真实入口，终点取检测到的i3过零括区右端。
以下全是合成F/H/s测试单位，不对应论文工况：

| 项目 | 数值约 |
|---|---:|
| M5开始时刻 | 3.4256471053 s |
| 第三相过零时刻 | 4.1370012783 s |
| SH2入口Vds | 6.310445770 V |
| SH2终点Vds | 5.983511639 V |
| C_norm | 3.219298246 F |
| Q_req | 20.315206995 C |
| Q_phase | 1.052498474 C |
| Q_remaining | 19.262708521 C |

Q_phase/Q_req约5.2%。其他坐标项被保留，其合计电压贡献在此线性合成网络中
仅约4.12e−18 V。主系数k≈0.310626703 V/C。
这量化了第三相电流域先失效时，目标高侧电压为何仍离零很远。
不能从这个合成数值推出实际器件所需alpha或snubber值。

## 结论与下一步

负目标到达和ZVS完成需要同时满足两类约束：
另一相的续流伏秒仍有余量，以及目标开关的电压换流量已完成。
D22与本次恒等式可共同用于定位候选失败，但都不是充分条件。
下一步应在冻结器件/控制边界下评估候选状态的两类约束，
而非把负电流比例或电容值作为隐含拟合旋钮。
