High-Performance Computing Systems*, APEC 2025，DOI 10.1109/APEC48143.2025.10977125。
本次直接检查本地PDF的Fig. 1–3、Sec. II及Sec. III起始段，印刷页2101–2104。
不是依据旧仿真倒推论文含义。

- **分支：P25，nP=3。** nM保留为必填系统参数，module指定当前分析哪个模块。
  Sec. II展示双模块；不能把单模块事件定义说成已经求解双模块耦合。
- 未调用P24拓扑、1%–2%阈值、四相轮转或P24器件数据。

  原图采用MOSFET/二极管符号，不代表GaN具有硅MOSFET体二极管的恢复模型。

## 2. 物理事件链，不以t编号作主键

原文证据标签为P25_EXPLICIT；把文字拆成独立事件并制定软件接口属于PROJECT_DECISION。
二者分别存储，不把我们的细分接口冒充论文原始控制器。

| 阶段 | 高侧ON | 低侧ON | 三相状态及结束事件 |
|---|---|---|---|
| M1 | SH1 | SL2、SL3 | iL1上升，iL2/iL3续流下降；SH1导通区间结束 |
| M2 | 无 | SL2、SL3 | iL1维持正值进行电容换流；SL1的Vds到零 |
| M2′（可选） | 无 | SL2、SL3 | SL1尚未栅极开启，可能反向导通；等待SL1开启 |
| M3 | 无 | SL1、SL2、SL3 | 三相电流下降；**iL2**向下过零 |
| M4 | 无 | SL1、SL2、SL3 | iL2负向增长，iL1/iL3仍正向下降；达到负电流目标 |
| M5 | 无 | SL1、SL3 | SL2实际关断后，iL2驱动换流；SH2的Vds到零 |
| M5′（可选） | 无 | SL1、SL3 | SH2尚未栅极开启，可能反向导通；等待SH2开启 |
| M6 | SH2 | SL1、SL3 | iL2由真实入口值上升，其他两相续流；SH2导通区间结束 |

表中“其他高侧OFF”依据Fig. 2栅极波形结合Fig. 3，而不是仅按图中路径是否画黑判定。
M2′/M5′不是每次必然经历的固定时间段；零电压到栅极开启之间也不能一概称为已经反向导通。

独立事件顺序：

`SH1开启 → SH1关断 → SL1零电压 → SL1开启 → iL2过零 → iL2负目标`

`→ SL2实际关断 → SH2零电压 → SH2开启 → SH2关断`

**达到负目标、发出关断命令、实际关断不能默认具有已知延迟。**
本规范记录目标事件和实际关断事件，命令/驱动适配器尚未实现；两者之间若有延迟，
这段新增区间必须继续推进电路状态，并检查其他相仍符合当前模态，不能冻结电流等候。

Vds第一次到零与栅极开启分别记录；开启瞬间还要重新满足ZVS条件。
单凭“早些时候曾经到零”不够，也不能默认立刻发出栅极命令。

## 3. 原文时标冲突：保留，不编造延迟

- p2103：Interval 4标作[t3,t4]，结束时控制器关断SL2。
- p2104：Interval 5却标作[t5,t6]，又说SL2在t5关断。
- 同页Interval 6重复标作[t5,t6]，描述的却已是SH2开启后的上升段。
- 因此不能凭编号差把t4解释为命令、t5解释为延迟后的实际关断。
  旧 `physical_events.py` 中相关映射不得作为该延迟已获原文证明的依据。
  本模块不调用该旧表；没有修改旧实验的运行语义。
- p2103中SL1的零电压条件须在开通时满足，但首次达到零可以早于开通，
  正是可选M2′存在的原因；不能锁死为同一个时刻。

以上只说明文字标号不能直接执行，不据此否定论文物理机制。

## 4. 负电流：阈值、参考值和时间分开

P25 Mode 4写5%–10%；Sec. III/Eq. (20)设计段写up to 5%。
本模块alpha专属于Mode 4范围，必须由调用者显式给定；不自动把Eq. (20)推广到10%。

定义正值参考峰值 Ipk2_ref > 0，目标 i2_target = -alpha × Ipk2_ref。
参考必须属于**第二相**，不能使用当前第一相峰值冒充。
可执行的参考策略仅列“已测得的上一峰值”或“显式设计参考值”，
属于项目控制选择，论文并未在这段文字中规定峰值采样/保持算法。
不能用尚未发生的未来峰值作为实时控制输入。

以 τz 为iL2向下过零时刻。按Eq. (11)的定L、定Vo、定压降近似：

    di2/dt = -(Vo + Vrev)/L2
    i2(t) = -(Vo + Vrev)(t - τz)/L2
    Δt_negative = -L2*i2_target/(Vo + Vrev)
                = L2*alpha*Ipk2_ref/(Vo + Vrev) > 0

Vrev在这里明确是非负压降幅值，不是带符号的Vds。
这证明的是到达负目标所需的局部时间，不是ZVS完成时间。
L和参考峰值不变时，目标幅值增大使该时间同比增加；没有据此承诺ZVS一定成功。

需要保留的两个公式边界：

1. Eq. (12)印刷形式没有显式L2因子；若分子按电流、分母按电压理解，
   量纲不成为时间。本模块从Eq. (11)求解上式，标P25_DERIVED，不冒充照抄Eq. (12)。
2. Eq. (11)的固定压降符号不能直接推广到负电流下的Ron模型。
   对低侧接地、忽略其他寄生的导通沟道，KCL/KVL给出
   `Vds_low = -Ron*i2`、`L2*di2/dt = -Vo - Ron*i2`。
   进入负电流后电阻项符号效果改变。非零Vrev版本仅检验论文局部近似的代数，
   不宣称它就是实际GaN沟道模型。Ron版本应另建器件分支，不在本次偷换。

## 5. 状态不重置：Mode 6还不能直接抄公式推进

定义X2为第二相电感左端/低侧漏极节点，iL2正向由X2流向输出，
VCs1/VCs2按Fig. 1串联电容标注方向。理想SH2与SL1导通、忽略导通压降时：

    X2 = VCs1 - VCs2
    vL2 = X2 - Vo = VCs1 - VCs2 - Vo
    iL2(t) = iL2(τH2_on) + (VCs1 - VCs2 - Vo)(t-τH2_on)/L2

这是Fig. 1节点关系加KVL的推导，不是Eq. (15)逐字抄写。
Eq. (15)印刷式未写-Vo与入口电流项；本次只记录差异，不在旧求解器里暗改。
第二相开启时电流可能仍为负，必须延续换流后的实际值，不能自动归零。
电感电流和电容电压连续性的使用以有限电压/电流、无冲激重置为边界；
理想开关约束若引起不相容状态，必须报错或另定义冲激/寄生模型。
