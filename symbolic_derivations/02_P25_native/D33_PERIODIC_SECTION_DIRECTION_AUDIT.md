# D33：任意初值夹具不等于周期返回截面

## 本次发现和纠正

旧D12/D21/D29入口i1=+20 A，可用于初值积分和局部失败诊断，
但不属于当前P25事件顺序的周期返回截面。
D29的13个邻近点i1均为18、20或22 A，同样不能成为该顺序的精确周期不动点。
这些测试没有报成功，已有局部计算仍有效；但不能把继续扫描这片区域
作为寻找周期解的有针对性方法。此前缺少这个提前排除检查。

## 依据与推导

来源是已锁定的P25事件模型，不新增硬件或论文参数：

1. `p25_cycle_modes.current_signs`中M15为(-1,+1,+1)。这是P25一相负电流
   换流模式的第三相循环映射，不声称论文逐字列出了“M15”。
2. `enter_next_high`要求目标SH1换流事件先于其他事件；电流过零或反向支路
   先接管不能被跳过。
3. M15→M1只改变栅极与控制记忆，不改变电感电流。

所以对严格分离的有效事件：

    i1(M1返回入口) = i1(M15结束) < 0

若考虑零电流重合边界，至少必须处于i1<=0的闭包；重合是否允许须另行判定。
因此i1初值>0不可能等于上述返回值。
到非正返回域的电流距离下界为max(i1初值,0)，单位A。
负电流初值仅满足必要条件，不证明能经过M1–M15或形成周期。

数值扫描和事件容差仍不是严格首根认证。本检查说明精确模型的必要方向；
显式电流决策裕量内的接近零值返回“未决”，不强行分正负。
该裕量不是D08的完整状态返回容差，不能替代全部状态/控制记忆闭合检查。

## 实现及边界

独立模块`p25_section_necessity.py`提供截面必要性检查。
不修改D20的通用初值构造接口，否则会破坏有用的非周期诊断夹具。
不篡改D29输出，不将+20 A自动翻转为-20 A，不更换器件、Ton、alpha或峰值参考。
4项测试覆盖正入口排除、负入口只作必要通过、零附近未决和非法裕量拒绝。

## 下一步的明确目的

下一次候选可达性工作应先经过本检查，在i1<0的返回截面区域内构造新初始猜测，
完整保持D20物理/控制契约；然后从M1重新积分，记录最早失败事件。
还须同时满足OFF电压间隙、其他相电流符号、完整模式域和控制条件。
新初值是周期方程的待求坐标，不是改写已积分轨迹，也不是论文给定数值。
目前没有据此宣称新的完整可行轨迹、周期解或论文复现成功。
