# D30：换流电荷与其余相续流预算的解析必要条件

## 目的、来源、没有改变的东西

不再扩大D29初值扫描。用D24的网络消元式和D25的电感/输出方程，
判断某个换流入口是否已经不可能在其他相过零前达到目标Vds=0。
这是项目自行推导的必要条件，不是论文提供的判据。
不改任何既有轨迹、器件值、控制比例或峰值参考，不新增SPICE实验。

## 严格适用范围

P25原生三相单模块；M5/M10/M15，q表示本次负电流相。
保持完整常量线性电容网络、动态Co、恒Vin、恒流负载。
所有绕组R严格为0；另两相低侧ON，节点电压严格为0。
入口iq0<0，其余ik0>0，Vo0>0，目标V0>0，xq0>=0。
仅研究目标V归零之前且iq<0、其余相电流>0、没有反向支路接管的固定模态。
任一其他事件先发生必须退出本模态，不得用公式跨越。

## 推导

记Φ(t)=∫Vo dt，入口时间取0，所有量均来自同一入口：

    F = min_{k≠q}(Lk ik0) > 0
    Cn V' = iq
    xq = xq0 + gamma (V0 - V), gamma>0

iq<0使V下降，故xq>=xq0>=0。在其他相尚未过零期间：

    ik = ik0 - Φ/Lk, k≠q
    Φ < F
    iq = iq0 + (∫xq dt - Φ)/Lq >= iq0 - Φ/Lq

从而输出电流之和满足：

    Σik - Iload >= Σik0 - F Σ(1/Lk) - Iload = Smin

如果入口计算出的Smin>=0，那么Co*dVo/dt>=0，Vo>=Vo0。
这里不是假定Vo恒定：由电流界推出它不下降。
连续性保证Φ从0增长；上述界在Φ达到F或其他事件发生前自洽。

因此，在保持该模态的条件下，其他相过零前的时间和负电流大小上界为：

    τ <= F/Vo0
    -iq <= -iq0 + F/Lq

目标Vds归零需要的归一化电荷，以及该时间内最多能提供的电荷满足：

    Qrequired = Cn V0
    Qavailable <= (-iq0 + F/Lq) F/Vo0 = Qupper

若Qrequired>Qupper，则本模态内不可能先完成目标ZVS再发生其他相过零。
若Qrequired<=Qupper，只能说这个保守判据未排除，绝不代表ZVS成立。
Smin<0也不代表失败，仅表示本证明不能建立Vo下界。

## 实现、故意拒绝的应用

`p25_commutation_necessity.py`返回必要条件状态，且分开记录C、s、A单位。
调用方显式给出电荷决策裕量；浮点求值不是区间算术认证。
完整事件控制器未被替换，反向支路准入仍由原有检查负责。

旧D29连续轨迹在M5入口的另一个ON节点带有非零数值残差。
本判据明确返回NOT_APPLICABLE，没有把它抹成0后冒充原轨迹的解析证明。
因此D29失败仍是数值事件诊断，D30没有将其升级为严格不可达证明。

新增4项检查：三相独立合成入口均能触发电荷不足判据；
旧轨迹残差拒绝；非零R或未满足Vo单调下界时不宣布不可行；
较大电荷预算不被误报为成功。
