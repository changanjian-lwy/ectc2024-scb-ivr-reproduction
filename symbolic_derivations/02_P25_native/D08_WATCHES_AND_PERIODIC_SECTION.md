# D08：监视清单与周期截面状态

2026-09-28。P25原生三相，沿用D03–D07电路、反向通道和控制边界。
本模块不改参数、不删寄生电容、不运行新的论文工况。

## 1. 当前理想模型必须监视的项目

`p25_watch_contract.py`按当前阶段、相号、栅极和反向活跃集合生成监视规范：

1. 当前控制事件：Ton终点/低侧归零/下一相过零/负目标/下一高侧归零。
2. 所有关断且尚未反向导通的支路：Vds+Vf的边界进入。
3. 当前反向导通支路：反向电流r下降到零的释放边界。
4. 各相的模态电流符号边界，不只包含目标相。
5. 外部端口显式声明的不连续事件，例如输入斜坡结束或负载阶跃。

已栅极开启器件的电压约束属于代数检查，不能把一直为零的Vds当作重复根事件。
活跃反向支路也不再不断触发电压为零，而是监视释放电流。

同一物理量可能同时具有控制意义和模态边界意义，例如ALL_LOW中iq过零。
规范保留这两种角色；整体调度层后续应明确合并或联合处理，不按任意优先级丢弃其中一个。

监视规范不是已安装的检测器。`missing_watches`检查调用方提供的安装名称是否遗漏；
它不能证明某个同名回调实际计算了正确量，也不能判断外部端口是否漏报事件。
反向活跃集合须由D05合法非退化解提供；本函数只核对名称/栅极一致性，不重新求解。

独立代数/边界检查保持：栅极电压、KCL、互补条件、局部非退化性、储能状态连续性、模型身份。

## 2. 统一周期截面

选取SH1刚刚开启后的截面，要求：

    phase=1, stage=RISE
    SH1 ON, SL1 OFF, SL2/SL3 ON
    进入本阶段的相对时钟为0
    本次负目标锁存已清空

比较相邻两次该截面，时间必须前进，周期编号恰好加1。
不能把不同相位的“看起来相近”的状态直接拿来比较。

绝对时间和递增周期计数是记账坐标，不要求数值回到原值；
但它们必须属于同一实验、同一时钟、同一模块和同一边界。

## 3. 返回状态包括什么

`p25_periodic_section.py`从真实端点计算并比较：

- 六个开关位置的电容电压，覆盖Coss与并联snubber；同位置电容共享电压但参数仍分别记录。
- Cs1、Cs2电压和Co电压。
- iL1、iL2、iL3。
- Vin（显式保留端口检查，即使部分信息在支路电压中冗余）。
- 三相已知峰值参考幅值、参考类型/来源。
- 已测量峰值的相对年龄：t_section-t_available，而非绝对时间戳。

峰值未知不会补成0；若缺少控制记忆，则阻塞周期状态检查。
设计参考的时间戳只用于因果准入，稳定的设计值不要求每周期更新其时间戳。
测量参考年龄保留是保守的记忆闭合要求；若后续证明某记忆量完全不影响未来动力学，
可明确作约化处理，不能为了通过结果临时删去。

当前理想反向通道没有Qrr、热或其他内部动态状态。
若加入真实器件、峰值跟踪窗口、驱动队列、滤波或其他控制器状态，必须扩展截面坐标，
不能继续沿用这份有限状态清单而声称完整周期闭合。

## 4. 有单位的残差分开归一化

对每个连续坐标x_j：

    delta_j = x_j(end)-x_j(start)
    allowance_j = atol_unit(j) + rtol*max(abs(x_j(start)),abs(x_j(end)))
    rho_j = abs(delta_j)/allowance_j

V、A、s的绝对容差分别显式输入，最后才对无量纲rho取最大值。
不再将电压和电流直接混成max_abs，也不让某个大电流缩小电压误差的相对比重。

所有坐标rho<=1时返回state_returns=True，语义仅为“两个给定截面的状态返回”。
它不是完整周期仿真通过，也不是论文复现通过。

## 5. 不得比较不同问题

两端必须使用完全相同的：

- 组件定义（含Coss/snubber、Cs/Co、L/R）；
- 反向通道模型及声明；
- 控制策略、共同Ton和容差定义；
- 外部端口模型身份；
- P25分支、nP/nM、模块号、输出边界和alpha。

同一截面身份和理想ON栅极电压也要检查，不能拿非法开关状态比较。
修改输出电容或把动态输出换成理想电压钳位会被拒绝，而不是算出一个“更好”的闭合误差。

## 6. 状态返回仍不等于周期解已证明

比较器不知道两端之间是否真有一条满足所有方程/事件的轨迹。
外部端口模型ID相同也不证明其激励在该时间间隔上重复：
例如同一个输入斜坡函数在两端可能不处于相同阶段。

要认定完整周期解，还必须：

1. 连续轨迹满足DAE、所有有效域和事件先后关系；
2. 全周期没有漏掉其他相越界或反向路径变化；
3. 外部输入、负载、其他模块和测量策略在所选周期上相容，或其状态一并闭合；
4. 补足所有内部记忆状态；
5. 在需要匹配论文频率时独立检查得到的周期，而不是强制截取到名义周期。

周期解存在、局部稳定、从零启动可达是三个不同结论。
本模块没有证明后两项，也没有默认前面五条已经成立。
