# D37：同一条轨迹上的负目标与换流预算

## 本次只做什么

复算D36的两组入口x1=3/4 V、Vo=0.5 V候选，不改初值、器件或控制。
沿M4/M5同一连续状态计算电感伏秒与换流电荷，不拼接模态、不重新赋电压阶梯。
完整三相电流/节点由既有模型同步演化，仍为F/H/s合成边界，非论文硬件值。
依据D03电感KVL、D23电荷账和D31适用条件，无新增文献参数。

## M4：达到负目标要消耗多少续流预算

令Φ=∫Vo dt。当前x2=0、R2=0，所以达到i2,target=-1 A需要：

    Φrequired = L2(i2,entry - i2,target) ≈ 3 V·s

第一相不把节点残差抹掉，其精确积分账为：

    L1 i1,end = L1 i1,entry + ∫x1 dt - ∫Vo dt - ∫R1 i1 dt

| 原初始x1 / V | M4入口L1i1 / V·s | 实际∫Vo / V·s | M4结果 |
|---|---:|---:|---|
| 3 | 2.330986331 | 2.330986332 | i1先到零，i2仅到约−0.776995 A，未达−1 A |
| 4 | 4.588317866 | 3.000000000 | 达到−1 A，剩余L1i1≈1.588317865 V·s |

节点残差积分分别约−4.36e-10、−1.17e-9 V·s，保留在完整数据和残差计算中。
第一组根端点微小负i1属于数值根容差，不强制写为0。

## M5：剩余预算不足以完成SH2换流

第二组M5入口继承全部M4终点电气状态，仅门极改变。
至i1过零，∫Vo≈1.588317865 V·s，第一相剩余预算耗尽。

| 同一M5延拓的量 | 值 |
|---|---:|
| SH2入口Vds | 4.582928805 V |
| SH2竞争根处Vds | 4.234110175 V |
| 所需归一化电荷 | 14.753814660 C |
| 已搬运负电流电荷 | 1.122951204 C，约7.6% |

该M5仅是至竞争根的未接受诊断前缀，不可标为完整M5成功。

## 不能借用前一次的解析上界

这一M5入口：

    dVo/dt = (i1+i2+i3-Iload)/Co ≈ -0.019819177 V/s

输出电压已经下降。D31的充分前提“由电流下界建立Vo不下降”未成立，
因此返回NOT_APPLICABLE，不用上一条轨迹的时间上界替代本次结果。
本次结论来自同轨迹积分与条件数值事件检查，不是D31解析不可达证明。

## 对下一步的约束

在固定M4入口、R1=R2=0及x2=0时：

    L1 i1,exit = L1 i1,entry - L2(i2,entry + alpha*Iref2) + ∫x1 dt

更大的负目标既可能加强下一段换流，也要先消耗其他相的续流预算；
非零x1残差及阶段时长影响仍要保留，不能只调alpha后假定其他状态不变。
本轮未扫描或改变alpha。后续应把目标需求和各相剩余预算联合检查。
