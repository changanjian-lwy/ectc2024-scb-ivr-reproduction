# D06：P25三相理想事件控制与记忆

2026-09-28。继D02事件、D03节点、D04判据、D05反向通道，
本模块仅补离散控制层，不代替连续电路求解。

## 1. 不能混成论文事实的假设

物理顺序以P25 Sec. II/Fig. 2–3为依据。以下软件结构和控制细节为PROJECT_DECISION：

- 理想零检测/命令/驱动延迟必须显式声明，不能默认为真实硬件。
- 三相使用共同Ton=D*T，Ton由外部明确输入，没有默认500ns或其他值。
  接口保留三相位置，但不相等的Ton会被拒绝，须另开优化/扩展分支。
- 负电流比例仍由P25原生分支给定；不引入P24的1%–2%。
- 在目标相电流过零时锁存本次负电流目标，避免随后参考更新使阈值移动。
  这是明确的因果实现策略，不声称论文公布了该锁存细节。
- 本模块不删除任何Coss/snubber，也不改变D03/D05器件模型。
- 从已经合法到达的高侧开启截面开始；这不是从零启动的方法。

## 2. 控制状态

连续状态仍为D03的节点电压与电感电流。控制记忆为：

    m = (k, stage, t_enter, Ipk_ref[1..3], availability[1..3], target_latched)

k为最近一次导通的高侧相，q=1+(k mod 3)为下一相。控制循环为1→2→3→1。
这只轮换开关及事件索引，**不轮换真实节点矩阵**：SH1接输入源，SH2/SH3接串联节点，
它们在实际电路上的位置仍由D03端点表决定，不能当作三个独立同构Buck。

完整软件状态还带分支/nP/nM/模块号、实验/时钟/周期编号，防止混用轨迹。

## 3. 转移表

| 当前控制状态 | 导通栅极 | 触发条件 | 理想动作与下一状态 |
|---|---|---|---|
| RISE | SHk，其他相低侧 | t-t_Hk_on=Ton | 关SHk；DOWN_COMM |
| DOWN_COMM | 除SLk外全部低侧 | Vds(SLk)到零，开启时复核 | 开SLk并锁存；ALL_LOW |
| ALL_LOW | 全部低侧 | iq向下过零 | 锁存本次负目标；NEGATIVE |
| NEGATIVE | 全部低侧 | iq达到锁存负目标 | 关SLq；UP_COMM |
| UP_COMM | 除SLq外全部低侧 | Vds(SHq)到零，开启时复核 | 开SHq，k←q；RISE |

RISE结束由实际高侧开启时刻起算Ton，不由旧的全局名义相位时刻代替。
没有同时强行指定整个循环的频率或相位间隔；最终周期必须由连续电路事件求出后核验。

原文允许的M2′/M5′可由电气反向通道层表示，不等于控制器开启栅极。
本零延迟控制分支不人为添加固定的钳位等待时间。

## 4. 锁存和因果峰值

栅极状态由离散控制状态决定，而不是每个时刻直接令 gate=(Vds==0)。
因此零电压准入以后，低侧不会因为该比较条件的变化而丢失导通命令。

可用峰值必须包括相号、正值幅值、来源/测量窗口说明和available_at时间。
允许设计参考或已经测得的过去峰值；初始未知项为None。
下一相过零时没有可用参考，就阻塞，不自动估成2*Iavg或借用本相峰值。

    I_target_latched = -alpha*Ipk_q_available

在NEGATIVE期间更新峰值记录不会改变已经锁存的目标；新记录只供后续使用。
旧参考不会自动视为“最新准确峰值”：参考新鲜度/误差属于后续测量策略。

高侧关断时不自动执行Ipk←i(t_off)，因为包含换流时峰值可能发生在其他瞬间。
严格连续测量可定义为指定过去窗口内的sup i(t)，但本模块未实现测量器或连续最大值追踪。
测试提供的是有标签的人工历史参考，不是对真实峰值观测的证明。

## 5. 守卫和状态更新

计时事件必须准确位于Ton终点；早到/晚到均拒绝。
物理事件必须提供同一阶段的左侧正判别值和根处容差内残差。
大步长跨过目标不算精确到达；未知反向准入不能由控制器自行补造。

每次转移同时检查三相电流符号域，不能只保证工作相达到条件而忽略其他相已出界。
所有已开启的理想开关须满足自身Vds=0约束。

电气状态更新为恒等映射：

    v_node^+ = v_node^-
    i_L^+ = i_L^-
    Vin^+ = Vin^-

只更新栅极、阶段、时钟和控制记忆。不把负入口电流归零，不重置飞跨或寄生电容电压。
加入新理想导通约束后若状态不相容，立即报错，不投影/修改电压。

容差是显式的独立V/A/s数值检查量，不是实际器件电压或时间参数。

## 6. 数学系统还不能省掉的连接

完整混合模型需要共同满足：

    E_sigma(x)*xdot = f_sigma(x,u,j)
    理想栅极约束 + D05反向通道互补约束
    模态有效域
    g_event(x,m,t)=0及方向、准入条件
    (x^+,m^+)=(x^-,R_m(x^-,m^-,event))

D06只实现最后两项的控制接口与必要检查。它没有证明所给左端点与根之间确实存在
符合DAE的轨迹、该根是第一次到达，或所有反向支路均可行。D05局部状态与根定位器
仍需由上层统一调用；单独控制器通过不能算物理换流通过。

同时事件尚未定义统一处理：例如低侧归零与下一相电流过零恰好同刻。
当前严格有序接口会拒绝不能提供阶段内左侧见证的情况，不任意排优先级。
后续要验证兼容事件可交换处理，冲突事件应明确报错。

周期闭合不能直接比较绝对时间、递增周期号：需选同一高侧开启截面，
比较电气状态、相对时钟、阶段、锁存/峰值记忆等约化状态。
电气周期性与控制记忆周期性都满足，才构成该模型的周期解。
从零可达性仍是独立问题。
