# D12：连续M1→M2→M3→M4入口，P25三相单模块

本次目的：把已建立的物理层、控制层和事件层连接成一条不重置电气状态的轨迹。
不增加器件复杂度、不改变论文参数、不混用P24四相。

## 锁定边界

- P25 nP=3、nM=1；仅第一相到第二相交接，不声称相号已任意推广。
- D03/D10全部常数电容、动态Co、固定Vin、显式恒流端口。
- 理想开关及显式零检测/驱动延迟；联合低侧事件仅支持理想零压降反向通道。
- 共用Ton显式输入；峰值必须有因果来源。测试数值全部为合成代数夹具。
- 各层V/A容差必须一致；时间定位保留单独容差，不混合单位。
- 有限网格筛查不能证明所有根均未遗漏，所有成功状态均带CONDITIONAL标记。

## 接通了什么

1. M1用D10连续推进至已声明的Ton；D06只关SH1，不改变电气状态。
2. M2用D11判断刚关断SH1从零电压向合法域离开；用D10监视所有相关边界。
3. 若最早候选集合仅为SL1目标归零及SL1理想反向边界，二者按同一电压函数处理，
   调用D07现有联合事件：D05检查切换前反向互补解，D06开启SL1，
   D03检查所有储能状态完全不变，D05检查切换后的电气可行性。
   其他相事件重叠或提前到达时停止，不按任意优先级吞掉。
4. M3全部低侧保持导通，用D10连续推进，同时监视三相电流与全部OFF高侧反向间隙。
5. 只有iL2过零成为单独最早候选时才进入M4；三相状态不重置、栅极不改变。
   D06锁存-alpha*Ipk2_reference。若参考缺失，准确报告控制输入缺口，不补零或猜峰值。

## 结果性质

6项专项测试覆盖真实仿射方程的合成轨迹，不再只用人工拼接的事件端点：

- M1末态连续传入M2，SL1联合事件后进入M3；切换前后互补检查通过。
- M3继续到iL2真实数值根，使用明确的合成设计参考后进入M4。
- 未提供峰值参考时，同一轨迹在iL2过零处被拒绝，理由是因果参考缺失。
- 将非工作相入口电流改小，检测到它提前过零，禁止强行完成低侧交接。
- 短观察窗无事件只报未观察到括区，不报物理不可行。
- 各层容差不一致被拒绝。

2026-09-28全库回归417项通过（本模块6项）；未运行新的论文工况仿真。

此处“真实轨迹”指测试端点由同一连续方程推进得到，不是实验测量或论文工况。
M3入口可保留根定位容差内的小电压残差；不投影为0，因此仍是容差内数值DAE近似，
不是精确实数意义下的理想约束证明。
