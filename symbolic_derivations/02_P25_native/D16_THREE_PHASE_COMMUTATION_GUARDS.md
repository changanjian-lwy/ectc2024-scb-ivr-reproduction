# D16：三相六个换流区间的统一检测

## 目的与来源

D15完成15主模态的节点方程接入，但连续流的换流检测和入口方向判断仍只支持M2/M5。
本次将这两个检测接口扩展到全部六个换流区间；依据仍是D02来源核对和D15的显式循环映射。
后两相属于论文重复相规则的项目展开，不冒充论文另给了六套独立公式。

主线仍是P25原生三相、单模块；不改拓扑、器件、初始状态、负电流比例和控制延迟。
不是P24四相，也没有新增参数拟合。

## 物理映射

| 区间 | 等待的物理事件 | 三相电流符号域 |
|---|---|---|
| M2 | SL1零电压准入 | + + + |
| M7 | SL2零电压准入 | + + + |
| M12 | SL3零电压准入 | + + + |
| M5 | SH2零电压准入 | + − + |
| M10 | SH3零电压准入 | + + − |
| M15 | SH1零电压准入 | − + + |

符号在闭域检查中允许零，但零点能否继续必须另判事件和方向，不能当成严格内点。
六个区间均监视目标Vds、所有OFF开关的反向间隙、所有三相电流边界。
控制目标不优先于其他相先发生的物理边界。

特别是M15的目标是原物理节点上的SH1：

    Vds(SH1)=Vin−a1

没有循环置换节点数组，更没有将它误当成SH2的a1−a2。

## 模块修改

- D15的cycle_mode旁新增current_signs和commutation_target，集中维护索引和符号。
- paper_mode_violations覆盖15主模态，并保留原M2/M5可选prime别名。
- scan_commutation与classify_entry调用同一份映射，避免三个接口各写一套相序。
- 入口零反向间隙仍必须严格向内；目标已为零仍返回需要事件处理。
- 不增加时间epsilon，不投影电压/电流，不强行开门。

## 测试与结果的范围

六项新增测试分别验证：

1. 六个目标开关与三相闭环回接正确；非换流模态被拒绝。
2. 每个区间监视所有OFF开关及全部三相电流。
3. 每个区间故意给另一续流相一个小正电流，检测器首先报告该相过零。
4. 故意把负电流放错相，必须检测出正确目标相与错误负电流相的双重符号冲突。
5. 目标从零开始不能被epsilon跳过，电气状态保持原样。
6. 全部15模态符号以及原prime别名保持一致。

所有数值是沿用的F/H/s量级合成夹具；每区间独立初始化，
不连接成周期、不代表论文工况，也不是六个换流均成功的证明。
有限采样可能漏掉切触或同格多次过零，输出仍标为条件性筛查，不是严格首根证明。

2026-09-28验证：新增6项通过；全库441项通过；公开便携套件422项通过。
