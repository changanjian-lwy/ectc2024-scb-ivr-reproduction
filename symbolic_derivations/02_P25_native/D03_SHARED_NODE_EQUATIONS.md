# D03：P25三相共享节点与M2/M5换流方程

## 1. 来源与统一边界

印刷页2101、2103。开关状态复用D02的P25原生三相表，不调用P24控制或四相模型。

**上表对全部M1–M6一致。只有理想导通约束随模态变化，不临时更换器件或输出边界。**
所有元件值必填、无论文工况默认值；接口保留nP=3、nM、模块号。
nM>1时其他模块通过显式电流端口接入，不等于已求解那些模块的耦合动态。
Co只记一次，不能给每个模块各复制一个系统Co再声称输出网络未变。

这是一层“按P25拓扑推导的完整节点模型”，不是声称逐字执行论文的全部简化公式。

## 2. 节点、方向与状态

以下a1/a2/x1/x2/x3是项目节点别名，不是论文额外元件：

| 器件 | 正端/漏极 | 负端/源极 |
|---|---|---|
| SH1及其电容 | Vin | a1 |
| SH2及其电容 | a1 | a2 |
| SH3及其电容 | a2 | x3 |
| SL1、SL2、SL3及各自电容 | x1、x2、x3 | 地 |
| Cs1 | a1 | x1 |
| Cs2 | a2 | x2 |
| L1、L2、L3 | x1、x2、x3 | 输出o |
| Co | 输出o | 地 |

节点坐标 v=(a1,a2,x1,x2,x3,vo)，电感电流 i=(i1,i2,i3)从x流向o。
这些是描述系统坐标，不代表任一模态都有9个独立自由度；理想导通约束会降低维数。

    vCs1=a1-x1;  vCs2=a2-x2
    vH1=Vin-a1;  vH2=a1-a2;  vH3=a2-x3
    vLswitch,k=xk
    Lk*di_k/dt=xk-vo-Rk*i_k

注意：vLswitch是低侧开关电压，不是电感端电压。

## 3. 不随模态删改的完整KCL

定义JHk、JLk为开关支路总电流，正方向同表中正端到负端。
它们等于沟道电流加并联电容电流，不等于对应电感电流。
Cs1/Cs2电流同样按正端到负端定义：

    a1:  -JH1 + JH2 + iCs1 = 0
    a2:  -JH2 + JH3 + iCs2 = 0
    x1:  -iCs1 + JL1 + i1 = 0
    x2:  -iCs2 + JL2 + i2 = 0
    x3:  -JH3 + JL3 + i3 = 0
    out: Co*dvo/dt = i1+i2+i3 + i_other - i_load
    input: i_in = JH1

常数电容版本：iCs=C_s*dvCs/dt，JH=jH_channel+C_H*dvH/dt，
JL=jL_channel+C_L*dx/dt，其中C_H/C_L均为该开关位置的总有效电容。
电容库必须说明是单管还是并联器件组；本接口要求已经汇总为该位置的电容，避免重复乘并联数。

M2只有SL2、SL3导通；M5只有SL1、SL3导通。
**其余开关电容仍然存在，不能因栅极OFF从KCL里删除。**

## 4. 统一约束系统与唯一性边界

以支路关联矩阵A记上述端点。完整电容矩阵为Cfull=A diag(Cbranch) Aᵀ。
取内部6节点子矩阵C，把电感关联矩阵记为B，当前导通沟道的关联列记为S，
这些沟道在Vin节点的关联行记为s_in。

    C*dv/dt + B*i + S*j_on = -Cfull[internal,vin]*dVin/dt + e_o*(i_other-i_load)
    diag(L)*di/dt = Bᵀ*v - diag(R)*i
    Sᵀ*v + s_in*Vin = 0

对最后一式求导后，与第一式联合求瞬时dv/dt和导通沟道电流。
正电容使C正定；这些模态的S列独立，故对应约束线性系统在本边界下可解且解唯一。
这只说明局部代数系统适定，不证明一整个事件序列可行。

每次接受状态必须满足原电压约束，不能只解其导数而忽略入口不相容。
用独立的V、A、V/s残差检查，不把不同单位混成一个绝对误差。

## 5. M2：消元得到的换流斜率

限定：Vin固定、x2=x3=0，全部关断反向通道未准入，电容为正定常数。
定义Hk=C_Hk、Lck=C_Lk、F1=Cs1、F2=Cs2，避免把低侧电容记作电感L。

    K2 = H1 + H2*(H3+F2)/(H2+H3+F2)
    Ceq_M2 = Lc1 + F1*K2/(F1+K2)
    dx1/dt = -i1/Ceq_M2
    da1/dt = F1/(F1+K2)*dx1/dt
    da2/dt = H2/(H2+H3+F2)*da1/dt

若i1>0，则SL1电压x1下降，SH1电压Vin-a1上升，与M2物理描述一致。
这里没有假设i1恒定；若用该斜率乘时间求整个区间，则还需要推进电感电流。

当F1、F2远大于各开关电容，极限是

    Ceq_M2 → Lc1 + H1 + H2

因此在这一特定边界下，下一高侧电容H2也参与第一相换流，不能只留H1和Lc1。

## 6. M5：第二相高侧归零与其他相电容的联系

限定：Vin固定、x1=x3=0；其余条件同上。

    K5 = H3 + H2*(H1+F1)/(H2+H1+F1)
    Ceq_M5 = Lc2 + F2*K5/(F2+K5)
    dx2/dt = -i2/Ceq_M5
    da2/dt = F2/(F2+K5)*dx2/dt
    da1/dt = H2/(H1+H2+F1)*da2/dt
    d(vH2)/dt = da1/dt-da2/dt
               = -(H1+F1)/(H1+H2+F1)*da2/dt

若i2<0，则x2上升，vH2下降。这是瞬时方向结论；i2在换流中可能改变，
不能据此断言它必能在电流反转或下一边界之前把vH2降到零。

在F1、F2足够大的相同极限下：

    Ceq_M5 → Lc2 + H2 + H3

**第三相高侧电容H3参与第二相换流，即使SH3栅极没有开启。**
这也说明不能未经拓扑消元，把所有换流都套用同一组“本相CH+CL”。
这不是对历史7.77%等门槛的新判定；那些数字必须连同旧器件、控制与输出边界单独复核。

上述消元只减少导数求解维数，不允许把原状态删掉、冻结或重置。

## 7. 模态切换与能量检查

无冲激模型的事件边界要求所有电感电流和所有电容电压左右连续。
`assert_continuous_energy_state`检查全器件而不只检查飞跨电容，电压/电流容差分别输入。

例如SH2开启时，不能把i2直接改为0，不能强行把a2抬到a1来制造ZVS。
若入口仍有非零vH2，理想导通约束不相容，接口报错而不是投影成一个好看的状态。
实际硬开通可以通过有限Ron/ESL等模型研究，但不属于本次理想ZVS切换边界。

M6的理想关系为：a1=a2、x1=0，因此x2=vCs1-vCs2。

    L2*di2/dt = vCs1-vCs2-vo-R2*i2

这延续D02所记录的KVL与印刷Eq. (15)的差别；同样必须延续真实入口电流。

能量与功率核对使用全部恒定电容及三只电感：

    W = 1/2 Σ Cb*vb² + 1/2 Σ Lk*ik²
    dW/dt = Vin*i_in + vo*i_other - vo*i_load - Σ Rk*ik²

理想导通沟道电压为零，所以不计其导通损耗。i_in包含SH1电容位移电流：
不能在SH1关断时一概把瞬时输入电流硬设为零。
如果器件电容是非线性Cdiff(v)，能量必须改为积分定义，不能继续沿用1/2*C*v²。
