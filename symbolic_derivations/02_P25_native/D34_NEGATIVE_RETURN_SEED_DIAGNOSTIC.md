# D34：符合返回方向的新初值，仍先检查可达性

## 目的、来源与改变项

按D33的必要条件，把新候选限制为i1<0，从M1重新计算。
不修改D29轨迹；对比D29基线，每组只改变入口i1。
器件、动态Co、Vin、负载、Ton、alpha、三相声明峰值、反向模型、
其他五个初值坐标及事件容差均保持原合成边界。
脚本共用D29的冻结上下文工厂，避免复制参数产生分歧。

初值选择依据：入口电感KVL给出的局部斜率尺度

    s = Ton (x1,0 - Vo,0)/L1 = 0.01 A

取i1=-0.25s、-0.5s、-s。它只是待求初值的测试尺度，不假定整个Ton内斜率恒定，
也不把s当成实际电流增量或峰值。第四组取-1 A（原alpha×设计峰值）作对照；
负目标是低侧关断阈值，不声称高侧开启时电流也应恰好等于它。

首先使用原M2搜索时长1 s；遇到无事件，再仅把M2搜索时长延长至10 s。
这是数值查找窗口变化，不是强制保持模态10 s：任一被检测的先发事件仍立即停止。
200/400网格各检查一次，不更改物理参数和控制时序。
这些秒和安培均属于原F/H/s合成夹具，不是论文工况。

## 结论与下一步

纠正初值方向后，旧M5障碍不再是这些新候选的最早障碍；需从M1/M2解释。
