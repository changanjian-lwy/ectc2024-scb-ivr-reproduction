# D25：目标Vds的二阶方程，不混用两种电容

## 目的

D24的Cn是目标高侧Vds相对iq的网络归一化电容，
不是可以不加说明就代入孤立LC频率公式的电容。
本次补出实际开关节点xq与目标Vds之间的变换，并与完整节点流核对。

仍为P25三相单模块M5/M10/M15，恒Vin、线性常量元件、
另两相低侧理想ON、无正在导通的反向钳位。完整动态Co及各相电流都保留。
公式来源是D03/D24的KCL/KVL消元，没有新增论文器件数值。

## 节点关系

令V=Vds_target，D24给出dV/dt=iq/Cn。
同一网络消元还给出：

    dxq = -gamma*dV
    xq(t) = xq0 - gamma*(V(t)-V0)

使用D24中的A、K1、K2、K3：

    M5:  gamma = (A+H2)/A * (1+K2/F2)
    M10: gamma = 1+H3/K3
    M15: gamma = 1+K1/F1

因此相对开关节点本身的电容归一化为：

    Cx = Cn/gamma
    Cx*dxq/dt = -iq

Cn与Cx不能混为一谈。这里并未删掉完整网络中的任何电容，
只是在已声明的固定栅极模态内消去了依赖坐标。

## 二阶方程

电感方程仍为：

    Lq*diq/dt = xq - Vo(t) - Rq*iq

代入上面关系得到：

    Lq*Cn*V'' + Rq*Cn*V' + gamma*V
        = xq0 + gamma*V0 - Vo(t)

右侧使用真实动态输出Vo(t)，不是固定1 V。
完整输出方程还受全部三相电流驱动：

    Co*dVo/dt = i1+i2+i3 - Iload

因此把V的二阶式单独看成恒定中心的自由谐振，会漏掉其他相经Co施加的耦合。
只有额外声明Vo恒定的局部近似，才可将右侧视为常数。
该局部齐次子方程的无阻尼参数为：

    omega0 = sqrt(gamma/(Lq*Cn)) = 1/sqrt(Lq*Cx)

这不是当前全耦合系统的完整固有模态，更不直接给出可行ZVS事件时间。
绕组R非零时还须保留阻尼；本次检查保留了它。
