# D04：按真实状态检查事件，不按时间猜事件

2026-09-28。P25原生三相；接续D02物理事件、D03节点定义。
依据不变：P25 Sec. II及Fig. 1–3。下面的检测接口是PROJECT_DECISION，
不是论文公开了这些容差、检测算法或驱动实现。

## 输入与模块边界

每个Snapshot保留同一瞬间的全部6个节点电压、3个电感电流、全部栅极状态、
Vin、时间、分支/nP/nM/模块号、实验/时钟/周期编号。
电压由D03真实支路端点计算，不把某个节点对地电压当成任意高侧Vds。

事件必须在相应栅极组合中检查：

| 物理事件 | 判别函数g | 对应区间 |
|---|---|---|
| SL1零电压 | x1 | M2 |
| 第二相电流过零 | i2 | M3 |
| 第二相到负目标 | i2 + alpha*Ipk2_ref | M4 |
| SH2零电压 | a1-a2 | M5 |

alpha继承P25 Mode 4的显式选择，不引入P24阈值。
目标峰值继承D02的第二相因果参考，不采用未来未知峰值。

## 1. 候选区间不是事件定位结果

`downward_bracket`要求相同实验、边界、时钟和周期，t_right>t_left，
g_left>0且g_right<=0。满足时只返回BRACKET_ONLY。

- 不能用右端点代替根时刻；右端点可能已经发生很大过冲。
- 不能凭两端点证明区间内只有一次过零或这就是第一次过零。
- 不能用这个检查替代连续的DAE轨迹、根定位和中间约束检查。
- 若左端点已经恰为零，此函数不重复触发；根处方向判定和去重仍待下一层实现。

## 2. 开通时重新检查电压

`gate_voltage_criterion`分别检查SL1或SH2，并要求目标开关及互补开关未开启，
其余开关符合该区间状态。调用者必须显式提供电压容差epsilon_V。

    abs(Vds_at_gate_request) <= epsilon_V

满足仅返回VOLTAGE_CRITERION_ONLY，不代表已经发出门极命令，也不代表驱动延迟后
电压仍合格。实际开启时还须再次检查。

“之前到过零”不能替代本次检查；Vds=-若干伏也不能仅因Vds<=0就宣称零电压。
若真实GaN在负压反向通道下开通，则须另外声明允许的反向导通/损耗边界，
不能偷偷扩宽这里的对称零电压容差。

## 3. 负电流目标与过冲分开

`target_residual`计算 i2-i2_target，并使用显式、独立的安培容差epsilon_I：

- 绝对残差<=epsilon_I：TARGET_CRITERION_ONLY。
- 正残差超容差：TARGET_NOT_REACHED。
- 负残差超容差：TARGET_OVERSHOT。

达到目标不等于实际关断；检测、命令、有效关断继续分开记录。
驱动延迟引起的额外负电流必须按方程推进，不能用目标值覆盖实际值。

## 4. 未知反向钳位保持未知

`reverse_boundary_status`不自带GaN数值或理想零阈值。
未提供规则时返回UNRESOLVED，禁止借“软件需要能运行”填一个0V。

若调用者显式提供非正的Vds边界及模型/来源：

- 开关已栅极开启：NOT_APPLICABLE，应使用双向沟道模型。
- 关断且电压仍高于所选边界：ABOVE_DECLARED_BOUNDARY。
- 到达或低于边界：REVERSE_MODEL_REQUIRED，必须停止未钳位模式或接反向模型。

这只是边界筛查，尚不计算反向电流、互补条件、退出条件、Qrr或损耗。
固定阈值也不是完整GaN特性；测试中的理想0V阈值明示为合成理想分支，不是器件数据。

完成：状态量到事件量的映射、方向性端点候选检查、开通时电压检查、
负目标残差分类、未知反向规则阻塞、跨实验混用检查。

因此这些函数既不构成完整控制器，也不声称模式在整个时间区间内已经有效。
