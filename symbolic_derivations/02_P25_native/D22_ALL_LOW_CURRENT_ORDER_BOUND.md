# D22：全低侧导通段的电流次序必要条件

## 目的与假设

在昂贵的全周期尝试前，找出能解析排除的局部初值条件，而非盲目增大某相电流。
仅分析P25三相单模块M3/M8/M13入口至下一相负目标，低侧仍全ON的范围。
来源是D03节点方程、D15相号映射和D14伏秒恒等式，不新增论文参数。

目标相q以及被比较相k必须满足R_q=R_k=0、x_q=x_k=0，
且入口三相电流严格为正。其他相不满足这些条件时明确报告不适用。
模型仍保留全部电容及动态Co。没有将Vo替换成1 V常量。

## 推导

两相满足：

    Lq * diq/dt = -Vo(t)
    Lk * dik/dt = -Vo(t)
    Phi(t) = integral Vo dt

因此：

    Lq*iq(t) = Lq*iq0 - Phi(t)
    Lk*ik(t) = Lk*ik0 - Phi(t)

要使目标相达到i_target<0，公共伏秒必须到达：

    F_target = Lq*(iq0-i_target)

在该瞬间另一相仍正向的必要条件是：

    Lk*ik0 > F_target

若Lk*ik0<F_target，由Phi连续性，另一相必在到达目标前经过零点。
相等时会与目标同时触边，不能当作严格正向续流成功。
这个必要性证明不要求Vo恒定，也不要求Phi单调；但正裕量不保证路径可达，
因为可能存在更早反向边界或Phi非单调等问题。

这是必要条件，不是ZVS能量判据，不是完整周期可行性证明。

## 实现及数值范围

p25_all_low_necessity.all_low_necessity返回每个可比较相的初始Li、
目标时刻必要剩余伏秒、跳过的相号及分类。
比较使用显式V·s数值保护带；浮点运算不是区间算术证书。
非零绕组R或哪怕很小的非零节点残差都不会被当作零删除。

测试：三相公式与动态Vo积分吻合；低裕量提前失败；
相等裕量不算成功；节点残差和绕组R不得忽略。均为合成F/H/s夹具。

## 旧失败链的交叉检查

使用D21基线实际M3入口（200点分段筛查），不是另造状态：

- q=2，到−1 A目标需要F_target≈8.6639114463 V·s。
- 第三相初始Li≈11.6639114463 V·s，差值=3 V·s。
- 与D14/D19进入M5时第三相剩余约3 V·s一致。
- 第一相节点x1≈−3.013e−9 V，为根定位容差内残差；公式实现将第一相跳过，
  不据此宣称全三相必要条件已全部证明。

因此该基线通过的是“第三相不必在负目标前先过零”的局部必要条件，
不否定其随后M5在SH2零压前耗尽余量的既有失败结果。
