# D09：P25逐模态方程对照，不调整参数

2026-09-28。依据P25 Sec. II、Fig. 1–3、印刷页2102–2104，及D02/D03源文核对记录。
只核对第一相到第二相的M1–M6。未运行新瞬态、未改变旧求解器、未引入P24规则。

## 1. 两种边界不得混为一谈

当前节点模型：有限Cs1/Cs2/Co，全部六个开关位置的Coss与snubber均保留，
线性常数电容、理想ON沟道；绕组R可显式非零。输出由Co和外部电流端口决定。

本次比较层：R=0、理想沟道压降=0；在需要积分成直线时，另取Vin、Vo、
串联电容电压在局部区间近似恒定。换流时间的线性估计还需电感电流近似恒定。
这些是纸面比较近似，未在动态模型中添加电压源钳位或状态重置。
瞬时斜率一致不等于整段轨迹、周期、电荷平衡一致。

符号：u1=Vin-vCs1；u2=vCs1-vCs2；Ton=D*T。
τH1/τH2为真实高侧开启时刻，τz为i2过零，τoff为SL2实际关断。
Ipk是已明确来源的峰值参考，J=-i2(τoff)>0。C_H/C_L均须说明单管/并联组、Coss/snubber口径。

## 2. M1：高侧导通，Eq. (1)–(4)

由SH1 ON、SL2/SL3 ON：

    L1 di1/dt = Vin-vCs1-Vo
    L2 di2/dt = -Vo
    L3 di3/dt = -Vo

与Eq. (1)–(4)在零导通压降边界下的斜率一致。
若局部电压恒定：i1(t)=i1(τH1)+(u1-Vo)(t-τH1)/L1。
论文Eq. (1)/(2)省略入口项；只有入口电流确为零，才恢复其绝对电流表达式。
换流后的负入口不能为了吻合该式被归零。

判定：斜率一致；入口电流为额外适用条件，不是自动成立。

## 3. M2：高侧关断，Eq. (5)/(6)

D03完整网络在Vin恒定、SL2/SL3理想导通、反向通道尚未准入时给出：

    dV_SL1/dt = -i1/Ceff_M2
    Ceff_M2 = C_L1 + Cs1*K/(Cs1+K)
    K = C_H1 + C_H2*(C_H3+Cs2)/(C_H2+C_H3+Cs2)

在Cs1/Cs2远大于开关电容的极限：Ceff_M2 → C_L1+C_H1+C_H2。
再取i1≈I1>0且入口V_SL1=U1，则Δt≈Ceff_M2*U1/I1。

论文Eq. (5)的斜率等于-I1/(2*C_L1)，其中I1=(u1-Vo)*Ton/L1；
Eq. (6)是该线性电压式归零的结果，两式在自身近似下代数一致。
要把它们与当前网络等同，还需要Ceff_M2=2*C_L1等电容条件。
仅称“串联电容很大”并不足够；例如所有开关总电容相等时上述极限为3C而非2C。

判定：换流方向一致；等效电容口径/近似需要解释，不能直接宣布原式错误或删掉其他相Coss。
恒流时间估计没有证明到归零前电流仍保持正值、也没有证明别的支路未先触边。

## 4. M3：全部低侧导通，Eq. (7)–(10)

零导通压降、R=0时，三相均满足di_k/dt=-Vo/Lk。
Vo局部恒定且i2入口>0时，到i2=0的时间为L2*i2(entry)/Vo。
这与Eq. (7)–(10)的零压降版本一致。
但Eq. (7)用峰值作为入口：完整模型须使用M2结束的真实i1，
只有忽略M2电流变化时才可用其替代。

判定：斜率及过零时间条件一致；峰值入口为换流恒流近似。

## 5. M4：建立负电流，Eq. (11)/(12)

理想沟道边界：i2(t)=-Vo*(t-τz)/L2。
达到-J的时间为Δt_negative=L2*J/Vo。
按论文定压降近似可写L2*J/(Vo+Vrev)，但不是负电流下的带符号Ron模型。
Eq. (12)印刷式未显式包含L2，若分子是电流、分母是电压则不具有时间量纲；
符号也应区分负电流与正的幅值J。详见D02。

判定：机制和Eq. (11)零压降斜率一致；Eq. (12)保留为量纲疑点。

## 6. M5：SL2关断，Eq. (13)/(14)

D03给出dV_SH2/dt=target_gain*(-i2/Ceff_M5)，target_gain<0。
设γ=-target_gain>0，i2≈-J，则dV_SH2/dt≈-γ*J/Ceff_M5。
对入口V_SH2=U2>0，局部归零时间≈Ceff_M5*U2/(γ*J)。
大串联电容极限为γ→1、Ceff_M5→C_L2+C_H2+C_H3。
恢复论文Eq. (13)形式还需Ceff_M5/γ=2*C_H2等额外条件。

独立于上述电容争议，按论文Eq. (13)本身：

    V_CH2 = U2 - (Vo+Vrev)*t43/(2*L2*C_H2) * (t-τoff)
    Δt_zero = 2*L2*C_H2*U2 / ((Vo+Vrev)*t43)

但Eq. (14)印刷分母为D*T*(Vo+Vrev)，不是t43*(Vo+Vrev)。
若这些符号按原文定义，则只有另有t43=D*T才可互相替代；
已核对段落未给出该等式。负电流建立时间与高侧导通时间不可默认相同。
此项先标为公式一致性疑点，不推断作者实验控制实际有错。

判定：物理方向一致；电容简化及Eq. (13)到(14)的时间替换分别待解释。

## 7. M6：第二相导通，Eq. (15)/(16)

SH2与SL1理想导通给出x2=vCs1-vCs2，因此：

    L2 di2/dt = vCs1-vCs2-Vo
    i2(t)=i2(τH2)+(vCs1-vCs2-Vo)*(t-τH2)/L2

后式仅在局部电压恒定时成立。Eq. (15)/(16)印刷式未写-Vo和入口电流。
前者不能仅通过“理想开关”或“串联电容零纹波”消去；需另有Vo忽略近似或符号解释。
后者须证明入口电流为零，否则违反当前连续状态边界。

判定：按Fig. 1 KVL保留-Vo及实际入口，原文差异单列，不把派生式标成照抄论文。
